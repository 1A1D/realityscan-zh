调整着色与纹理设置

若要调整模型着色/纹理的任何参数，可在 MESH & COLOR 选项卡的 Color & Texture 区域找到两者的 Settings。

纹理及其质量在很大程度上取决于 UV 的生成方式。RealityScan 提供的方式是按坐标系单位定义所需纹素大小（例如纹素为 5mm），也可以设定最大纹理分辨率和可用于给模型贴图的纹理数量。此外，也可以随模型导入 UV 坐标（了解更多）。


默认展开UV参数

可以修改纹理工序前默认使用的展开UV参数（用于模型尚未展开UV的情况）。目前有两种方法：Geometric 与 Mosaicing based。Geometric 是传统的快速展开法；Mosaicing based（实验性）是新方法，产生的 UV 岛更少，但比几何法慢。



  • Gutter 表示纹理图中每个图表边框的像素数。Gutter 对于避免渲染时模型上出现可见瑕疵很重要。许多渲染引擎使用 mipmap 等技术，把纹理逐级缩小形成图像金字塔；当引擎从较高层级渲染纹理时，插值过程中一个图表的颜色可能渗到另一个图表里 —— 只要图表之间的 gutter 不够大就会发生。默认值 2 在多数渲染引擎中足以避免此类瑕疵。
  • Minimal texture resolution 设置展开UV的最小分辨率，可选 512x512、1024x1024、2048x2048、4096x4096、8192x8192 或 16384x16384。该值不能高于 Maximal texture resolution。
  • Maximal texture resolution 设置展开UV的最大分辨率，可选 512x512、1024x1024、2048x2048、4096x4096、8192x8192 或 16384x16384。该值不能低于 Minimal texture resolution。
  • Large triangle removal threshold 指定控制大三角面如何展开的阈值。若某三角面的边长乘以该值后仍超过模型的平均边长，该三角面就会被映射到单个纹素。例如设为 400，意味着边长超过模型平均边长 400 倍的三角面会被映射为一个纹素。
  • Unwrap method 定义展开模型UV所用的方法，可在 Geometric 与 Mosaicing based 之间选择。
  • Style 定义基于所选 Unwrap method 构建 UV 的策略。
  • Defragment charts 启用后会在展开过程中使用 Maggiordomo、Cignoni 与 Tarini 的方法生成更大的 UV 岛（了解更多）。

警告：仅当对象不含 UV 贴图、且你按下 Texture (F9) 按钮时，才会使用默认展开参数。若模型已有贴图而要重新计算展开，请使用 Unwrap tool.

几何展开法

使用几何法时，可以设置最大纹理数量，或控制纹素大小。

最大纹理数量模式

当你需要把模型限制在特定纹理数量时，这个模式很有用。把 Style 设为 Maximal texture count，就会出现 Maximal texture count 设置。纹素细节会自动调整，使纹理在所选最大分辨率下刚好放进指定的最大纹理数量。

控制纹素大小

若目标是交付具有预定视觉精度的模型（例如为生成真正的正射影像而采用 1cm 分辨率），请使用 Fixed texel size 或 Adaptive texel size 模式。纹理数量会按所选纹素大小所需的量自动生成。

两种展开模式有部分共用设置，以下是与此相关的设置：

  • Coordinate system 定义作为测量单位依据的参考坐标系。要更改此值，请修改项目坐标系（了解更多）。
  • Unit type 显示所选坐标系的单位，例如 meter、inch；若单位类型未知则显示 "units"。
  • Texel size 在此设置纹理像素的尺寸。使用自定义选项时，若坐标系单位是米，把该值设为 0.01 即得到 1cm 的纹素。模型计算完成后，可用 Unwrap 工具估算合理的最小分辨率。

实际应用中，例如扫描广场上的雕像时，你可能希望雕像附近细节更细、其他地方保持 1cm 细节。这时可选 Adaptive texel size 模式，在其中定义纹理必须落入的范围。RealityScan 的展开算法会结合三维模型、相机位姿和输入分辨率计算最优纹素大小，并把估算值限制在以下范围：

  • Minimal required texel size 纹素的最小尺寸。使用高分辨率相机在不同物体间拍摄时，用它可避免浪费纹理像素。
  • Maximal required texel size 定义纹素的最大尺寸，即不会出现更大的纹素。若之后要在纹理上绘制，这个设置很实用。


基于镶嵌的展开法

基于镶嵌的展开有另一套 Style 选项，可在 Maximal texture count 与 Quality 之间选择。

  • Maximal texture count 当你需要把模型限制在特定纹理数量时，这个模式很有用。
  • Quality 从预定义质量档中选择，或自定义数值。

颜色与纹理设置

在着色与纹理设置中，可以设定导入纹理的分辨率，以及影响纹理与着色过程的各种参数。



导入的 UV 贴图

导入的模型（了解更多）可能已带 UV 坐标，此时不必也不建议重新计算。不过导入时纹理分辨率可能无法确定，例如缺少占位纹理文件时。

  • Imported-model default texture resolution 导入纹理分辨率未知的模型时使用的默认值，可选 512x512、1024x1024、2048x2048、4096x4096、8192x8192 或 16384x16384。以 FBX 格式导入模型时此设置会被忽略。

纹理算法

用以下设置配置额外的纹理与着色选项。

  • Coloring method Linear 取平均值。Multi-band（默认）使用多个通道，把图像分解为多个频率分量后再合并：低频分量承载颜色与亮度，可在大范围内线性合并；高频分量承载细节（例如纹理颗粒尺度），用另一种优化方式合并。
  • Coloring style Visibility-based 模式快速且锐利；Photo-consistency based 模式较慢，但结果更复杂精细。
  • Coloring image layer 选择用于着色的图像图层，默认使用几何图层。
  • Texturing style Visibility-based 模式快速且锐利；Photo-consistency based 模式较慢，结果更复杂。Mosaicing based（实验性）把模型表面划分为若干区域，每个区域用单一图像源贴图，再在接缝处融合 —— 这与「对多个图像源取平均来生成纹理」的融合方式不同。它生成的纹理比 Visibility-based 更锐利，但更慢，也不建议用于较大的数据集。Maximal、Minimal 和 Average intensity 会根据能看到该点的所有相机，为点赋予强度值（单色）。
  • Texturing image layer 选择用于纹理的图像图层，默认使用几何图层。
  • Downscale images before texturing 此处填写的数字是纹理计算前自动缩小图像的倍数。填 1 表示不缩放（100% 分辨率），填 2 表示图像每边缩小一半（原分辨率的 25%），以此类推。
  • Downscale images before coloring 该数字用于在着色前缩小原图，作用同上。推荐值与默认值均为 2。
  • Fill in uncolored / untextured parts 该功能特别适合检查覆盖情况 —— 当模型中有些部分未被相机或激光扫描覆盖时。设为 True 后，应用会智能填补输入图像未覆盖的模型区域。
  • Recolor model after texturing 启用后会从纹理计算顶点色 —— 只需点击一次 Texture (F9) 即可同时得到着色与纹理。
  • Correct colors 自动补偿所选组件中所有图像之间的颜色、亮度和对比度差异。
  • Ignore color correction 在着色/纹理计算时忽略图像的颜色校正。
  • Prefer 16-bit/HDR textures generation 详情参见 16 位与 HDR 图像。

提示：模型着色和/或贴图完成后，就可以通过渲染截图查看效果、创建正射投影和/或导出了。

已贴图模型的纹理属性

模型展开UV、贴图或导入后，可以查看以下纹理属性：在 1Ds 视图中选中模型，会出现该模型的面板，展开其中的 Texturing 分组即可。

  • Coloring style 着色/纹理采用的风格或执行方式。
  • Unwrapping style 所使用的展开UV模式。
  • Unwrap method 所使用的展开UV方法。
  • Count of textures 纹理数量。
  • Texture resolution 纹理分辨率。所有纹理的分辨率必须相同。
  • Chart gutter size 纹理图中每个图表边框的像素数。
  • Texture utilization (with gutter) 已使用纹素的百分比。
  • Optimal texel size 与图像可捕获的最小细节相对应的三维纹素尺寸。
  • Texture quality 等于纹素尺寸相对最优纹素尺寸的百分比，反映纹理细节相对图像可提供的最大细节的水平。
  • Texel size 三维纹素的尺寸（实际单位）。

纹理图层

完成展开UV或纹理后，可在 1Ds 视图中模型下方的 Model Textures 里选择纹理图层。



Selected Texture Layer 面板显示创建该纹理图层时所用的设置。点击图层的 Name 并输入新名称即可改名。
