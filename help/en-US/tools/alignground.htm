地平面

RealityScan 会自动检测地平面。若你的组件看起来是歪的，可以手动调整场景的位置与朝向。

  • 在应用功能区选择 SCENE 3D/TOOLS 选项卡。
  • 点击 Set ground plane 按钮定义地平面，地平面工具会出现在 3Ds 视图中。
  • 点击 Set ground plane 下拉按钮可显示更多选项：Define Ground Plane、Set Ground by Reconstruction Region、Reset Ground。
  • 用 ground plane widget 移动和/或旋转场景。
  • 点击并拖动圆形控件可旋转场景。按住 SHIFT 可放慢旋转速度，按住 CTRL 可按 15 度增量吸附。
  • 左键点击并拖动箭头控件可平移场景。右键拖动可在垂直于箭头方向的平面上移动场景。按住 SHIFT 可放慢控件的移动速度。
  • 双击可重新设置轴心位置。
