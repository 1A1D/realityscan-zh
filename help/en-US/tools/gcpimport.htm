地面控制点导入

地面控制点是三类控制点之一，与某个三维位置（例如 GPS 坐标）关联。若你已有控制点的坐标，可以导入这些数值并把它们放到对应照片上，从而对模型做地理配准和/或缩放。

  • 地面控制点的图标如下所示：

  • 首先，确认已把项目坐标系设为待导入地面控制点所在的坐标系。应用Settings位于 WORKFLOW 选项卡的 Application 区域下 Coordinate systems / Project coordinate system 处。
  • 现在进入 WORKFLOW / Ground Control，浏览选择含地面控制点的文件。

导入对话框

会立即弹出导入对话框，下面看看其中的各项选项：



  • File name 含地面控制点信息的文件名。
  • File format 定义用于描述地面控制点的数值的顺序与类型。
  • Values separator 用于分隔地面控制点文件中各值的分隔符。也支持限定符，即可把每个字段放在双引号（""）里表示它们是同一个字段。
  • Ignore first line 若文件带表头，可让 RealityScan 忽略第一行。以 # 符号开头的行会被自动跳过。
  • Coordinate system 定义地面控制点所在的坐标系。
  • Position accuracy 地面控制点坐标的精度。选择相应的 File format 也可以从文件中加载精度。

  • You can define your own file format, different values separator, comment symbol or qualifiers in the groundcontrol.xml which can be found in the application installation folder. You can find the instructions on how to edit the groundcontrol.xml, as well as the list of supported values for import here.

    提示：Lon —— 经度，Lat —— 纬度，Alt —— 高程

    A sample of the Name, Y/Lat, X/Lon, Z/Alt（以字符分隔） file format with tab-separated values:

  • 系统支持以度为单位输入，也支持绝对值的 X、Y 与 Alt，具体取决于所选coordinate system。
  • 在本页顶部所示对话框中点击 OK 后，GCP 数值就会导入项目。
  • 此时建议至少核对 2 个 GCP 的导入坐标与源文件中所给的是否一致。若有不对，先修正再继续下一步。
  • 接下来只需把 GCP 手动放到正确位置。最简单的方式是从 1Ds 视图的列表中拖放 GCP。

最后几点提示

  • 建议一个 GCP 至少用在三张图像中。
  • 手动添加控制点的快捷键是 F3。
  • 坐标偏差在 5 厘米以内可以接受。
  • 也可以用命令行导入 GCP。
