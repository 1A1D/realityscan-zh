裁剪盒

裁剪盒是一个可调整的方块，用于定义已重建模型中指定部分的三维显示范围，而不丢失模型的任何部分。在 3Ds 视图中调整其尺寸时，显示内容会自动更新。
当内存或显存不足以显示整个模型时，裁剪盒非常有用，例如在 solid 或 color/texture 渲染模式下（见 Real-time Scene Renderer）。

  • 只有在模型已重建、且某个视图设为 3Ds 时，该工具才可用。这时才能在 SCENE 3D/VIEW 选项卡中看到并点击该按钮。
  • 点击 Clipping Box 按钮旁边的小箭头可查看其全部选项。在 3Ds 视图中点击三次即可定义盒体，之后还可以调整大小或删除。打开 Clipping Box 下拉菜单，还能找到从重建区域自动创建盒体的选项。见下文：

若选择手动创建裁剪盒，把鼠标移入 3Ds 视图并：

  1. 点击鼠标左键确定区域底面左上角。
  2. 移动鼠标确定重建盒的底面。
  3. 点击鼠标左键确认区域底面。
  4. 移动鼠标调整区域高度。
  5. 点击鼠标左键确认区域。

定义好裁剪盒后，点击 Edit Clipping Box，用 box widget 移动、旋转或调整方块尺寸，用法与 reconstruction region 类似。

要移除裁剪盒，选择 Clear Clipping Box。
