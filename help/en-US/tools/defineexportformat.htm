自定义导出格式

如果你需要导出额外信息，或想改动现有导出格式，部分导出格式可以按你的具体需求和偏好进行自定义。这些导出包括：配准、地面控制点、控制点、点云、正射影像、横断面、等高线、深度与遮罩图像、重建区域、报告，以及地图向导报告。

要自定义这些导出，需要编辑安装目录下对应的文件。若安装时未更改安装位置，可在以下路径找到： 

C:\Program Files\Epic Games\RealityScan

导出文件结构

每个导出文件都有一定结构，所用的元素与属性取决于你的需求以及 writer 属性。 

<format id="" mask="" descID="" desc="" writer="" requiresGeoref="" requiresEqualResolution="" undistortImages="" exportImages="" supportsGeoref="" specificCoordSystem="" requires="">
    <parameter name="" type="" default="" variable="" hint=""/>
    </parameter>
    <body>
    </body>
</format>
  • <format> 定义导出的参数与属性。
    • id (optional) 唯一标识号（GUID）。
    • mask 导出文件的格式扩展名。例如写 *.xyz 就会导出 XYZ 文件。
    • descID （可选） 用于语言本地化的唯一内部标识号。
    • desc 在导出对话框中显示的文件格式名称。
    • writer 导出格式的结构取决于所选 writer。某些 writer 无法完全自定义。
    • requiresGeoref （可选） 若要求组件已做地理配准才显示此导出格式，就使用该属性并设为 1；设为 0 则组件未做地理配准时也显示此选项。
    • requiresEqualResolution （可选） 使用并设为 1 可启用导出对话框中的 Undistortion settings，并允许自定义图像宽高。它是 undistortImages 属性的补充属性。设为 0 可去掉自定义宽高选项。
    • undistortImages （可选） 使用并设为 always 可在导出对话框中显示 Undistortion settings。它是 exportImages 属性的补充属性。设为 never 可去掉自定义宽高选项。
    • exportImages （可选） 使用并设为 1 可在导出对话框中启用图像导出选项。
    • supportsGeoref （可选） 使用并设为 1 可在导出对话框中显示变换设置；设为 0 则去掉变换设置。
    • specificCoordSystem （可选） 使用并设为 1 可让导出对话框的项目输出选项中能够设置 Coordinate system。
    • requires （可选） 指定项目里必须存在并被选中什么，才会看到此导出选项。可设为：component、model、GCP（地面控制点）、cpm（控制点测量）、projection（正射投影）、dtm（数字地形模型）、crosssections、isolines（等高线）或 georeferenced。
  • <parameter> (optional) 编辑已有的导出参数，或创建自己的参数。
    • name 参数名称会显示在导出对话框中。
    • type 设置数据类型。可选 bool、integer、float 和 value。
    • default 导出对话框中显示的默认值。
    • variable 参数名称，可在 body 元素中作为变量使用，并会显示在参数文件（params.xml）中。
    • hint 为该参数创建提示文本。把鼠标悬停在导出对话框中的该参数上即可看到提示。
  • <body> 导出文件的内容。该元素使用模板系统的函数与变量，并非所有 writer 选项都支持。

Writer 属性

writer 属性指定可用的参数以及导出文件的整体内容。部分 writer 选项使用内置文件格式，无法完全自定义。

只有带 <body> 元素的格式才能自定义内容，但并非所有 writer 选项都支持该元素：有些使用内置文件格式，内容不可更改。不支持 <body> 元素的 writer 选项包括：

  • rca 用于导出 RealityScan 对齐组件（.rsalign）的 writer。
  • RealityScan.Export.STMaps 仅用于导出 ST Maps。
  • RealityScan.Export.OrthoExport 用于正射投影、数字表面模型和数字地形模型导出。
  • RealityScan.Export.ModelCrossSections 用于导出横断面。
  • RealityScan.Export.DepthAndMaskImages 用于导出深度与遮罩图像。
  • RealityScan.Export.Isolines 专用于导出等高线。
  • RealityScan.Export.ReconstructionRegion 用于导出重建区域。

使用带 <body> 元素的 writer 选项，就能用模板系统的函数与变量生成导出文件内容。可用的模板函数集取决于所选 writer 选项。

  • csv 用于一般文本导出。可用的函数集为 BasicExportFunctionSet、ConfigExportFunctionSet 和 SfmExportFunctionSet。
  • RealityScan.Export.ControlPoints 用于导出控制点与地面控制点。可用函数集与 csv writer 相同，另增加 ControlPointsExportFunctionSet。
  • RealityScan.Export.ReportWriter 用于导出报告或地图向导报告。此 writer 支持所有函数集。
