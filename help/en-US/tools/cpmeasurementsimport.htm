控制点测量导入

RealityScan 支持导入control points在特定图像中的位置，以及ground control points。控制点的位置以像素为单位，原点为图像左上角。

导入控制点测量值有两种方式：

  • Using the Control Points import button.
    1. Go to WORKFLOW / Import Metadata / Control Points.

      • File name 包含控制点测量值的文件名称。
      • File format 定义文件中各值的顺序与类型。
      • Values separator 用于分隔文件中的各值的分隔符。也支持限定符，即可把每个字段放在双引号（""）里表示它们是同一个字段。
      • Ignore first line 若文件带表头，可让 RealityScan 忽略第一行。以 # 符号开头的行会被自动跳过。
      • Imported data accuracy 可在 Measurements accuracy 中以像素为单位定义导入控制点测量值的精度。该值表示控制点在图像中预期能达到的放置精度。
    2. 可以在应用安装目录下的 measurementsimport.xml 中自定义文件格式、其他值分隔符、注释符号或限定符。关于如何编辑 measurementsimport.xml 的说明，以及导入支持的值列表，请见此处。

    注意：只有当前项目中已导入至少一张图像时，此选项才可用。
