API 方法 —— 节点

可与 RSNode 配合使用、作用于节点自身的 API 方法。

getNodeConnectUser

把用户连接到节点。这会为当前用户预留一个剩余会话名额（直到使用 /project/create、/project/open 或 /node/disonnectuser 为止）。

GET
/node/connectuser

参数

请求头参数

名称 说明 是否必需
clientId* UUID（uuid）
客户端标识		 必需
appToken* String
调用方应用标识		 必需

响应

  • 状态：200 —— OK
  • 状态：400 —— 请求无效

结构：

apiError {
 code: integer
 message: string
}
  • 状态：401 —— 未授权

结构：

apiError {
 code: integer
 message: string
}
  • 状态：404 —— 未找到

结构：

apiError {
 code: integer
 message: string
}
  • 状态：500 —— 服务器内部错误 apiError

结构：

apiError {
 code: integer
 message: string
}

getNodeConnection

查询 RSNode 的连接信息（仅在 localhost 上可用）。返回 RSNode 的连接信息。

GET
/node/connection

参数

请求头参数

名称 说明 是否必需
clientId* UUID（uuid）
客户端标识		 必需
appToken* String
调用方应用标识		 必需

响应

  • 状态：200 —— OK

结构：

RS Node Connection Information {
 protocol: string
    Connection protocol (http or https)
 hostAddress: string
    RSNode 监听的本地 IPv4 地址
 port: string
    Port on which RSNode listens
 authToken: string
    Token to authorize with RSNode
 pairingPage: string
    URL path to pairing page
 landingPage: string
    URL path to landing page
 allAddresses: [string]
    所有本地网络适配器的 IPv4 地址
}
  • 状态：400 —— 请求无效

结构：

apiError {
 code: integer
 message: string
}
  • 状态：401 —— 未授权

结构：

apiError {
 code: integer
 message: string
}
  • 状态：403 —— 禁止访问

结构：

apiError {
 code: integer
 message: string
}
  • 状态：404 —— 未找到

结构：

apiError {
 code: integer
 message: string
}
  • 状态：500 —— 服务器内部错误 apiError

结构：

apiError {
 code: integer
 message: string
}
