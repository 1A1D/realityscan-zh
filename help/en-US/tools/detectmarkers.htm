检测标记工具

该工具可自动完成在图像中放置control points的过程，比手工寻找又快又准。导入的图像中会检测所选类型的靶标，并为每个靶标创建一个控制点。
你只需准备好合适的标记（可用我们内置的生成器），在拍照前把它们放进场景，剩下的交给 RealityScan。

什么是标记

标记是印在平面上的高对比度特殊图案，其形状使其能从任意视角被精确定位。此外，每个标记还能通过内部或附近的附加图码被唯一识别，我们把这些附加图码称为数据（data）。除识别外，数据还用于把标记与图像中的随机图案区分开。为了读取数据，工具要求标记足够大，一般建议拍摄到的标记宽度至少 100 像素。建议相机与标记之间的夹角大于 45 度（最理想是垂直于标记拍摄），并且标记不得被遮挡或以任何方式修改，这包括标记的白色背景。

提示：请记住，大场景需要大尺寸的标记。

标记类型

  • Circular, single ring 带数据环的简单圆形靶标。凭借白色中心点，可达到很高精度。
  • Circular, dual ring 带数据环与外围方向环的圆形靶标，精度与单环型相当。
  • Square, April Tag 外观类似二维码。检出率高，即在恶劣光照条件或远距离拍摄时更容易被检出。
  • Circular, legacy 该类型仅用于检出旧版 RealityScan 打印的圆形单环标记。旧版标记类型已无法再生成。

标记还有多种子类型，主要区别在于可用不同标记的数量。由于每个标记在场景中只能放置一次，应确保能生成足够多的不同标记。

操作步骤

  1. 点击 ALIGNMENT 选项卡 Constraints 区域的 Detect Markers 按钮。也可在 IMAGE 2D/TOOLS 选项卡中找到。
  2. 这些设置位于 Detect Markers Tool panel in the 1Ds panel:

    Marker type 要检测的标记类型，各种类型见上文。
    Required measurements 检出图像数少于此处设定值的新标记会被丢弃。该选项可有效滤掉出现在图像数不足的标记。
    Image layer 可选择在哪个图像图层中检测标记，按你的输入内容选择即可。
    Marker count 在此指定要生成的标记数量。可生成的标记上限由标记类型决定（见上表）。
    Markers per page 指定每页放多少个生成的标记。
    Paper size 打印标记所用纸张的尺寸。

    TIP: Set Required measurements 设为大于 1 的数值，以便更稳健地检出标记。
  3. 若想让 RealityScan 替你生成标记，选择数量、每页个数和纸张尺寸，然后点击 Generate。
  4. 若只想在一部分输入图像中检测标记，请先选中这些图像。
  5. 现在可以点击“检测标记工具”面板中的 Detect 按钮。
  6. 每个被检出的标记都会创建一个新的控制点，前提是不存在名称完全相同的控制点。

其他说明

  • 还可能在 1Ds 面板的控制点列表中得到一些控制点建议，由你确认或丢弃。
  • 名称匹配的已有控制点会补充新的测量值，其他属性全部保留。
  • 新建的控制点是连接点，因为这些点的物理位置未知。不过检测完成后可以更改控制点的类型。
  • 给 Ground control points 取一个合适的名称，再运行标记检测，就能通过标记检测定位地面控制点。
