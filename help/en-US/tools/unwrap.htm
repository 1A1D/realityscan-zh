展开工具

用这个工具在贴图前（重新）计算模型的展开。在模型算好之后想估算合理的最小分辨率时，它同样有用。该工具位于 MESH & COLOR 选项卡的 Color & Texture 区域。

  • Optimal texel size 与图像所能捕捉的最小细节相对应的纹素尺寸。
  • Gutter 表示纹理图中每个图表（chart）边界所占的像素数。留白对避免渲染时模型上出现可见瑕疵很重要：许多渲染引擎会使用 mip-mapping 这类技术，把纹理多次降采样以生成图像金字塔；若引擎从较高层级的金字塔取纹理，插值过程中一个图表的颜色就可能渗到另一个图表。只要图表之间的留白不够大，就会出现这种情况。默认值 2 在大多数渲染引擎中已足以避免此类瑕疵。
  • Minimal texture resolution 设置纹理可用的最小分辨率，可选 512x512、1024x1024、2048x2048、4096x4096、8192x8192 和 16384x16384。
  • Maximal texture resolution 设置纹理可用的最大分辨率，可选 512x512、1024x1024、2048x2048、4096x4096、8192x8192 和 16384x16384。
  • Large triangle removal threshold 指定控制大三角面如何展开的阈值。若某三角面的边长乘以该值后超过模型的平均边长，该三角面会被映射为单个纹素。例如设为 400，表示边长超过模型平均边长 400 倍的三角面会被映射到一个纹素。
  • Unwrap method 定义展开算法。Geometric 是旧的展开方法；Mosaicing based (experimental) 是新方法，产生的 UV 岛更少，但比 Geometric 方法慢。
  • Style 定义构建 UV 贴图所用的策略。关于展开风格的更多内容见此处
  • Defragment charts 启用此项后，展开时会采用 Maggiordomo、Cignoni 与 Tarini 的方法生成更大的 UV 岛（阅读更多）。
  • Calculate Unwrap 点击 Unwrap 按钮计算展开并构建 UV 贴图。
  • Grid size 设置棋盘格图案的尺寸。棋盘格有助于在贴图前于三维视图中预览模型上的接缝。
  • Fill with charts 启用此项后，在 2D 视图中把 UV 图表叠加显示在 UV 棋盘格之上。
  • Update checker 按当前设置更新 UV 棋盘格。若模型此前未做 UV 展开就贴了图（即在贴图过程中自动生成了展开），则会新建一个 UV 棋盘格。
  • Calculate Unwrap 计算 UV 展开。若模型已有展开或已有纹理图层，则会生成新的展开。
