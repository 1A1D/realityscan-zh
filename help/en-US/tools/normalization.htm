色彩校正

该功能可在对齐完成后校正/减小图片之间的颜色不一致。这类差异可能来自：使用白平衡不同的相机拍摄、曝光不同的照片、光照条件变化（一部分数据在白天采集、另一部分在暗处），或者部分照片是逆光拍摄。

  • 运行色彩归一化的按钮叫 Correct Colors，位于 MESH & COLOR 选项卡的 Color & Texture 区域。
  • 完成后，在 2D 视图中查看图像时会显示归一化后的颜色。

注意：校正后的颜色信息随项目数据一起保存，每次重新打开项目时都会加载。
The first run of this feature within a project may take longer since the data needs to be cached. In addition, you can run it as many times as you need.
若使用了多个纹理图层，将分别为它们各自创建新的归一化图层。

设置

色彩校正有两个设置项，位于 MESH & COLOR 选项卡 / Color & Texture / Settings：

  • Correct colors 设为 Yes 后，在给模型贴图/上色时会自动触发色彩校正。
  • Ignore color correction 设为 Yes 后，贴图会使用未经色彩校正的图像。

你也可以禁用某些图像使其不参与，或指定某张图片作为色彩校正的参照：

  • 禁用某张照片时（例如该图像颜色很差、会拖累结果），算法会直接忽略它——颜色不会变化，该图片也不影响最终的色变换。修改此设置的开关位于 1Ds 的 Selected input 面板 / Color normalization。
  • 被作为色彩归一化参照的照片，其自身颜色不会改变，但这张选中的照片会影响项目中其他已启用图片的色变换。当你觉得某张图片的颜色很好、希望其他图片向它靠拢时，可以这样做。要使用该设置，进入 Selected input 面板 / Color normalization reference 并设为 Enable。在同一窗口中也可以为每个所选输入分别禁用色彩归一化。

提示：若想快速查看颜色校正前后的效果，可以把图片拖到 2D or 2Ds window (for thumbnails) and, with one of these windows active, navigate to the Image Display section of the IMAGE 2D/VIEW and check or uncheck the Color corrected checkbox to see the changes.
