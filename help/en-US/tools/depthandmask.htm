地图与遮罩导出

用 MESH & COLOR 或 SCENE 3D/TOOLS 选项卡 Export 区域的 Maps and Masks 按钮导出深度图与遮罩图像。按下按钮后会弹出 Windows“另存为”窗口，可选择导出文件所在的文件夹；点击 Select Folder 按钮进入导出设置对话框。

  • File format 指定导出所用的格式。深度图导出为 EXR 格式，法线图与遮罩图像导出为 PNG 格式。
  • Export location 在 Windows“另存为”窗口中指定的文件夹路径。
  • Export Image List 启用此选项（设为 Yes）会导出一个图像清单，列出深度图与遮罩图像的文件名及其格式扩展名，并在对应输入（含完整路径）旁边列出。
  • Export Image List File Name 选择一个已有的文本文件来保存图像清单。
  • Export File Naming 选择深度图与遮罩图像的命名规则。
  • Mask and Depth Settings 调整遮罩与深度图的导出设置。
    • Export masks 启用此设置可导出由当前所选模型生成的遮罩图像。
    • Export camera depths 启用此项可导出由当前所选模型生成的深度图。
    • Distance scale 用于调整长度值以匹配不同单位的缩放系数。仅在启用相机深度导出时可用。
    • Project Distance Unit 指定输入距离所用的单位。此设置在导出对话框中固定，不可修改。
    • Near Plane Distance 设置相机与模型之间允许的最小距离。比该距离更近的区域不会生成深度图。
    • Far Plance Distance 设置相机与模型之间允许的最大距离。超出该距离的区域不会生成深度图。
  • Camera Normals Settings 调整法线图的导出设置。
    • Export camera normals 启用此设置可导出由当前所选模型生成的相机法线图。
    • Normals format 选择导出法线图的格式，可选相机空间与世界空间格式。
    • Camera-space format 依据将要使用法线图的引擎，选择相机空间法线图的格式。
    • World-space format 依据将要使用法线图的引擎，选择世界空间法线图的格式。
  • Undistortion settings Adjust the undistortion settings.
    • Undistort images Enable (set to Yes) to undistort exported images.
    • Fit 指定去畸变图像中参与输出的部分。
    • Resolution 设置图像分辨率。选 Fit 或 Preserve 会启用 Downscale 设置；选 Custom 则可设置 Custom width 与 Custom height。
    • Downscale 指定图像的降采样倍数。
    • Custom width 指定图像的自定义宽度。
    • Custom height 指定图像的自定义高度。
    • Undistort principal point 调整去畸变图像中心的位置。设为 Yes 可让光心与导出图像的实际中心对齐。
    • Image cut-out 指定用于去畸变的图像比例。
    • Max count of pixels 设置图像的最大分辨率（像素）。填 0 表示不限制。
