简化

再来看一个能让工作事半功倍的强力工具。请注意，只有在完成重建并选中模型后，Simplify 工具才会激活。它位于应用功能区的 SCENE 3D/TOOLS 选项卡中。

简化工具

该工具可减少模型三角面数量，把近似平坦的表面连通起来——例如一面由 1,000 个三角面组成的墙会被替换成等效的 2 个三角面。

  • 用这个工具减少模型三角面数，可以让模型体积更小。
  • 请注意，该工具不会修改已有的模型，而是生成一个精简后的新模型，新模型会丢失纹理、只保留颜色。可在 1D 场景视图中切换模型。
  • 点击 Simplify 工具后，其菜单会在 1Ds 窗口中出现。


  • Type 可从四种简化模式中选择：
  •  Absolute 按 Target triangle count 执行，把模型简化到指定的三角面数——推荐做法。
  •  Relative 依据 Target triangles percentage 执行，把模型简化到原模型三角面数的指定百分比。
  •  Maximum of absolute and relative 取 Absolute 与 Relative 两种方式中较大的三角面数。
  •  Minimum of absolute and relative 取 Absolute 与 Relative 两种方式中较小的三角面数。
  • Minimal edge length 受影响的边不会短于此阈值。达到目标边长时简化就停止。
  • Coordinate system 与 Unit type 按所设坐标系显示单位。此处仅供查看，数值不能修改。
  • Part merging 设为“Disable”时保留原有模型分块；设为“Enable”时，模型分块会尽可能合并成适合后续处理的较大分块（分块数量减少）；选“Create a singleton”会强制模型只有一个分块。建议仅对三角面数小于数百万的模型使用该选项。
  • Border Decimation 可选“Simplify the border”，边界也会被简化；或选“Keep border intact”，沿边界保留原模型的所有顶点。做非常极端的简化时不建议选后者。
  • Density Equalization 确保多分块模型中所有已简化分块的顶点密度一致。禁用时，各分块顶点密度可能不同，导致分块之间出现可见接缝，在 Vertices 渲染模式下最明显。启用后计算时间会变长，因此对特别大的模型可以考虑禁用。
  • Color reprojection 启用/禁用把源模型的颜色图层重投影到简化模型上。
  • Normal reprojection 启用/禁用把源模型的法线图层重投影到简化模型上。第三个选项 Automatic 表示仅在合理时才重投影法线图层。

展开参数

Maximal texture count 选择用于定义简化模型最多纹理数量的选项。可与源模型相同，也可设为自定义值。
Custom maximal count 当 Maximal texture count 选了自定义值时显示此设置。
Texture resolution 选择用于定义投影到简化模型上每张纹理分辨率的选项。可与源模型相同，也可自定义最小值与最大值。
Custom minimal resolution 当 Texture resolution 选了自定义值时显示此设置，可从预定义分辨率列表中选择纹理的最小分辨率。Custom maximal resolution 当 Texture resolution 选了自定义值时显示此设置，可从预定义分辨率列表中选择纹理的最大分辨率。

  • 设置完成后，点击面板底部的 simplify 按钮。
