地图向导

RealityScan 地图向导基本上就是你的私人虚拟助手：它引导你创建带地理配准的地图和/或模型，并且替你完成几乎所有既定处理。
整个流程非常直观、简单。随时可以在 WORKFLOW 选项卡中点击 地图向导 按钮把它调出来。不必从头到尾跟着走——你也可以在任意阶段退出向导自己继续，也随时可以再回来。

标准流程

  1. 从新建的空项目开始时，点击 地图向导 按钮后，系统会先要求你添加要处理的输入：

    • 通过 Images 按钮，可以向项目中插入单张图像或整个图像清单。
    • 通过 Image Folders 按钮，可以添加所选文件夹中的全部图像，还可选择是否包含其子文件夹。

    导入完所有图像后，你会看到已地理配准图像数、未地理配准图像数，以及传感器当前不在 camera database 中的图像数。默认会依据 EXIF 数据对图像分组（更多信息见此处）。

  2. 如果图像的 EXIF 中没有 GPS 位置，你就需要用 地理配准 来定位场景，可使用 飞行日志 or some 地面控制点 （坐标与测量值）：

    • 通过 Flight Log，可以导入含指定坐标系下相机位置的文件。
    • 通过 Ground Control，可以导入指定坐标系下的地面控制点（GCP）坐标。
    • 通过 Control Points 按钮，可以导入（地面）控制点的图像测量值。

    注意：务必选对导入文件的格式与 坐标系 （以上两项）。要用 GCP 做地理配准，需要么把 GCP 的测量值加载到多张图像中，要么把地图向导对话框最小化后手动添加测量值。
    还要注意：当同时使用图像中 WGS84 坐标系（GPS）的相机先验与另一坐标系下的 GCP 时，必须确保两者使用相同的垂直坐标系。同时使用相机先验与 GCP 时，RealityScan 会同时考虑这两组坐标。多数情况下，来自相机先验的 GPS 坐标精度低于 GCP 坐标，两组一起使用可能带来更大的误差。

  3. 所有输入成功加载后，就可以把它们显示在地图上并划定重建区域。在“校验重建区域”对话框中，所有带真实坐标的输入都会基于 OpenStreetMap 显示：

    • 可以用重建区域控件划定重建区域，用法与应用内的同名控件类似（更多信息）。可拖动 dragging 圆形控件改变区域水平尺寸，拖动 dragging 弧形控件改变其旋转。
    • 橙色方块定义要创建的正射投影（正射投影）的左上角，点击其他角上的方块即可换到那个角。
    • 要缩放地图，使用鼠标滚轮或 +/- 按钮。
    • Frame GCP 用此按钮把重建区域居中显示到窗口中间。

  4. 下一步是确定重建的目标输出。若只需要一个带地理配准的正射投影，就选 Map，然后继续定义所生成地图的最终质量。若只想创建一个带纹理的三维模型，就选 Model 选项并继续定义重建参数。你也可以两者都选。

    地图相关参数

    定义地图最终分辨率（地面采样距离）有两种方式：

    • 基于质量 正射投影的最佳分辨率会依据模型质量与已生成的 texture。在此可按所算最佳分辨率的百分比定义最终分辨率：可从下拉选项（100/50%）中选择，也可自行输入百分比数值。
    • 基于距离 在此可通过设定真实世界的像素尺寸来定义所需的地图分辨率。可从下拉菜单选择（1/5/10/50 cm/px），或输入其他以 cm/px 为单位的值。

    勾选 Save report 并选择预定义报告模板，还可以把报告导出为 HTML 文件。关于 RealityScan 报告的更多信息，点击此处。

    模型相关参数

    此窗口用于定义所生成三维网格的细节程度与纹理：

    Detail 可从以下预定义模式中选择：

    • Preview mode 生成网格非常快但细节较低。网格计算只使用空三对齐阶段算出的连接点。
    • Fast normal-detail 生成质量较低的网格。计算深度图时图像按 4 倍降采样。
    • Normal detail 生成质量尚可的网格。计算深度图时图像按 2 倍降采样。
    • High-detail mode 生成细节最高的网格，但计算可能更耗时。此模式下图像不做降采样。

    Simplify to 可从下拉菜单选择网格simplification级别（small - 10 万三角面、medium - 50 万、moderate - 100 万、large - 1000 万、10/50/100%），也可输入目标三角面数或目标百分比（后者别忘了带上 % 符号）。

    Texture 在此定义简化模型所生成纹理的质量：

    • Optimal detail 自动计算最佳纹素尺寸，用于生成 100% 质量的纹理。纹理最大分辨率设为 2048x2048。
    • 50% quality 使用 2 倍最佳纹素尺寸生成 50% 质量的纹理。纹理最大分辨率设为 2048x2048。
    • 10% quality 使用 10 倍最佳纹素尺寸生成 10% 质量的纹理。纹理最大分辨率设为 2048x2048。
    • 4K 调整纹素尺寸，以生成单张 4096x4096 分辨率的纹理。
    • 8K 调整纹素尺寸，以生成单张 8192x8192 分辨率的纹理。
    • Do not create texture 选此项则不计算纹理。
    • 也可以输入自定义纹素尺寸（cm/px），此时纹理最大分辨率会设为 2048x2048。

  5. “摘要与微调”对话框会汇总所选输出，并让你做最后的调整：

    • 你可以通过 clicking the Add Map or Add Model 按钮新增输出。对每一项输出，都可以通过 Show Execution List 按钮查看已选参数，需要时再修改。要移除某一项，请 click Remove 点击对应行中的图标。
    • 每种输出都可以用 Add Export 按钮从下拉菜单中建立导出列表。地图可导出为正射投影和数字表面模型；地图与模型都可以导出为网格，上传到 Sketchfab 或 Cesium ion，并附带报告。
    • 整套配置可用 Save 与 Load 按钮保存到文件并重新载入。
  6. 按下 GO 按钮就会启动所定义的处理流程。你可以跟踪计算进度、预计完成时间，以及当前与已完成的处理步骤。
  7. 计算完成后，可以关闭地图向导，在 1Ds 面板中查看输出结果。
