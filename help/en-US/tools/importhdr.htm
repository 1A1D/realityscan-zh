16 位与 HDR 图像

RealityScan 支持对 16 位以及 HDR 图像做完整处理。本教程将带你完成导入、用它们贴图，以及导出纹理（连同对应模型）的整个流程。

导入

要用 16 位或 HDR 图像开始项目，点击 Workflow 功能区 Inputs 区域的 16-bit/HDR images 按钮，随后会出现此窗口：

  • Tone-mapping method 选择用于对输入做tone mapping以便后续处理的编解码方式：选 No tone mapping 会使用（你机器上安装的）某个局部窗口编解码器，只把 16 位/HDR 输入转成 8 位，不做任何颜色、对比度、gamma 调整；也可以选择 RS tone mapping（推荐，针对 RealityScan 使用做了优化）。
  • Output path 指定 .geometry.jpg 文件（转换后用于后续处理的图像，下文会详细说明）的目标文件夹。可以保存在原文件旁边（With original files 选项），也可以保存到你自定义的位置（Custom 选项）。

转换

导入图像时，RealityScan 会对输入做色调映射并转成 jpg 格式。转换只为处理需要——它能加快速度，而导出的结果会包含源图像的全部 16 位或 HDR 信息。

注意：16 位/HDR 导入过程会自动把所有已导入并做过色调映射的图像（.geometry.jpg 文件）加入当前项目，无需再手动添加一次。

也可以不转换为 .base.jpg，直接处理原始 16 位或 HDR 文件，但我们仍推荐采用前面的做法（带文件转换）。具体做法是把图像直接拖放进 RealityScan 工作区，或用 Workflow 选项卡中的 Images 或 Folder 按钮开始项目，就像普通图像一样。这种情况下会出现下列窗口：



按下 Original 后，图像不会被转成 .geometry.jpg，而是以原始格式导入。

之后就可以继续常规处理（对齐与网格重建）。

在 HDR 下贴图

  1. 要开始创建 16 位/HDR 纹理，点击 MESH & COLOR 选项卡中的 Settings 按钮——位于 Color & Texture. 区域。
  2. 然后到面板最后一行，把 Prefer 16-bit/HDR textures generation 设为 Yes。
  3. 现在回到 MESH & COLOR 选项卡，点击 Texture 按钮。
  4. 会创建一个 HDR 或 16 位纹理图层（取决于导入图像的文件类型）。它会出现在 1Ds 面板中你的模型结构里——Model Textures 之下。

注意：RealityScan 中显示的纹理经过色调映射，并不代表最终纹理。

模型与纹理导出

  • 要导出模型及其 16 位/HDR 纹理，点击 MESH & COLOR 选项卡 Export 区域或 SCENE 3D/TOOLS 选项卡中的 Model & Point Cloud 按钮。
  • 在打开的“导出模型”对话框中找到 HDR Color Layer，把 Export layer 设为 Yes。
  • 选择所需的 Texture file format 与 Texture pixel format。
  • 调整其他需要的参数，然后点击 OK。
