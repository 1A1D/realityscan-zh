横断面工具

该工具会在模型中切出横断面，可按所需方向生成水平或垂直断面。

注意：要创建断面，必须先有已重建的网格模型。

使用 Cross Sections 工具前必须先选中模型。该工具位于 SCENE 3D/TOOLS 选项卡的 Tools 区域。



点击该选项后，会在 1Ds 视图中打开 Create model cross section 窗口，三维视图中则出现类似正射创建控件的小工具。在 Create model cross section 窗口中可设置各断面之间的间距，并据此算出“生成的断面数量”。



在 3D 视图中可以为该工具设置重建盒，并选择生成断面的起始方向。你还能看到断面在模型上的分布，并检查它们预先算好的位置。



设置满意后，点击 Create cross sections 即可在模型中生成断面。断面显示在 3D 视图中，并位于 1Ds 中所选模型之下。在 1Ds 视图中选中某个断面即可重命名。



可在 SCENE 3D/TOOLS 选项卡 Export 区域的 Cross Sections 按钮导出断面。随后会打开导出窗口，可选择目标文件格式（DXF 或 SHP）、为导出文件命名并选择保存位置。

选好格式后会打开 Cross Sections 导出对话框，在其中选择要导出的断面，还可设置坐标系以及场景与法线变换参数。
