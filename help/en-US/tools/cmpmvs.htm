打开文件

可以打开已有的 RealityScan 工程或文件，它们可能包含相机位姿与预先算好的去畸变图像。支持的文件格式包括 RealityScan 工程（.rsproj 与 .rcproj）、Bundler 输出文件（.out）、COLMAP 文件（.txt）以及 Gom TRITOP 测量协议格式。CMPMVS 工程也可以连同对应图像一起导入。

要打开文件，点击左上角的 RealityScan 徽标打开文件菜单，选择 Open... 调出 Open Project 窗口。也可以使用 ctrl+O 快捷键。

Open Project 窗口是一个 Windows 资源管理器窗口。必须先更改左下角的文件格式，才能导入所需的工程格式，这样资源管理器就只会显示所选格式的文件。

RealityScan 工程

要打开已有 RealityScan 工程，在 Open Project 窗口中把文件格式设为 RealityScan Project Files。之后只会显示扩展名为 .rsproj（或 .rcproj）的文件，定位到目标文件即可打开。

Bundler 输出文件

Bundler 输出文件包含由一组输入图像推导出的场景相机位姿与三维结构的关键信息，在 Bundler 执行的摄影测量重建流程中起核心作用。要导入 Bundler 输出文件，选择 Bundle out Project Files 格式，资源管理器便只会显示扩展名为 .out 的 Bundler 文件。

打开 Bundler 输出文件后，必须先运行对齐才能继续重建。此外，Bundler 文件导入还有一些限制：

  • 图像必须是 JPEG 格式。
  • 图像名称必须是数字，例如 55.jpg 或 00055.jpg，后者应始终至少 5 个字符。编号应从 0 或 1 开始，取决于你把 N-1 还是 N 视为最终索引，其中 N 是图像总数。
  • 图像被视为已去畸变。
  • 畸变模型被忽略。

COLMAP 文件

要在 RealityScan 中打开 COLMAP 文件，在 Open Project 窗口中把导入格式设为“Colmap Text Format”。这会把资源管理器过滤为只显示文本文件——其中也包括并非 COLMAP 的文件，所以请确认选对了要打开的那个。

GOM TRITOP 文件

在 GOM TRITOP 系统中创建的工程也能在 RealityScan 中打开。把 Open Project 窗口中的导入格式设为 Gom TRIPOD Measurement Protocol Files，再选择要打开的文件。

CMPMVS 工程

RealityScan 可以轻松加载并重构 CMPMVS 工程。一个 CMPMVS 工程由成对的图像与文本文件组成；假定图像已去除相机畸变，含相机位姿的文本文件以 3x4 投影矩阵形式存储。

导入 CMPMVS 工程的步骤：

  • 找到含图像的 CMPMVS 工程文件夹，即包含“image_file_name.ext”与“image_file_name_P.txt”文件的那个。
  • 把该文件夹中的图像加入 RealityScan，不要把这些文本文件一起选中。RealityScan 会自动查找关联的文本文件；若文本文件与图像在同一文件夹，系统会自动建立相机参数。
  • 对图像执行对齐。对齐过程会使用已有的相机信息，同时也会为未提供相机位姿的图像补充配准。
