图像图层

在 RealityScan 中，可以把图像分到不同图层，再在不同处理步骤中使用。例如，可以用一组图像做空三对齐与网格重建（如带投射图案的图像），用另一组图像做纹理。你不需要为每组图像分别加载项目，只需正确命名图像并一次性加载；RealityScan 会依据图像名（或文件夹名）自动识别并归入相应图层。

注意：同一张图像的所有图层必须共享相同的相机与物体位置。相机位置有差异或物体有轻微移动，都可能导致纹理模糊。

图像命名

有两种做法：重命名单个文件，或重命名整个文件夹：

  1. 重命名单个文件时，新名称由两部分构成：原本用于几何图层的文件名（含格式扩展名），加上各图层对应的扩展名。要正确分配图层，必须保持图像名一致，只额外添加正确的图层名及其格式扩展名。见下例：
    • 用于对齐与网格重建的图像：
      DSC_0001.jpg
      DSC_0002.jpg.geometry.jpg —— 这时整个文件名（含 geometry 一词）都会出现在应用的图像列表中
    • 含遮罩的图像：
      DSC_0001.jpg.mask.png
    • 用于纹理的图像：
      DSC_0001.jpg.texture.jpg
      DSC_0001.jpg.texture02.jpg
      DSC_0001.jpg.texture3.jpg
  2. 重命名整个文件夹时，所有图像必须使用相同的图像名（文件格式可以不同）。此时文件夹名由“点 + 图层名”构成，例如：
    • 用于对齐与网格重建的图像：
      …\layers\.geometry\DSC_0001.jpg
    • 含遮罩的图像：
      …\layers\.mask\DSC_0001.png
    • 用于纹理的图像：
      …\layers\.texture\DSC_0001.jpg
      …\layers\.texture02\DSC_0001.jpg
      …\layers\.texture3\DSC_0001.jpg
注意：文件夹名中的点（.）也可以换成下列符号之一：_ @ # 和 !。例如：_texture、@texture、#texture 或 !texture。.

图层命名

为便于区分各图像图层，每个图层都可以有自己的名称。命名可通过给单个文件命名，或给整个图像文件夹命名来实现。

通过给单个文件命名来定义自定义图层名

ImageName.($imgExt)($sep)($LayerDef)($optNum)($sep OR ‘’)($LayerName).($imgExt)

示例：

  • Image01.png.texture03@Third.Texture.png（名为“Third.Texture”的第三个纹理图层）
  • Image02.jpg!geometry_My Geometry.jpg（名为“My Geometry”的几何图层）

通过给整个图像文件夹命名来定义自定义图层名

($sep)($LayerDef)($optNum)($sep OR ' ')($LayerName)//Images

示例：

  • _texture02@Light texture（名为 Light texture 的第二个纹理图层）
  • .geometry!Shapes（名为 Shapes 的几何图层）

命名参数的含义：

  • ($sep) 分隔符，可为：. _ @ # !
  • ($LayerDef) 图层定义。见下文“支持的图层类型”一节。
  • ($LayerName) 将赋予相应图层的名称。
  • ($imgExt) 图像扩展名。
  • ($optNum) 可选编号。在同类型图层被导入多个时使用。

添加图像

顺便说明：

  • 对逐个命名的图像，只需把所有图像一次性加入应用（可通过 WORKFLOW 选项卡的 Images/Folder 导入，或把它们拖放进应用）。
  • 对整个重命名的文件夹，同样可用 WORKFLOW 选项卡 / Folder 导入，或把整个文件夹（及其子文件夹）拖放进应用。
  • 所有图像图层都能在“Selected input table”中看到，也可在选中某张图像后的 1Ds 视图中看到。要在 2D 视图中显示某个图层，可在 IMAGE 2D/VIEW 上下文选项卡的 Source 区域选择。


提示：可以用以下键盘键在已显示的图层之间切换： Tab (for next layer) or Shift + Tab (for previous layer).

支持的图层类型

RealityScan 可自动识别以下图层类型：

.geometry（等同于没有图层扩展名的图像/文件夹）
.mask
.labels
.depth
.textureXX
.texture（等同于 .texture1 和 .texture01）

注意：文件夹名中的点（.）也可以换成下列符号之一：_ @ # 和 !。例如：_texture、@texture、#texture 或 !texture。

如果项目中存在多个纹理图层，贴图时每一层都会被使用，并分别生成对应的纹理层。在具体模型下展开 Model Textures 后，可在 1Ds 树中显示各个颜色图层。
若项目中的图像没有加载纹理图层，贴图时将使用 Geometry 图层，并会把它与 Texture 图层关联。此外，所有图层都会做色彩校正，颜色按图层分别校正。


移除图像图层

要移除图像图层，需先打开 Inputs 面板。在 1Ds 视图中点击 Images（或 Inputs）。展开 Remove image layer 并选择要移除的图层。移除可撤销，也可重做。

Selected layer 选择要移除的图层。唯一不可移除的是 Geometry 图层，它不会出现在选择项中。
Remove selected layer 点击此按钮会从全部图像或仅从选中图像中移除图像图层。将要移除该图层的图像数量显示在 Remove 按钮后的圆括号内。
