航迹导入

航迹文件（飞行日志）记录相机位姿、朝向与内参，可用于对场景做地理配准并生成带尺度的模型。

  • 首先，确认已把项目坐标系设为相机位姿所在的坐标系。Application Settings 位于 WORKFLOW 选项卡 Application 区域下的 Coordinate systems / Project coordinate system。
  • 然后进入 WORKFLOW 选项卡，点击 Import Metadata 区域的 Trajectory 按钮。
  • 航迹文件也可以用命令行导入。

导入对话框

会立即弹出导入对话框，下面看看其中的各项选项：



  • File name 含相机航迹信息的文件名。
  • File format 指定文件中的数值及其顺序。
  • Custom format description 用可用变量定义自定义导出格式（例如 name x y z omega phi kappa）。仅当文件格式设为 Custom 时可用。
  • Euler angles order (YPR) 定义在 North-East-Down（NED）坐标系中绕 X（Roll）、Y（Pitch）、Z（Yaw）轴的旋转顺序。旋转顺序从右往左计算。
  • Euler angles order (OPK) 定义在 East-North-Up（ENU）坐标系中绕 X（Omega）、Y（Phi）、Z（Kappa）轴的旋转顺序。旋转顺序从右往左计算。
  • Camera mount 指定相机相对于其安装平台坐标系的安装方式。仅当文件格式包含 Yaw-Pitch-Roll 旋转时可用。
  • Camera coordinate system 指定坐标轴的约定。仅当文件格式包含 Omega-Phi-Kappa 旋转时可用。
  • Values separator —— 用于分隔航迹文件中各值的分隔符。也支持限定符，即可把每个字段放在双引号（""）里表示它们是同一个字段。
  • Ignore first line —— 若文件带表头，可让 RealityScan 忽略第一行。以 # 符号开头的行会被自动跳过。
  • Coordinate system —— 定义相机位置所在的坐标系
  • Automatically group camera calibration —— 可以把航迹文件中的所有相机归入同一组，也可以按焦距分组，或者不分组。
  • Accuracy settings source —— 从文件读取并编辑缺失的精度定义：从文件读取精度，缺失的在 Position Accuracy 中手动设定；全局相机先验设置：所有参数的精度在 Alignment settings. 中定义。

  • You can choose from various text file formats provided by RealityScan. Advanced users can easily define their own formats, different values separator, comment symbol or qualifiers by modifying the flightlogs.xml in the application installation folder. You can find the instructions on how to edit the flightlogs.xml as well as the list of supported values for import here.
