命令序列

除显示进度外，console 视图还可用于直接在界面中使用 CLI 命令，或创建命令序列。

在 console 视图中使用 CLI 命令与在命令提示符、.rscmd 文件或批处理文件中使用完全一样：先写一个连字符，然后写命令及其必需和/或可选参数，填入 console 视图底部的命令文本框。写完一条或多条命令后，按键盘上的 ENTER 即可执行。

如果记不清命令该怎么写，可以只写开头几个字母，然后按下键盘上的 TAB 键，在以这些字母开头的命令之间循环切换。例如在控制台的命令文本框里输入 -select 并按下 TAB 键，每按一次 TAB 都会显示一条以 -select 开头的不同命令。下图中就是这样找到了 -selectImage 命令。

写命令时会出现如上图所示的提示气泡。它会列出该命令的所有变体，以及它们必需和可选的参数（若有）。

若使用的命令带路径参数（指向电脑上文件或文件夹的路径），可以用快捷键让输入这些路径轻松许多。要搜索某个文件的路径，用 CTRL+Enter 快捷键，会打开 Windows 资源管理器，从中找到并选中需要的文件；需要文件夹路径时，用 CTRL+Shift+Enter 快捷键。

也可以用键盘上的 UP 与 DOWN 键翻阅已用过的命令。命令按时间顺序存储，用 UP 键可以从最近一次用过的开始往回访问。

添加命令按钮

在 console 视图中用过的命令可以保存为命令按钮，并从 WORKFLOW 选项卡的 Commands 区域调用。

要添加命令按钮，Commands 区域中点击 Add 按钮，会打开 console 视图且命令文本框已选中。也可以手动把某个视图改成 console 视图并点击命令文本框来选中它。在命令文本框中写入一条或多条命令，然后按下图所示按 Add 按钮创建新序列。

这会打开 Add Command Button 窗口，可为命令按钮命名。所有命令按钮都能在 WORKFLOW 选项卡的 Commands 区域找到。要运行已保存的命令序列，只需点击相应命令按钮。

要删除命令按钮，Commands 区域中点击 Remove 按钮，会打开 Remove Command Button 窗口。在下拉菜单中选中要删除的命令按钮，然后点击 OK 按钮。


注意：所有命令按钮都归属于 RealityScan 而非创建它们的项目，因此在任何 RealityScan 实例、任何项目中都能使用。
