纹理重投影

该工具可把已在 RealityScan 中创建并带纹理的模型的纹理，投影到同一component内的另一个模型上。你可以把高精度模型上生成的纹理投影到高度simplified的模型上，相比用 Texture (F9) 按钮给简化模型重新贴图，耗时大幅缩短，从而得到尽可能锐利的纹理。

当需要给大幅简化或重拓扑后的模型贴图时，这个工具尤其有用：简化后的模型会失去粗糙度、变得更平滑，尤其是在起伏不平的区域；在这些地方用原始图像重新贴图会发虚，原因是两个表面差异太大。纹理重投影工具正好解决这个问题。

操作流程

点击 SCENE 3D/TOOLS 选项卡 Model & Texture 区域的 Reproject Texture 按钮后，1Ds 面板中会出现以下菜单：

  1. 在 Source model 中选择源模型——点击面板中对应行会展开滚动菜单。该模型用于提供颜色和/或表面信息。
  2. 选择 Result model，其纹理将被写入。要求结果模型已完成展开（见 unwrap tool）。
  3. Adjust the Reprojection settings:

    Reprojection parameters

    Supersampling This option allows you to sample each quantity (i.e. color, normal or depth) multiple times, improving the quality of the result. Use it to reduce the amount of aliasing in the resulting textures. Select Off to sample each quantity once and get faster reprojection.

    Color reprojection

    该部分仅在源模型具有颜色纹理时可用。
    Source layer 用于取色的颜色纹理图层。
    Texture sampling method 选择要使用的采样方法。"Nearest sampling" 速度较快，但若未启用足够的 "Supersampling" 可能产生锯齿伪影。"Trilinear sampling"（推荐）可消除所有锯齿伪影。

    Displacement reprojection

    This option creates a special texture layer that stores the distance between the models. The resulting texture is used to create tesselation effects in external rendering software.

    Normal reprojection

    This one creates a special texture layer that stores surface direction of the source model. The resulting texture is used to create detailed lighting effects in external rendering software.

  4. 按下 Reproject 按钮，剩下的交给 RealityScan。
