渲染图像

Render image 工具可按 3Ds 视图中所见，从所选或全部相机的位姿，渲染并导出当前所选模型的图像。即使因多边形过多、GPU 性能不足而无法显示模型（只显示点云或较低细节的纹理），图像依然会正常渲染。

Render image 工具的按钮位于 WORKFLOW 选项卡的 Output 区域，既可作为按钮使用，也可作为下拉菜单使用。作为按钮时执行 From Current View 选项，渲染当前所选 3Ds 视图的图像。作为下拉菜单打开时提供两个选项：From Current View 与 From Camera Positions。From Camera Positions 选项从相机位姿渲染所选模型的图像：若未选或只选了一台相机则使用全部相机；若选中多台则只用选中的相机。

从当前视图

  • Type 定义渲染图像的布局。
    • Colored (textured) 类型是最终检查模型时的基本选择。
    • Composite colored (textured) 类型会把渲染出的带颜色或带纹理模型导出为一张图，并在其左上角以蓝色标出输入图像的预览。
    • Shaded 类型可把重建模型渲染为单色版本（不带纹理的着色版本）。
    • Composite 4-views 类型会把多个视图合成一张图：左上为以蓝色标出的输入图像，右上为带颜色或带纹理模型的顶点，左下为带颜色或带纹理的模型，右下为着色模型。
  • Resolution 选择渲染图像的目标尺寸/质量。
  • Shading type 决定法线与三角面边线的渲染方式。
    • Smooth Phong 着色，对顶点法线做插值，得到平滑的表面外观。
    • Flat Phong 着色，每个三角面使用单一法线。
    • Flat wireframe 与平面着色相同，但渲染器还会勾出三角面的边线。
  • Color type 定义渲染时的颜色来源。
    • Coloring 使用模型的逐顶点颜色，三角面的颜色由其顶点的线性组合得出。
    • Texturing 使用由输入照片计算出的纹理，三角面内填充小图像，因此比着色方式更真实。
  • Background color 定义未渲染像素的颜色。默认白色。可从预设调色板中选择，也可自定义。
  • 想看出模型由多少个分块组成，或只是想要一张颜色更丰富、更有艺术感的图，可以启用 Random part color。该设置仅对带阴影的渲染类型生效，在平滑和平面着色类型下最明显。

从相机位姿

  • File Format 关于导出文件格式的说明信息。
  • Export location 关于渲染图像存储目录的说明信息。
  • Type 定义渲染图像的布局。
    • Colored (textured) 类型是最终检查模型时的基本选择。
    • Composite colored (textured) 类型会把渲染出的带颜色或带纹理模型导出为一张图，并在其左上角以蓝色标出输入图像的预览。
    • Shaded 类型可把重建模型渲染为单色版本（不带纹理的着色版本）图像。
    • Composite 4-views 类型会把这些多次渲染合成一张图：左上为以蓝色标出的输入图像，右上为带颜色或带纹理模型的顶点，左下为带颜色或带纹理的模型，右下为着色模型。
  • Shading type 决定法线与三角面边线的渲染方式。
    • Smooth Phong 着色，对顶点法线做插值，得到平滑的表面外观。
    • Flat Phong 着色，每个三角面使用单一法线。
    • Flat wireframe 与平面着色相同，但渲染器还会勾出三角面的边线。
  • Color type 定义渲染时的颜色来源。
    • Coloring 使用模型的逐顶点颜色，三角面的颜色由其顶点的线性组合得出。
    • Texturing 使用由输入照片计算出的纹理，三角面内填充小图像，因此比着色方式更真实。
  • Background color 定义未渲染像素的颜色。默认白色。可从预设调色板中选择，也可自定义。
  • Export file naming 定义导出渲染图像的命名规则。
  • Output file format 定义导出图像的格式，可选 PNG 与 JPG。
  • Undistortion settings Adjust the undistortion settings.
    • Undistort images Enable (set to Yes) to undistort exported images.
    • Fit 指定去畸变图像中参与输出的部分。
    • Resolution 设置图像分辨率。选 Fit 或 Preserve 会启用 Downscale 设置；选 Custom 则可设置 Custom width 与 Custom height。
    • Downscale 指定图像的降采样倍数。
    • Custom width 指定图像的自定义宽度。
    • Custom height 指定图像的自定义高度。
    • Undistort principal point 调整去畸变图像中心的位置。设为 Yes 可让光心与导出图像的实际中心对齐。
    • Image cut-out 指定用于去畸变的图像比例。
    • Max count of pixels 设置图像的最大分辨率（像素）。填 0 表示不限制。
