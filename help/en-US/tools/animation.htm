动画工具

此工具可让你在 RealityScan 中直接为重建模型创建和修改动画（编辑相机路径、切换视图），并生成、播放和重新加载视频。


基本流程

  1. 使用应用的「带控制台的 1+1+1 布局」，打开 1Ds 面板、两个 3Ds 视图和 4Ds 面板，
  2. 在 3Ds 视图中显示重建好的模型，
  3. 进入 ANIMATION 4D 上下文选项卡，勾选全部 3 个选项以显示相机路径、关键帧和相机，
  4. 在 4Ds 窗口左侧菜单中展开「Animation Objects」（见下图）—— 点击「Animation Objects」左侧的加号；同时展开同一树中的「Camera」，
  5. 要指定用哪个 3Ds 窗口显示动画，点击 4Ds 面板左上角的第 2 个按钮 —— 第 6 步也可以同样操作，
  6. 在 4Ds 视图中创建关键帧（即视频时间轴上的位置），步骤如下：
    • 旋转、移动和/或缩放场景，得到动画中要用的另一个模型视角；也可以用数字小键盘快捷键快速切换到标准视图（见文末）。
    • 点击 4Ds 面板顶部的 Add a key-frame 按钮（4D 按钮的说明可看 tooltip）—— 这会在所选 3Ds 和 4Ds 视图中创建相机轨迹的起点，
    • 调整视图后再用同样方式创建另一个关键帧 —— 也可以右键时间轴上的目标位置，从右键菜单添加关键帧；或按住 Ctrl 拖动已有关键帧；还可以用 Insert 按钮添加新关键帧；最后一种方式是在三维视图中双击相机，
    • 如果两个帧叠在一起，或想移动某个帧的位置，只需在 4Ds 时间轴上把新建的帧拖动到一侧 —— 这样两个帧视图之间的相机轨迹也会相应延长，
    • 想加多少关键帧都可以 —— 注意：当滑块位于已建关键帧之间时，新关键帧会插在 4Ds 蓝色滑块线的位置；否则会附加在最后一帧之后。
  7. 在 3Ds 中按喜好修改相机路径 —— 可以沿蓝色三维路径滑动相机；双击相机后，可拖动三个圆环之一来朝对应方向旋转相机控件；要修改相机坐标，对相机轴心（显示相机三维坐标系）做同样操作；另见本教程末尾的「Selected key-frames panel」一节，
  8. 回放检查（播放动画）并反复修改，直到满意，
  9. 用 4Ds 窗口顶部菜单的最后一个按钮渲染并保存动画。

提示：取消关键帧的编组后，就可以为动画相机对象的平移、旋转和/或投影分别使用不同设置。例如想让相机沿笔直走廊前进、途中依次看向两侧时，可用 2 个关键帧定义位置（走廊起点与终点），再把相机先转向一侧、再转向另一侧。
取消关键帧编组的做法，见本页下方“动画”一节。

4D 窗口中的按钮

  • Pair Views 这些按钮（位于 4Ds 面板左上角）把当前 4D 参数应用到选中的 3Ds 视图。回放的动画会显示在配对的 3Ds 视图中。相机关键帧将从该视图添加。
  • Play/Pause 播放或暂停动画；前提是 4Ds 窗口中的蓝色滑块线位于时间轴中间 —— 若它在末尾且 Loop（见下文）已关闭则不适用。这种情况下要继续播放，把蓝线拖回起点再按播放。
  • Stop 暂停正在播放的动画并跳到 0 秒（动画起点）。
  • Loop On/Off 动画到达末尾后会重新播放。再次点击该切换按钮可停止循环。
  • Prev key-frame 跳到上一个关键帧。
  • Next key-frame 跳到下一个关键帧。
  • Add a key-frame 添加新关键帧（从配对视图）。
  • Delete the selected key-frames 删除选中的关键帧。更高级的选择方式见下文的关键帧操作。
  • Render animation 从已创建的动画渲染视频。若动画长度为零，则只渲染一帧 —— 一张图片。点击此处了解视频导出设置。

其他操作


时间轴

操作 说明
右键上下拖动 / Ctrl + 滚轮 向两侧拉伸时间轴。
左键拖动 把时间轴的蓝色滑块线拖向一侧。
Shift + 左键点击 / Shift + 拖动 在配对视图中显示该帧。
在时间轴区域右键 弹出右键菜单「Add a key-frame」（在点击位置添加相机关键帧）。
左键拖动 改变时间。
左键拖动 + Shift 改变时间并在配对视图中重放动画。
X 跳到第 X 秒（如 0.05）。
Xs 同上。
Xm 跳到第 X 分钟。
Xh 跳到第 X 小时。
XsYmZh 上面三种方式的组合 —— 跳到 Z 时 Y 分 X 秒。

动画

操作 说明
右键关键帧（时间轴中贯穿 3D、Matrix、Matrix 这几行的竖线） 弹出右键菜单：
更新关键帧（从配对视图刷新相机关键帧的值），
分组/取消分组关键帧（把多个关键帧合并为一个；或把一个关键帧拆成多个独立关键帧，例如把相机关键帧拆成平移、旋转、投影三个关键帧）。

若要把已取消分组的关键帧重新分组，需把它的各部分上下对齐成一条竖线，然后右键该竖线并左键点击「Group the key-frame」。
拖动时间轴中「Camera」行的中间部分 可整体移动动画在时间轴上的位置。
拖动时间轴中「Camera」行的边界 可缩放动画面板，并对齐到最近的时间帧。
拖动时间轴中 Camera 行的边界并按住 Shift 忽略对最近关键帧/时间的吸附。
ANIMATION 4D/Show 3D Path 勾选/取消以在三维视图中显示已创建的相机路径。
ANIMATION 4D/Show Camera 仅在动画路径可见时可用。勾选/取消以在三维视图中显示相机控件。
在 3Ds 视图中（沿蓝色三维路径线）拖动相机 以改变时间并在配对视图中显示相应帧。

关键帧

操作 说明
拖动 移动并对齐到最近的时间点。
Shift + 拖动 移动但不吸附到最近的关键帧/时间。
Ctrl + 拖动 复制选中的关键帧。
左键点击 在 4Ds 中选中关键帧，并在 1Ds 中显示其属性。
Ctrl + 左键点击 把关键帧加入选择，或从选择中移除。
Shift + 左键点击 先对第一个关键帧执行，再对最后一个关键帧执行同样操作，即可选中两者之间的全部关键帧。
在时间轴「Camera」行上左键点击 选中全部关键帧。
ANIMATION 4D/Show Keyframes 仅在动画路径可见时可用。勾选/取消以在 4Ds 视图中显示已创建的关键帧。
在 3Ds 视图中点击关键帧（相机锥体） 以选中该关键帧。
点击该关键帧 以在 3Ds 视图中显示操作控件。
在 3Ds 视图中双击相机 以添加新关键帧。新帧可能与原帧位置重叠（相当于复制），这时只需拖动它移开即可。
另外，双击相机后，三维视图中会出现朝向控件 —— 拖动 3 个圆环之一即可朝对应方向旋转；同时出现相机轴心，可修改其三维坐标。

选中关键帧面板

在 4Ds 视图中点击关键帧时，该面板会显示在 1Ds 面板中。

Time 选中关键帧的时长。重新输入该值会改变帧在时间轴上的位置。当全部关键帧都被选中时，在此输入的数字还会在 4Ds 中创建新关键帧（若尚不存在），否则会把该关键帧显示在 4Ds 中。

  • Camera position
    x/y/z 相机的三维坐标。修改这些值可调整该关键帧在 3Ds 视图中对应的相机位置。
  • Camera rotation
    Camera Rotation Type
    • Classic (yaw, pitch, roll) 偏航/俯仰/翻滚角，以度为单位。修改这些数值可调整赋给该关键帧的相机旋转，作用于 3Ds view.
    • Look at 使用以下两个附加参数：
      相机注视点 - 定义相机要对焦的点的坐标。这些值的变化可在 3Ds 视图中看到。
      相机上方向矢量 - 定义相机视图的方向，用于设定相机翻滚角，至少有一个坐标必须非零。这些值的变化可在 3Ds 视图中看到。
  • Camera projection parameters
    Focal length / zoom 透视视图下为焦距，即焦点到相机中心的距离，焦距越小视野越大；平行投影下则为缩放。
    Projection 透视或平行。

快捷键

快捷键 操作
在 3Ds 视图中按一次 0-7 配对视图：0 透视、1 平行、2 顶视、3 底视、4-7 侧视。
Space bar 播放/暂停动画。
Esc 停止动画。
Home 跳到 0.0 秒（动画起点）。
L 切换循环。
Del 删除选中的关键帧。
Insert 添加关键帧（从配对视图）。
<- 跳到上一个关键帧 / 把选中的关键帧左移 + 0.1 秒。
-> 跳到下一个关键帧 / 把选中的关键帧右移 - 0.1 秒。
+ 增加 1 秒。
- 减少 1 秒。
CTRL + 增加 0.05 秒。
CTRL - 减少 0.05 秒。
