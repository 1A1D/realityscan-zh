Cesium ion

Cesium ion 是一个健壮、可扩展且安全的三维地理空间数据平台。上传内容后，Cesium ion 会针对网页做优化与切片，在云端提供，并流式传输到任意设备。模型不必先做地理配准也能上传，因为可以先上传模型、之后再指定其大致位置。

有两种做法：

  1. 使用 WORKFLOW 选项卡 Output 区域的 Share 按钮，这会把模型直接导出到你的 Cesium ion 账号。下面的表单很简单，只需填写模型名称和描述。
  2. 导出 LOD（细节层级）再手动导入 Cesium ion 账号。进入 MESH & COLOR 选项卡或 SCENE 3D / TOOLS 选项卡，使用 Export 区域的 Level of Detail 按钮，会打开“另存为”窗口，在类型下拉菜单中可选 Cesium 3D tile（*.json）格式。导出参数的设置说明见此处。

    .json 文件导出完成后，就可以通过 Cesium ion 网站上的 Add data 按钮上传。
