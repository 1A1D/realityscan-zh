区域设置

重建区域设置可调整区域的中心坐标、尺寸与朝向。使用偏移工具，可以用相对值或绝对值在空间中移动区域。这些设置可通过 MESH & COLOR 选项卡 Reconstruction Region 区域的 Region Settings 按钮，或 SCENE 3D/TOOLS 选项卡 Scene Alignment 区域中的同一按钮打开。

可用的信息与工具：

  • Coordinate system 对所有场景都有用，既适用于局部坐标系项目，也适用于地理配准项目。
  • Center 重建区域中心在所选坐标系中的坐标。
  • Rotation 重建区域的偏航、俯仰和翻滚旋转值。
  • Size 重建区域在网格单位下的尺寸。
  • Offset Box 用相对值或绝对值偏移区域的工具。相对值相当于乘数（偏移值乘以对应的尺寸值）；绝对值（把 Use relative values 设为 'No' 时）则按网格坐标沿所选轴偏移区域。
