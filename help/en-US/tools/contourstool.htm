等高线工具

该工具会在所选正射投影上生成等高线。

使用前，先在 2D 视图中显示要生成等高线的正射投影，然后在 ORTHO 2D/TOOLS 的 Tools 区域点击 Contours 按钮启用等高线工具。



启用后会显示 Contours Tool 面板。



  • Pixel Type 可选 Altitude 或 Depth：
  • Altitude 会显示等高线的高程
  • Depth 给出的等高线表示从零起算的深度。
  • Layer 若随正射一起生成过 DSM 或 DTM，可以选择用哪一个来计算等高线的高度。
  • Units 不可修改，取自正射投影所用的坐标系。
  • Minimum 等高线的最低值，默认取自正射投影中的最小高度值。
  • Maximum 等高线的最高值，默认取自正射投影中的最大高度值。
  • 设置完成后，点击面板底部的 Compute 按钮。

显示等高线

可以在 ORTHO 2D/VIEW 选项卡的 Display 区域选择显示已生成的等高线，勾选 Contours 复选框即可。
