LOD 导出

RealityScan 允许生成模型的多个简化版本并导出。
这对许多渲染系统很有用——按观看距离选择合适的细节层级更高效。若只想导出一个最高质量的单文件，请参考 Model export 指南。

操作步骤与设置

  1. 先完成模型重建
  2. 点击 MESH & COLOR 选项卡 Export 区域或 SCENE 3D/TOOLS 选项卡中的 Level of Detail 按钮。
  3. 在文件对话框中指定文件名与目标格式
  4. 视格式不同，会显示下文所述的两个对话框之一。调整设置后点击 OK 按钮开始导出。

线性 LOD 导出对话框




选择以下格式之一时显示此对话框：obj、ply、xyz、abc、glb、fbx、dxf、dae。

  • Stopping criterion 选 Model Count 可导出精确数量的细节层级；选 Triangle Count 则持续导出细节层级，直到简化模型的三角面数小于指定值为止。
  • Model count 当 Stopping criterion 设为 Model Count 时，此项指定要导出的细节层级数量。
  • Simplification type 生成下一级细节所用的简化方法。选 Relative 按指定百分比减少三角面数；选 Absolute 则在给定区间内均匀分布三角面数。Absolute 选项仅在 Stopping criterion 设为 Model count 时可用。
  • Relative simplification factor 当 Simplification Type 设为 Relative 时，指定某级细节相对于上一级更高质量模型的三角面数比例。
  • Maximal triangles 导出的最高质量细节层级的三角面数。
  • Minimal triangles 导出的最低质量细节层级的三角面数。当 Stopping criterion 设为 Model Count 且 Simplification Type 设为 Relative 时不可用。
  • File suffix 默认情况下，每个导出文件的后缀为“_LODn”，其中 n 表示细节层级编号。要自定义后缀，请选 Custom。
  • Suffix 可输入自定义后缀，附加到每个导出文件名后面。
  • Numbering start 在此自定义导出模型的编号。默认第一个（最高质量的）模型编号为整数 0。
  • Mesh settings 在此自定义导出模型的格式专属设置。选项与 Export Model 对话框中完全相同，详情请参考 Model Export。

层级 LOD 导出对话框




选择 Cesium 3D Tiles 格式时显示此对话框。层级细节会把模型拆成质量各异的所谓“节点”层级结构。在兼容的查看器中显示时，只会加载部分节点，以在展示细节几何的同时维持渲染性能。若被导出的模型已做地理配准，其地理空间位置会被保留（见 Geo-referencing a Model）。

  • Initial simplification 可在导出前先简化模型，直接决定导出模型能达到的最大细节。
    把 Type 设为 None 可跳过初始简化；设为 Relative 按相对于原模型的比例减少三角面数；设为 Absolute 可指定具体的三角面数。
  • Iterative simplification 指定生成下一级细节所用的简化步长。目前 Type 唯一允许的取值是 Relative。
  • Export textures 控制是否导出纹理。请注意，被导出的模型必须已有纹理才能导出。要为模型计算纹理，请参考 Coloring and Texturing 中的贴图章节。
    Source Layer 选择用于贴图的纹理图层。
    Texel size 指定导出模型中可达到的最佳纹理质量；纹素尺寸越小，质量越高。
    Texture Format 选择纹理格式，可选 .webp、.jpg 或 .png。
  • Maximum node triangle count 决定模型拆分成节点的粒度。该值越小，节点层级越细。
  • Bandwidth Scale 设为小于 1 时流式加载更快但模型质量更低；设为大于 1 时加载更慢但质量更高。
  • Altitude 用于调整模型相对地形的高度。
