高级质量分析

高级质量分析选项用于分析场景中相机之间的依赖关系。有三种检查方法可用：

  • Camera relations 用此选项检查相机之间的关系。
  • Point cloud uncertainty 用于分析连接点位置的精度以及计算位置的不确定度。
  • Misalignment detection 该项目会直观提示项目中是否存在未对齐，并帮助排查。

相机关系

使用这种方式时，相机会依据彼此的连接情况和所设参数连成虚拟组件，同一虚拟组件内的相机用同一颜色标记。如果生成了多个虚拟（彩色）组件，说明这些组件之间相机的连接可能更稳定 —— 建议在这些区域补拍图像。

  • Component connectivity 与相邻相机/图像的最小连接数。若相机之间的边数达到该值，这些相机就连成一个组件（同色标记）。相机之间的边依据以下设置生成。
  • Apical angle 相邻相机/图像之间的最小张角。它由两条投影线（来自两台相机）构成，连接点位于角的顶点。数值越小越好。
  • Feature consistency 表示特征的最小一致性，定义需要「看到」该特征的相机数量。若该特征在此数量的相机/图像中可见，且相机对之间的夹角大于 Apical angle 所定义的角，则该边的 Matches count 加一。
  • Match count 在此指定图像之间期望的总连接数。只有当两台相机之间的共同特征（匹配）达到该数量时，它们才会连入同一虚拟组件。匹配是指满足 Apical angle 与 Feature consistency 条件的特征。
  • Minimal matches 在此指定两张图像之间期望的最小连接数。特征数低于该值的边完全不显示；恰好等于该值的边显示为深蓝色。
  • Maximal matches 在此指定两张图像之间期望的最大连接数，填 0 表示不限制。特征数最高的边显示为深红色。若设了具体数值，它就是两张图像间连接数的上限；颜色刻度会按最小/最大匹配重新计算。
  • Show edges 要显示的边类型：internal/external/both。内部边是虚拟组件内部的边；外部边是虚拟组件之外、连接各虚拟组件的边。选 both 可看到全部边（灰色为内部边，彩色为外部边）。
  • Analyze selection 若想把连通性分析限制在所选相机/点云范围内，设为 True。

点云不确定度

  • Uncertainty enumeration method 定义计算连接点不确定度的方法。此工具只作用于在 3D SCENE/VIEW 上下文选项卡中按 Track length 筛选后显示的点，可用滑块限定范围。方法可选 Relative 与 Absolute。
    • Relative 该方法适用于未做地理配准或未缩放的模型，此时点的精度（不确定度）是相对全部点的某个百分比来显示的。相对法可用的设置如下：
      • Reference uncertainty region percentile 是一个百分比值，定义可视为正确的点的比例。默认 70，即 70% 的连接点被视为稳定且质量良好；这些点显示为蓝色，并作为参照用于 Estimated reference uncertainty (blue) number.
      • Color palette radius 是定义点不确定度范围的乘数：Estimated reference uncertainty (blue) 乘以该数即得 Low-quality points' threshold (red)。
      • Estimated reference uncertainty (blue) 与 Low-quality points' threshold (red) 是定义颜色刻度范围的不确定度最小/最大值。不确定度低于 Estimated reference uncertainty (blue) 的点显示为深蓝（精度较高），高于 Low-quality points' threshold (red) 的点显示为深红（精度较低），其余点按上述颜色刻度着色。

    • 注意：红色点表示该区域计算出的点不确定度较高。在这些区域应补拍更多图像，以获得精度更高的连接点。红色不确定度线的方向即不确定度的方向；此时应在垂直于不确定度线的方向上补拍。
    • Absolute 该方法适用于已地理参考、已标定尺度的模型，可用场景单位定义点的不确定度。绝对法可用的设置有：
      • Minimal uncertainty size (blue) 定义色标的下界。不确定度低于该值的点都标为蓝色。例如对于以米为单位的坐标系，数值 0.01 表示连接点位置有 1 厘米的不确定度。
      • Maximal uncertainty size (red) 定义颜色刻度的上限。不确定度高于该值的点全部标红，介于其间的其余点按上述颜色刻度着色。

  • Uncertainty line multiplier 所显示不确定度线的缩放系数。值越大，3Ds 视图中的线越长、越显眼。

未对齐检测

该选项可帮你找出场景中未对齐的相机或薄弱位置。

  • Misaligned points threshold 按给定百分比给最可能未对齐的点着色。例如设为 50%，该工具会标记出 50% 最未对齐的点。
  • Misaligned camera pairs threshold 为每个未对齐相机组显示给定百分比的最未对齐相机对。例如设为 50%，该工具会为每个检测到的相机组标记 50% 最未对齐的相机关系。
  • Misalignment detector sensitivity 设置未对齐检测器的灵敏度。灵敏度越高计算越慢，但产出的数据更多。某些情况下高灵敏度会产生误报。
  • Point size multiplier 增大该值可放大显示的点，使其更易看清。
  • Display only misaligned points 仅显示被判定为未对齐的点。改为「是」会隐藏所有正确对齐的点。
  • Display only misaligned cameras 仅显示被判定为未对齐的相机。改为「是」会隐藏所有正确对齐的相机。
  • Misaligned components count 限制显示的未对齐相机组件数量，只显示该数量最差的组件。

选中「未对齐检测」后，3Ds 视图中的点会分成多种颜色：蓝色点表示正确对齐的点，红色或其他非蓝色点则是 RealityScan 判定为未对齐的点。

每一组点代表一个「未对齐组件」，它在 1Ds 视图中看不到，但与 Inspection tool 相关。据此可以通过调整控制点来校正对齐，最终得到精度更高的单一组件。

未对齐相机会以随机颜色显示在 3Ds 视图中，且比代表输入的相机更大。点击其中一个未对齐相机，会选中与它相关的相机；颜色表示精度：浅蓝色是 RealityScan 判定精度较低的，灰色则精度较好。相机之间可能连有白线，通常指向有问题的相机。
