配准导出

只要输入已完成对齐并成功创建了组件，就可以使用配准导出。Registration 导出按钮位于 ALIGNMENT 选项卡的 Export 区域，或 SCENE 3D / TOOLS 选项卡。

导出设置

选定格式（类型）、名称和位置后，在 Windows“另存为”窗口中点击 Save 按钮，即可打开导出对话框。该对话框中可用的导出设置取决于所选格式，因为每种格式需要的配置项不同。下面列出所有可用设置、其说明，以及使用这些设置的格式。

  • File format
    • 定义数据的导出类型，也就是数据的组织方式以及兼容软件读取它的方式。
    • 适用于所有格式的导出对话框。
  • File name
    • 导出文件所使用的名称。
    • 适用于除 ST Maps 之外所有格式的导出对话框。
  • Export location
    • 导出文件的目标路径，即 Windows“另存为”窗口中选择的位置。
    • 适用于所有格式的导出对话框。
  • Export transformation settings
    • 调整导出配准结果的位置、缩放与朝向。
    • 适用于以下格式：RealityScan XMPs with Image List、Boujou、Bundler v0.3、Bundler v0.3 (negative z)、COLMAP Text Format、Maya 2013 ASCII scene、Radiance Fields Transformation File、Internal/External Camera Parameters、Comma-separated position formats、Comma-separated position and rotation formats。
  • Undistort images
    • 开关是否导出去畸变图像。启用此选项（设为 Yes）会显示 Undistortion settings.
    • 适用于以下格式：RealityScan XMPs with Image List、COLMAP Text Format、OpenCV-compliant Intrinsics/Extrinsics、Radiance Field Transformation File。
  • Undistortion settings
    • 图像信息与图像会按所选去畸变设置一起导出。
    • 适用于以下格式：RealityScan XMPs with Image List、Boujou、Maya 2013 ASCII scene、Bundler v0.3、Bundler v0.3 (negative z)、COLMAP Text Format、OpenCV-compliant Intrinsics/Extrinsics、Radiance Field Transformation File、ST Maps、Undistorted images with Image List。
  • Export images
    • 开关是否在导出配准结果的同时导出图像。启用此选项（设为 Yes）会显示 Export image settings.
    • 适用于：RealityScan XMPs with Image List、Boujou、Maya 2013 ASCII scene、Bundler v0.3、Bundler v0.3 (negative z)、COLMAP Text Format、OpenCV-compliant Intrinsics/Extrinsics、Radiance Field Transformation File、Undistorted images with image list。
  • Export image settings
    • 设置导出图像的相关选项。这些设置仅在启用 Export images is enabled (set to Yes).
    • 适用于以下格式：RealityScan XMPs with Image List、Boujou、Maya 2013 ASCII scene、Bundler v0.3、Bundler v0.3 (negative z)、COLMAP Text Format、OpenCV-compliant Intrinsics/Extrinsics、Radiance Field Transformation File、Undistorted images with Image List、Original images with Image List。
  • Export image planes
    • 启用或禁用兼容 Maya 的图像平面导出。
    • 仅 Maya 2013 ASCII scene 格式支持此导出。
  • Bounding box scale
    • 选择包围盒（AABB）缩放值。该值与场景尺寸成正比，场景越大需要的值越高。
    • 适用于 Radiance Field Transformation File 导出。
  • Exported ST Map Image format
    • 选择 ST Map 图像的格式。ST Maps 会导出为 U、V 两个通道；U、V 值表示源像素的绝对位置，归一化到 0–1，其中 0 对应左下角、1 对应右上角。
    • 适用于 ST Maps 导出。
  • Export Image List
    • 启用或禁用图像清单导出。清单包含 ST Map 图像的名称，以及对应原始图像的路径、名称与格式扩展名。
    • 适用于 ST Maps 导出。
  • Export Image List File Name
    • 指定图像清单的导出文件，应为文本格式。
    • 适用于 ST Maps 导出。
  • Export File Naming
    • 指定导出 ST Map 图像的命名规则。
    • 适用于 ST Maps 导出。
The RealityScan Alignment Component, Image list, and CmpMvs_P matrices 这些导出没有专属设置项：在 Windows“另存为”窗口中选好名称、格式（类型）与位置后即会导出。

去畸变设置

设置图像与图像信息的去畸变参数。

  • Fit 定义去畸变图像中参与输出的范围。
  • Custom width 调整导出图像的宽度。默认值为原图宽度。
  • Custom height 调整导出图像的高度。默认值为原图高度。
  • Downscale 设置用于缩小图像的分母值。
  • Image cut-out 定义去畸变时使用图像的多大比例。
  • Max count of pixels 定义图像的最大分辨率（像素数）。填 0 表示不限制。

导出图像设置

自定义图像导出。

  • Image format 导出图像所用的格式。
  • Pixel format 选择导出图像的像素格式：24 位 BGR、32 位 BGRA 或 64 位 RGBA。
  • Naming convention 选择导出图像的命名规则。
  • Customize image path 启用此项（设为 Yes）即可自定义图像的导出路径。
  • Image path 自定义图像的导出路径。
  • Background color 设置导出图像的背景色。

导出变换设置

调整导出场景的位置、旋转与缩放。

  • Coordinate system 选择场景导出时使用的坐标系。
  • Scene transformation
    • Move X / Y / Z 按坐标系定义的单位（默认米）把场景沿任意方向平移。
    • Rotate X / Y / Z 定义场景绕相应坐标轴的欧氏旋转，范围为 -180 到 180 度。
    • Scale X / Y / Z 沿相应坐标轴缩放场景。
  • Normal transformation
    • Space 法向量的坐标系可设为 World、Object 或 Tangent（Mikktspace）。选 World 时，法线与点云顶点处于同一坐标系；Object 与 World 类似，只是“场景变换”中指定的旋转不会应用到法线上；Tangent（Mikktspace）选项则兼容多种第三方渲染系统。
    • Range 决定用于表示法向量的浮点值范围。若选择了非浮点的纹理像素格式，此设置无效。
    • Flip X / Y / Z coordinate 镜像法向量的方向。在某些第三方渲染系统中，可能需要翻转 Y 坐标才能正确使用导出的法线贴图。
