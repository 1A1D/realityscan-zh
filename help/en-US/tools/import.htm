模型导入

可以导入 Wavefront OBJ（.obj）、Polygon File Format（.ply）、Autodesk 文件格式（.fbx）、AutoCAD DXF（.dxf）和 Collada DAE（.dae）格式的模型。最常见的用法是把从 RealityScan 导出、经外部精修后的模型再导回来烘焙纹理，但不仅限于此。你还可以继续做后期处理、重新生成 UV、平滑或简化模型等等。模型导入数量不限，当你想在一个项目中处理多个模型时很有用。

注意：模型导入有若干限制。只有项目中已存在组件（对齐成功运行过）时才能导入模型；此外有些格式（.ply 与 .dxf）无法连 UV 贴图或纹理一起导入。

如何导入

把模型导入应用的整个过程非常直接、直观，只需注意以下几点：

  • Model 按钮位于 MESH & COLOR 选项卡的 Import 区域。
  • 点击 Model 按钮后，需要指定要导入模型的位置。请确认选对了格式，否则在 Windows 资源管理器里看不到模型文件。点击 Open 按钮确认选择。
  • 会出现 Import Model 对话框。若原模型导出时带了 .rsinfo 文件，其中的数值会用来预填所有设置。若模型的尺度、位置或朝向不同，可以调整设置后重新导入，使导入模型与源模型及相机对齐结果相匹配。


从 RealityScan 导出任何模型之前，建议同时导出一个信息文件（*.rsinfo，默认已启用）。当你把后期处理过的模型重新导回 RealityScan 做贴图或纹理重投影等后续处理时，该信息文件很有用。

RealityScan 会自动查找该信息文件；找到后用其中的信息预填新导入对话框的设置。信息文件必须与被导入模型同名，并额外带“.rsInfo”扩展名，例如 myObject.obj.rsInfo。


坐标系与贴图

  • 若导入的模型带 UV，则直接使用这些 UV。若不想用这些 UV 贴图，可用 Unwrap 工具替换。UV 坐标必须为所有三角面定义，否则文件不会被导入，并会弹出错误提示。
  • 若模型带一个或多个纹理文件，则会改用纹理文件的图像分辨率。纹理文件必须通过材质 .mtl 文件与模型关联。
  • 若模型没有纹理文件，则模型分辨率取自 MESH & COLOR / Color & Texture / Settings / Imported model default texture resolution。导入 FBX 格式模型时该设置被忽略。

提示：你可以导出模型、做重拓扑、创建 UV，再导入回来。之后对导入模型执行贴图时，会自动使用你的 UV 并计算各纹素的颜色，也就是不会再做一次展开。
