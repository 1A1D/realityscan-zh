RealityScan Node

Node 是一个系统服务，充作自定义应用与 RealityScan 之间的桥接。它提供类 REST 的 API，用于管理 RealityScan 会话、上传下载会话文件以及运行 CLI 命令。

RealityScan Node 既可从 RealityScan 启动，也可直接从 RealityScan 安装目录启动。从 RealityScan 启动：进入 WORKFLOW 选项卡的 Assistants 区域，使用 Real-time Assistance 工具，这会自动启动 RealityScan Node（可在 Windows 系统托盘中找到）。从安装目录启动：直接运行 RSNode.exe，或在命令提示符中调用它，例如：

"C:\Program Files\Epic Games\RealityScan\RSNode.exe" -hostAddress 192.168.0.74 -port 7878 -landingPage "\/static/MyApp.html"

目前只有一种认证方式：使用带 GUID 令牌的 Bearer HTTP 授权头。该令牌在打开着陆页时作为 GET 参数发送，所有 API 调用都需要它（静态 HTTP 服务器除外）。若直接连接某个节点，请注意该连接并不加密，因此应依赖私有且受保护的局域网。
