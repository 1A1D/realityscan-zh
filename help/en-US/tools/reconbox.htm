重建区域

若只想重建场景的特定部分，可以放置和/或修改重建区域；想重建整个场景则直接跳过这一步。从实用角度看，把重建限制在合理范围内是明智的，这样场景中不重要的部分完全不会被考虑，可加快模型计算。

  • 选择 MESH & COLOR 选项卡，找到 Reconstruction Region 区域。
  • 点击 Set Reconstruction Region 按钮，会自动在 3Ds 视图中创建重建区域。
  • If you open the Set Reconstruction Region 下拉菜单后，会有更多创建重建区域的选项：
    • Set Region Automatically —— 依据点云尺寸自动检测重建区域的选项（ctrl+shift+U).
    • Set Region on Grid —— 在网格上用三次左键点击创建重建区域。前两次点击确定重建区域在网格上的底面，第三次点击确定重建区域的高度。高度不必紧贴网格之上。
    • Set Region by Point Density —— 依据稀疏点云的密度创建重建区域，优先选择更密集的部分。对转台数据集或背景细节很少的数据集效果最好。
    • Set Region from Clip Box —— 此项会把 Clipping Box 转换为重建区域，但不会清空裁剪盒。
    • Set Region on Reconstruction —— 通过点击模型来创建重建区域。前两次点击确定区域的宽度，第三次确定长度，第四次确定高度。
    • Set Region from Control Points —— 若你在使用控制点，此项可基于控制点创建重建区域，并支持吸附到控制点。用三个点确定区域底面——前两点定宽度，第三点定长度；第四个点可用来确定区域高度。
    • Clear Region —— 从 3Ds 视图中清除重建区域。

若选择在网格上创建重建区域，请把鼠标移入 3Ds 视图：

  1. 点击鼠标左键确定区域底面左上角（原点）。
  2. 移动鼠标确定重建盒的底面（宽度与长度）。
  3. 点击鼠标左键确认区域底面。
  4. 移动鼠标调整区域高度。
  5. 点击鼠标左键确认区域。

用 box widget 移动、旋转或缩放区域。按住 SHIFT 可放慢 box widget 的移动速度，按住 CTRL 可按 15 度增量吸附旋转。


提示：可以旋转场景、切换视图，或在另一个视图中继续创建盒体。按 right click 可以回到上一步。拖动盒体各侧的圆点可调整盒体尺寸。

导出与导入重建区域

重建区域也可以用在其他项目中。用 SCENE 3D/TOOLS 选项卡 Export 区域的 Reconstruction Region 按钮导出重建区域；要导入到另一个项目，可用 MESH & COLOR 选项卡 Import 区域的 Reconstruction Region 按钮。
