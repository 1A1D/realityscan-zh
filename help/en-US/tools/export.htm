模型导出

导出模型前，项目中至少要有一个已创建并选中的模型，否则导出按钮不可用。当然，模型也可以在导出前先着色和/或贴纹理，这样导出时就能一并导出纹理。

注意：模型若经过简化，必须重新计算纹理，才能随模型导出纹理。
  • 要导出已准备好的模型，请点击 MESH & COLOR 选项卡或 SCENE 3D/TOOLS 选项卡 Export 区域的 Model & Point Cloud 按钮。
  • 点击导出按钮后会弹出 Windows 的「另存为」窗口。请注意文件名不能包含 Unicode 字符和/或空格，若包含会弹出提示。
    可选择的输出格式有：Wavefront（.obj）、Polygon File Format（.ply）、XYZ 点云（.xyz）、Alembic（.abc）、Binary GL Transmission Format（.glb）、立体光刻格式（.stl）、3D Manufacturing Format（.3mf）、Universal Scene Descriptor（.usd）、Universal Scene Descriptor 压缩包（.usdz）、激光点云（.ptx）、LAS 点云（.las）、可见部件列表（.partList）、仅纹理、Autodesk 文件格式（.fbx）、AutoCAD DXF（.dxf），以及 Collada DAE（.dae）。



    注意：最近使用的 5 种格式会排在导出对话框最前面。

  • 根据所选的另存类型，会出现相应的导出选项（「可见部件列表」除外，它不需要额外设置）。另请注意某些参数可能会隐藏 —— 例如导出未着色或未贴纹理的模型时，颜色/纹理相关的额外选项不会显示。

通用设置



Export an info file 设为「是」会创建一个 XML 文件（.rsinfo），其中包含内部坐标系的重要信息、与模型坐标导出所用坐标系的关系，以及导出参数。该文件在两种情况下有用：

  • 可以把这些导出参数当作 CLI 命令“-exportModel”的定义来使用：只需把生成的 .rsinfo 文件中 ModelExport 标签内的文本复制出来，粘贴到一个空的 .xml 文件里，再用这个 .xml 文件配合该命令。 here这类 .xml 文件的示例可在 本页找到。.

  • 当你需要导出模型、做后期处理、再导回同一组件时，这个文件很重要——之后你就可以给处理过的模型重新贴图。
    应用会自动查找该信息文件；找到后会用其中的信息把模型正确放置到内部坐标系中。信息文件必须与被导入模型同名，并额外带“.rsInfo”扩展名，例如 myObject.obj.rsInfo。

警告：若不使用 info 文件，导入的模型在场景中可能相对原模型和相机发生平移、旋转和缩放。

Save mesh by parts 按创建时的部件拆分导出模型，或作为单体导出。
Format version 虽然该设置对各种格式都会显示，但只有导出 .fbx 时才有意义。.fbx 的选项分 binary 和 ASCII：FBX201100、FBX201200、FBX201300、FBX201400、FBX201800、FBX201900 和 FBX202000。
File type 以 .ply 格式导出时可选择 Binary（二进制格式）或 ASCII（文本格式）。二进制格式比 ASCII 占空间更小。
Export vertex normals 法线是垂直于表面切平面的向量。例如之后按法线相对模型表面的朝向来打光时会很有用。
Export vertex colors 启用后，模型顶点会连带颜色信息一起导出。
Grayscale quality values 当模型使用网格质量值着色时可用。启用可保留质量信息的完整值域与精度。
Export materials 启用后导出内容会包含材质信息，仅适用于 .fbx 格式。
Number format 选择导出的数字格式，可选 Decimal、Scientific 和 General。Decimal 与 Scientific 最多 17 位有效数字并去掉末尾零，区别在于显示方式；General 会按哪个更短来选用 Decimal 或 Scientific。
Classification export 若选择了 .ply、.xyz 或 .las 格式，可导出在待导出模型上创建的分类。
Generate multi-scan PTX 以 .ptx 导出的模型可以导出为 multi-scan，即所有激光扫描会写入同一个文件。
Output Decimal Precision 定义 .ptx 文件中所存数值的小数位数。

纹理设置



Export textures 若要导出纹理请设为「是」，这会启用其他纹理相关设置。若模型有多张纹理，还可以选择导出其中哪些。
Embedded textures 当模型文件格式支持内嵌时出现。选「是」会把纹理嵌入模型文件，这样整个场景就是一个文件。
Export texture alpha Alpha 遮罩定义哪些像素包含纹理、哪些不包含。
导出为单个纹理文件 设为「否」时会出现三个 Tile type 选项：_u1_v1、(u,v) 和 UDIM。把多张纹理导出为单张时，会把所有（方形）纹理拼接到一张图里，处理超大模型时特别有用。另见下图。


警告：若纹理超过最大分辨率，会被缩放到适配尺寸，从而降低细节质量。

Texture maximal side 仅在 Export to single texture file 设为「是」时可用：512、1024、2048、4096、8192、16384、32768 或 65536 像素。
Use pow2 texture size 仅在导出单张纹理时可用。设为「是」后，导出纹理由若干单张纹理拼成，尺寸对齐到所选最大纹理尺寸的 2 的整数倍或约数，同时保持最终纹理为方形、面积最小，且不降低分辨率（上一条警告的情况除外）。效果见下图：

Texture file format 选择纹理导出的格式。
Texture pixel format 选择导出纹理的像素格式：24 位 BGR、32 位 BGRA 或 64 位 RGBA。
Grayscale quality values 导出带质量纹理的模型时可用。启用可保留质量信息的完整值域与精度。


注意：对 16 位与 HDR 图像，“导出模型”对话框的贴图设置中还有一些其他参数。 点击此处 了解更多详情。

导出相机设置

这些设置大多只对 .fbx 和 .abc 格式可用。



把相机作为模型部件导出 若想把相机转换成网格，设为「是」。
Export cameras 若想随模型一起导出相机的位置、朝向与焦距，设为「是」。
Undistort images 设为「是」会启用去畸变相关设置，图像信息将参照无畸变图像导出。
Export images 设为「是」会随模型导出生成该模型的组件中已配准的图像，同时启用导出图像设置。

去畸变设置

这些设置大多只对 .fbx 和 .abc 格式可用。

Fit 定义无畸变图像中用于输出的部分。
Resolution 指定图像分辨率。设为 Fit 或 Preserve 时会出现 Downscale 设置；设为 Custom 时则提供 Custom width 与 Custom height。
Undistort principal point 控制无畸变图像中心的位置。设为「是」会把图像的光学中心移到导出图像的实际中心。
Image cut-out 定义参与去畸变的图像比例。
Max count of pixels 定义图像的最大分辨率（像素）。填 0 表示不限制。

无畸变图像的更多信息见 此处。

导出图像设置

Image format 图像导出的格式。
Pixel format 选择导出图像的像素格式：24 位 BGR、32 位 BGRA 或 64 位 RGBA。
Naming convention 选择导出图像的命名规则。
Image path 图像默认导出到模型所在文件夹，可在此改为其他路径。
Background color 设置导出图像的背景色。

导出变换设置

RealityScan 允许对导出的模型进行平移和缩放，例如把单位从米换成厘米时很有用。把 Scale X/Y/Z 设为 10，模型就会放大 10 倍。



Coordinate system 选择模型导出所用的坐标系。
Transformation preset 应用预定义的场景变换与法线变换设置。
Scene transformation 调整模型的位置、朝向与缩放。
Normal transformation 调整所有导出的法线贴图。

坐标系

Grid plane - 与 3Ds 视图中看到的一致。
Project Output - 仅在模型已完成地理参考时可用。输出坐标系可在 WORKFLOW 选项卡 / Settings / Coordinate systems 中选择。
Shifted project output - 与 Project Output 相同，只是平移到场景中心。
Same as XMP – 使用与导出的元数据（XMP）相同的坐标系导出。此选项对未地理参考的模型同样可用。

场景变换

Move X / Y / Z 按坐标系定义的单位沿任意方向移动对象，默认单位为米。
Rotate X / Y / Z 定义模型绕相应坐标轴的欧拉旋转（-180 到 180 度）。
Scale X / Y / Z 通过改变默认缩放数值来缩放相应坐标轴的坐标。

法线变换

Space 法线向量所在的坐标系。选 World 时，法线与模型顶点处于同一坐标系。Object 与 World 基本相同，区别是场景变换中的旋转不会应用到法线上。Tangent（Mikktspace）选项兼容多种第三方渲染系统。导出切线空间法线贴图时，建议始终启用 Export vertex normals 以获得最佳效果。
Range 决定用法线向量表示的浮点值范围。选择非浮点的 Texture pixel format 时无效。
Flip X / Y / Z coordinate 镜像法线向量的方向。某些第三方渲染系统中需要翻转 Y 坐标才能正确使用导出的法线贴图。
