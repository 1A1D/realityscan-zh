以视频作为输入

如果你拍的视频是按摄影测量拍摄要点来的，就可以用它代替照片和/或激光扫描，或作为拍摄同一物体/场景的其他输入的补充。这类视频的数量同样不限。（你甚至可以用这个功能把任意视频切成图片序列，用于本软件之外的用途。）
RealityScan 只从视频中抽取关键帧（即任意平滑过渡的起止点），忽略内插帧（由编解码器合成、几何上不准确），尽量帮你得到想要的结果。


只要装有 Windows 原生的编解码包（无需额外安装），就能导入以下视频格式：Advanced Systems Formats（.asf）、AVI（.avi）、QuickTime（.mov）、MPEG（.mpg、.mpeg、.mp4）和 Windows Media Video（.wmv）。输出的帧为 PNG。

也可以导入 Leica BLK3D 以 .cmi 文件格式采集的图像序列。

什么是 Leica BLK3D？

它是一台手机大小的简易设备，配有两个 1000 万像素相机，可同步连续成像。由于两相机之间的相对位置与距离已知，RealityScan 能利用这类数据自动为你的模型定尺度，无需任何额外操作或输入。之后你可以在场景中量测、加入未缩放的其他输入并对齐这些数据，从而把它们一起缩放。


操作步骤

  1. 要导入一个或多个视频，可用 WORKFLOW 选项卡中的 Video 按钮，或直接把视频拖放到 RealityScan 项目中。
  2. 选好之后会进入设置对话框，需要为抽取的帧指定保存位置，以及它们的时间跨度——即 Jumps' length(s)——它定义两帧之间的间隔。导入 .cmi 格式的数据时会跳过此对话框。
  3. 点击 Import 后，视频会被拆成帧并载入应用，可在 1Ds 面板的 Images 根节点下找到。
  4. 之后就可以像平常一样继续添加其他输入，或直接对齐并做后续处理。
