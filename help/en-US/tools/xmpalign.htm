XMP 元数据文件

元数据或 XMP 文件包含图像信息，可用于替代图像的 EXIF 信息，或复用对齐配置。在搭建相机装置（相机位置不再变动）时特别有用。

  • XMP 文件与图像直接关联。若放在同一文件夹且同名，导入 RealityScan 时图像与 XMP 会作为一体处理，XMP 中的全部信息会自动赋给对应图像。
  • 图像应与其 XMP 文件同名。例如给 Image01.jpg 配 XMP，XMP 文件名应为 Image01.xmp。
  • 也可以用 CLI 命令 addImageWithCalibration 导入图像及其 XMP 文件。这种情况下两个文件不必同名，也不必放在同一文件夹。

导出 XMP 文件

可以用 XMP Files 按钮或 Export Registration 按钮导出 XMP 文件，两者都在 ALIGNMENT 选项卡的 Export 区域。

XMP Files 按钮会打开 XMP metadata export 对话框：

  • Camera export mode 指定相机位置，以及它们在后续计算中的使用方式。
    • Export as draft “草稿导出”会使用绝对相机位置，但这些位置在对齐过程中仍会被调整。
    • Export as exact 精确导出可确保相机保持相对位置，适用于必须保留相机间空间关系的场景。
    • Export as locked 锁定导出同时保留相对与绝对相机位置。与草稿导出不同，位置固定不变，对齐阶段不会调整。
  • Merge with existing XMP files 为同一批图像新建 XMP 会替换已有的 XMP。
  • Export rigging setup 启用后会导出激光扫描的装置配置信息；不启用则只导出位置与朝向。
  • Export camera calibration groups 导出标定组信息。标定组详情见 此处。
  • Include editor options 启用表示这些图像参与纹理和网格化计算。该信息可在 Selected input 面板中查看。
  • 用优化后的值替换 GPS EXIF 信息 用对齐过程中计算出的坐标替代 EXIF 坐标。

Export Registration 按钮会打开文件资源管理器。要导出 XMP，把保存类型设为 RealityScan XMPs with Image List 并按 Save，随后进入 Export Registration 对话框：

  • File name 将在导出位置创建的图像列表文件名。
  • Export location 导出文件的存放目录路径。
  • Camera export mode 指定相机位置，以及它们在后续计算中的使用方式。
    • Export as draft “草稿导出”会使用绝对相机位置，但这些位置在对齐过程中仍会被调整。
    • Export as exact 精确导出可确保相机保持相对位置，适用于必须保留相机间空间关系的场景。
    • Export as locked 锁定导出同时保留相对与绝对相机位置。与草稿导出不同，位置固定不变，对齐阶段不会调整。
  • Merge with existing XMP files 为同一批图像新建 XMP 会替换已有的 XMP。
  • Export rigging setup 启用后会导出激光扫描的装置配置信息；不启用则只导出位置与朝向。
  • Export camera calibration groups 导出标定组信息。标定组详情见 此处。
  • Include editor options 启用表示这些图像参与纹理和网格化计算。该信息可在 Selected input 面板中查看。
  • 用优化后的值替换 GPS EXIF 信息 用对齐过程中计算出的坐标替代 EXIF 坐标。
  • Undistortion settings 调整应用到 XMP 文件导出数据上的去畸变参数。
    • Undistort images 启用（设为 Yes）以导出与去畸变图像相对应的数值。
    • Fit 指定无畸变图像中纳入输出的部分。
    • Resolution 设置图像分辨率。选 Fit 或 Preserve 会启用 Downscale；选 Custom 则可设置 Custom width 与 Custom height。
    • Downscale 指定 XMP 导出中无畸变图像的降采样系数。
    • Custom width 指定 XMP 导出中无畸变图像的自定义宽度。
    • Custom height 指定 XMP 导出中无畸变图像的自定义高度。
    • Undistort principal point 调整无畸变图像中心的位置。设为 Yes 可把光学中心对齐到导出图像的实际中心。
    • Image cut-out 指定 XMP 导出中用于去畸变的图像比例。
    • Max count of pixels 设置图像的最大分辨率（像素），填 0 表示不限制。
  • Export images 启用后会连同 XMP 文件一起导出图像。
  • Export image settings 配置导出图像的设置。
    • Layer 选择要导出的图像图层（例如输入图像或贴图图层）。
    • Image format 图像导出的格式。
    • Pixel format 选择导出图像的像素格式：24 位 BGR、32 位 BGRA 或 64 位 RGBA。
    • Naming convention 选择导出图像的命名规则。
    • Customize image path 若要自定义图像的导出路径（目录），启用此设置。
    • Image path 设置图像的导出路径（目录）。
    • Background color 选择导出图像的背景色。
  • Export transformation settings 配置导出数据的变换设置。
    • Coordinate system 选择导出 XMP 元数据所使用的坐标系。
    • Scene transformation 应用变换以改变场景的位置、旋转和缩放。
    • Normal transformation 对法线向量应用变换设置。

XMP 内容

看一下 XMP 文件内容示例：

<x:xmpmeta xmlns:x="adobe:ns:meta/">
    <rdf:RDF xmlns:rdf="http://www.w3.org/1999/02/22-rdf-syntax-ns#">
        <rdf:Description xmlns:xcr="http://www.capturingreality.com/ns/xcr/1.1#" xcr:Version="3"
            xcr:PosePrior="initial" xcr:Rotation="-1 0 0 0 0 -1 0 -1 0" xcr:Coordinates="absolute"
            xcr:DistortionModel="division" xcr:DistortionCoeficients="0 0 0 0 0 0"
            xcr:FocalLength35mm="18" xcr:Skew="0" xcr:AspectRatio="1" xcr:PrincipalPointU="0"
            xcr:PrincipalPointV="0" xcr:CalibrationPrior="initial" xcr:CalibrationGroup="-1"
            xcr:DistortionGroup="-1" xcr:Rig="{1E204070-A17D-444E-9455-493C15B37B93}"
            xcr:RigInstance="{2DC9F356-432F-4234-9148-DC2655788342}" xcr:RigPoseIndex="3"
            xcr:InTexturing="1" xcr:InMeshing="1">
            <xcr:Position>0.262424475861358 -2.26397531586648 7.03879070281982</xcr:Position>
        </rdf:Description>
    </rdf:RDF>
</x:xmpmeta>

提示：可以在图像文件夹中放一个名为 _common.xmp 的文件，让其中所有图像都以相同的 XMP 信息导入。
