正射选择工具

使用这些工具前，至少要已创建一个正射投影。在 2D 视图中显示后，选中该视图并打开 ORTHO 2D/TOOLS 上下文选项卡。Shapes & Regions 面板中的工具可让你在正射投影上新建区域或形状，并选中和编辑它们。

要创建区域（形状），先按需点击 Measure、Enhance Mosaic 或 Edit shape 按钮。

  • Measure 用于创建线与形状，可据此计算位于该形状内模型的体积与表面积信息，或生成高程剖面。
  • Enhance Mosaic 想新建区域并更换这些区域在图像镶嵌中所用的图像时，用这个选项。
  • Edit region 用于帮助用户编辑已创建的多边形。选择此选项后，在正射投影上选中一个多边形，就能看到它的顶点。

创建形状

选择 Measure 或 Enhance Mosaic 选项时就会新建区域或形状。启用后可使用下列工具之一：

  • Line/Polyline 该工具可在正射投影上创建线或折线。开始画线时点击你想要作为第一个点的位置；若要创建第二个点，只需在正射投影上点击目标位置。结束时双击即可落下最后一个点。该工具在选中 Measure 选项时可用。
  • Circle 可通过以下方式创建：点击正射投影确定圆心，拖动鼠标定义半径，再点击一次即可成圆。另一种方法是用 3 次点击创建圆。
  • Rectangle 在正射投影上点击确定第一个点，按住鼠标键并拖动确定对角线；松开鼠标键即完成矩形。
  • Polygon 创建多边形时，在正射投影上点击落下第一个点，然后继续点击创建更多点。要闭合多边形，可双击落下最后一个点，或让多边形的最后一条边吸附到第一个点。
  • Freeform 可用套索创建形状。点击并拖动鼠标即可画出形状。
  • Brush 基于圆形的笔刷。点击并拖动鼠标即可画出形状。

创建好的形状/区域可在 1Ds 视图中、创建它们所用的正射投影下找到。按所选选项不同，它们会出现在 Measurements（Measure）或 Mosaicing（Enhance Mosaic）之下。

选择形状

可在 1Ds 视图中选中形状/区域，也可在 2D 视图中显示的正射投影上选中。

要选中更多形状，按住 CTRL 键并在 1Ds 视图或 2D 视图中显示的正射投影上点击这些形状。要取消选中，按住 CTRL 键在 1Ds 视图中点击要取消的形状；若想在显示的正射投影上取消，则按住 SHIFT 并点击该形状。

选中形状后，可使用以下工具：

  • Merge regions 把选中的形状合并为一个。
  • Remove regions 移除选中的形状。
  • Remove vertices 从多边形形状上移除顶点。

编辑多边形形状

只有多边形形状在创建之后还能编辑。要编辑它们，需启用 Edit shape 选项。启用后选中多边形形状即可开始编辑。

  • Select vertices by a click 此时多边形形状上应显示顶点。把鼠标移到目标顶点附近并点击它。要选中更多顶点，按住 CTRL 并点击要选的顶点；要取消选中某个顶点，按住 SHIFT 并点击它。
  • 使用形状创建工具选中顶点 可用上面提到的任一形状创建工具来选顶点。Edit Shape 启用时，选择想用的工具，按上面的说明画出一个形状，该形状内的所有顶点都会被选中。要用另一个形状继续加选，在开始画之前按住 CTRL；要用另一个形状取消选中，在开始画之前按住 SHIFT。
  • Add vertices 要新增顶点，把鼠标悬停在多边形上想加点的边上，会出现一个预览顶点，点击确认其位置。
  • Move vertices 移动顶点只需点击并拖动到目标位置，再松开鼠标键确认位置。
  • Add and move vertices 如果加了顶点但点击后没有松开鼠标，可以拖动到目标位置，再松开鼠标键放下它。
  • Remove vertices 要移除顶点，先选中它们，再使用 Remove vertices 工具。也可以用键盘上的 DELETE 键。
