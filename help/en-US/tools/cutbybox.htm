按盒裁剪

可以用重建区域来裁剪已创建的模型。使用该工具的前提是项目中至少已创建一个模型。当某个视图设为 3Ds 时，该工具会出现在 SCENE 3D/TOOLS 选项卡中。

决定裁剪前，请确认重建区域的尺寸与位置已设正确。设好后，可从 Cut Model By Box Tool 面板中选择一个选项。

Remove mesh inside the box 把模型裁剪到重建区域，并滤掉重建区域内部的三角面。
Remove mesh outside the box 把模型裁剪到重建区域，并滤掉重建区域外部的三角面。
Fill cut holes 设为 Yes 时，会填补裁剪产生的孔洞。
