自定义导入格式

部分导入格式可以按你的具体需求和偏好进行自定义。例如，当你需要导入额外信息、文件包含任意列，或数据格式不正确时，可以编辑以下导入项：控制点、地面控制点、距离定义和飞行日志。

要自定义这些导入项，需要编辑安装目录下对应的文件。若安装时未更改安装位置，可在以下路径找到： 

C:\Program Files\Epic Games\RealityScan

导入文件结构

每个导入文件的结构都相同，这让自定义变得更容易。 

<format id="" descID="" desc="Text Displayed in the Import Dialog" reader="">
    <parser allowedSeparators="" comment="" showIgnoreFirstline="" qualifiers=""> 
        <Variable index="" format=""/> 
    </parser> 
</format>
  • <format> 定义导入的参数。
    • id (optional) 唯一标识号（GUID）。
    • descID （可选） 用于语言本地化的唯一内部标识号。
    • desc 在导入对话框中显示的文件格式名称。
    • reader 文件读取器。建议沿用文件中已有格式所用的同一个读取器。
  • <parser> 定义文件的读取方式。
    • separator 用作分隔符的符号（例如逗号 "," 或空格 " "）。
    • allowedSeparators 在导入对话框中显示的分隔符列表。分隔符可由文件自动识别，也可由用户手动选择。若未定义允许的分隔符，则使用 separator 参数中指定的符号。
    • comment 用于标识文件中注释的符号。该符号之后同行内的所有文本都会被忽略。
    • showIgnoreFirstline 设为 true 或 false，决定是否在导入对话框中显示“忽略第一行”选项。设为 true 时该选项会显示。
    • qualifier 可包裹数值的符号，例如双引号。当数值中可能出现与分隔符相同的字符时很有用。建议沿用文件中已有格式所用的同一组符号。
  • <Variable> 导入值的类型。可用变量取决于所选 reader；控制点、地面控制点、距离定义与飞行日志各自可用的变量清单，见下文对应段落。
    • index 定义存放该值的列号，从 0 开始计数。可以用它跳过不需要的列。
    • format 导入值的数据类型。支持的类型有：value —— 精确数值；degrees —— 以度为单位的值（例如 GPS 值 N65 23 12.1）；name —— 字符串（例如控制点名称）；name.ext —— 含扩展名的文件路径与名称（例如 IMG_0001.jpg）。

距离定义

修改 "distancedefinitions.xml" 文件即可自定义距离定义的导入。作为 reader 使用 "RealityScan.Import.CsvDistanceDefinition"。

示例文件格式：

<format id="{08192FC0-A5D9-4E99-B993-F274EFA5745F}" descID="8413" desc="Name, Point A, Point B, Distance, Accuracy (character-separated)" reader="RealityScan.Import.CsvDistanceDefinition">
    <parser allowedSeparators=",; &tab;" comment="#" showIgnoreFirstline="true" qualifiers="&quot;optional" >
        <Name index="0"/>
        <PointA index="1"/>
        <PointB index="2"/>
        <Distance index="3"/>
        <DistanceAccuracy index="4"/>
    </parser>
</format>

可用变量：

  • Name 距离约束的名称。
  • PointA 定义该距离约束的第一个点的名称。
  • PointB 定义该距离约束的第二个点的名称。
  • Distance 距离约束的长度。
  • DistanceAccuracy 所定义距离的先验精度。

控制点

修改 "measurementsimport.xml" 文件即可自定义控制点的导入。作为 reader 使用 "RealityScan.Import.CSVControlPointsMeasurements"。

示例文件格式：

<format id="{FDB5E38A-823C-446A-B144-6D33B2172D8A}" descID="8388" desc="Image, Point, X, Y (character-separated)" reader="RealityScan.Import.CSVControlPointsMeasurements">
    <parser allowedSeparators=",; &tab;" comment="#" showIgnoreFirstline="true" qualifiers="&quot;optional" >
        <Image index="0" format="name" />
        <PointName index="1" />
        <X index="2" />
        <Y index="3" />
    </parser>
</format>

可用变量：

  • Image 图像名称，含路径与格式扩展名。
  • PointName 控制点名称。
  • X 控制点在图像中沿 X 轴的位置，以距图像左上角的像素数计。
  • Y 控制点在图像中沿 Y 轴的位置，以距图像左上角的像素数计。
  • XAccuracy X 轴方向的位置精度。
  • YAccuracy Y 轴方向的位置精度。
  • RotationAccuracy 精度区域相对 X 轴的旋转角，左手坐标系。

地面控制点

修改 "groundcontrol.xml" 文件即可自定义控制点的导入。作为 reader 使用 "RealityScan.Import.CSVGroundControl"。

示例文件格式：

<format id="{28626CC0-6311-41FD-88EE-988A673A5CB8}" descID="8406" desc="Name, X (East), Y (North), Alt, X Accuracy, Y Accuracy, Alt Accuracy (character-separated)" reader="RealityScan.Import.CSVGroundControl">
    <parser allowedSeparators=",; &tab;" comment="#;" showIgnoreFirstline="true" qualifiers="&quot;optional">
        <Name index="0" format="name"/>
        <X index="1" format="value"/>
        <Y index="2" format="value"/>
        <Altitude index="3" format="value"/>
        <XAccuracy index="4" format="value"/>
        <YAccuracy index="5" format="value"/>
        <AltitudeAccuracy index="6" format="value"/>
    </parser>
</format>

可用变量：

  • Name 地面控制点的名称。
  • Longitude 地面控制点的经度坐标。
  • LongitudeAccuracy 经度坐标的位置精度。
  • X 地面控制点的 X 坐标。
  • XAccuracy X 坐标的位置精度。
  • Latitude 地面控制点的纬度坐标。
  • LatitudeAccuracy 纬度坐标的位置精度。
  • Y 地面控制点的 Y 坐标。
  • YAccuracy Y 坐标的位置精度。
  • Altitude 地面控制点的高程（Z）坐标。
  • AltitudeAccuracy 高程（Z）坐标的位置精度。

飞行日志

修改 "flightlogs.xml" 文件即可自定义控制点的导入。作为 reader 使用 "RealityScan.Import.CSVFlightLog"。

示例文件格式：

<format id="{97F08A22-F231-4AB4-A2FD-6FA42BB6D663}" descID="8436" desc="Name, X (East), Y (North), Alt, X Accuracy, Y Accuracy, Alt Accuracy, Yaw, Pitch, Roll (character-separated)" reader="RealityScan.Import.CSVFlightLog">
    <parser allowedSeparators=",; &tab;" comment="#" showIgnoreFirstline="true" qualifiers="&quot;optional" >
        <Image index="0" format="name.ext"/>
        <X index="1" format="value"/>
        <Y index="2" format="value"/>
        <Altitude index="3" format="value"/>
        <XAccuracy index="4" format="value"/>
        <YAccuracy index="5" format="value"/>
        <AltitudeAccuracy index="6" format="value"/>
        <Yaw index="7" format="value"/>
        <Pitch index="8" format="value"/>
        <Roll index="9" format="value"/>
    </parser>
</format>

可用变量：

  • Image 图像名称，含完整路径与格式扩展名。
  • Longitude 相机位置的经度坐标。
  • LongitudeAccuracy 经度坐标的位置精度。
  • X 相机位置的 X 坐标。
  • XAccuracy X 坐标的位置精度。
  • Latitude 相机位置的纬度坐标。
  • LatitudeAccuracy 纬度坐标的位置精度。
  • Y 相机位置的 Y 坐标。
  • YAccuracy Y 坐标的位置精度。
  • Altitude 相机位置的高程（Z）坐标。
  • AltitudeAccuracy 高程（Z）坐标的位置精度。

  • Yaw 偏航角先验（绕 Y 轴）。
  • YawAccuracy 偏航角先验精度。
  • Omega omega 旋转先验（仅用于地理配准场景）。
  • OmegaAccuracy omega 旋转先验精度。
  • Pitch 俯仰角先验（绕 X 轴）。
  • PitchAccuracy 俯仰角先验精度。
  • Phi phi 旋转先验（仅用于地理配准场景）。
  • PhiAccuracy phi 旋转先验精度。
  • Roll 翻滚角先验（绕 Z 轴）。
  • RollAccuracy 翻滚角先验精度。
  • Kappa kappa 旋转先验（仅用于地理配准场景）。
  • KappaAccuracy kappa 旋转先验精度。

  • FocalLength 焦距（先验标定值）。
  • PrincipalU 主点 x（先验标定值）。
  • PrincipalV 主点 y（先验标定值）。
  • Skew 相机斜切系数（先验标定值）。
  • AspectRatio 相机宽高比校正系数（先验标定值）。
  • RadialDistortion1 畸变模型第一径向系数（先验镜头畸变）。
  • RadialDistortion2 畸变模型第二径向系数（先验镜头畸变）。
  • RadialDistortion3 畸变模型第三径向系数（先验镜头畸变）。
  • RadialDistortion4 畸变模型第四径向系数（先验镜头畸变）。
  • TangentialDistortion1 畸变模型第一切向系数（先验镜头畸变）。
  • TangentialDistortion2 畸变模型第二切向系数（先验镜头畸变）。
