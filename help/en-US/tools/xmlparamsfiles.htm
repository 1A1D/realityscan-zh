正射投影的参数文件

用 -calculateOrthoProjection 命令创建正射投影时，会用扩展名为 .rsortho 的参数文件来定义渲染正射投影的参数。下面详细看一下它的内容。

用于计算正射投影的 *.rsortho

使用 -calculateOrthoProjection 命令时，应用会从指定的 params.rsortho 文件加载参数。要得到格式正确的该文件，可以手动创建一个正射投影，导出为任意格式，并在导出时把 exportProjectionParametersFile 设为 True。
下面是用于计算正射投影的 .rsortho 文件内容示例： 

<OrthoProjection width="10011" height="8076" name="Ortho projection 1" modelName="Model 1"
    colorType="texturing" boxSideConerIndex="13" bEmpty="0" backFaceColorType="1" backFaceColor="2130706687">
    <Header magic="5787472" version="1"/>
</OrthoProjection>
<ReconstructionRegion globalCoordinateSystem="NONE" globalCoordinateSystemName="NONE" isGeoreferenced="0"
    isLatLon="0" yawPitchRoll="0 -0 -0">
    <widthHeightDepth>29.8926887512207 29.9313926696777 24.1154346466064</widthHeightDepth>
    <Header magic="5395016" version="2"/>
    <CentreEuclid>
        <centre>-0.098011314868927 0.0846212208271027 12.4095182418823</centre>
    </CentreEuclid>
    <Residual R="1 0 0 0 1 0 0 0 1" t="0 0 0" s="1"/>
</ReconstructionRegion>
<DTMParams classificationLayerId="-1">
  <ClassificationParams modelType="nature" postprocessType="soft_edges" sensitivity="0.5"/>
  <Header magic="1480868688" version="1"/>
</DTMParams>

要得到格式正确的该文件，可以手动创建一个正射投影，导出为任意格式，并在导出时把 exportProjectionParametersFile 设为 True。
文件的第一部分给出创建投影所需的参数。

参数：

  • width/height —— 投影的宽度/高度
  • name —— 投影的名称
  • modelName —— 要为其计算投影的模型名称
  • boxSideConerIndex —— 0 到 23 的数字；它决定重建区域的哪一面作为投影平面、哪个角作为最终投影的左上角；该数字并非固定值，取决于重建区域的旋转；获取该数字最好的办法是先手动创建一个正射投影，并连投影参数文件一起导出；之后再创建投影时，沿用该 boxSideConerIndex 值即可。
  • colorType —— 可选值：texturing、coloring
  • bEmpty —— 可选值：0 —— 会计算正射投影，等同于在正射投影工具设置中按下 Render 按钮；1 —— 不计算投影，等同于按下 Add to batch 按钮。建议保持为 0。
  • backFaceColorType —— 可选值：0 —— None —— 模型投影的内部与外部颜色相同；1 —— FixedColor —— 模型投影的内部与外部颜色不同，颜色由 backFaceColor 定义。
  • backFaceColor —— 模型内部部分的颜色

第二部分描述重建区域的参数，其中一面即投影平面。这部分可通过手动设置重建区域后将其导出来获得。

第三部分（位于“DTMParams”标签之间）包含创建数字地形模型（DTM）所需的参数。

参数：

  • classificationLayerId —— 用于生成 DTM 的分类图层 ID。“-1”表示渲染时计算一个新分类，此时用户还需定义 ClassificationParams（见下文）。
  • modelType —— 依据场景性质设定的分类类型。可选值："industrial_complex"、"mixed"、"city"、"nature"、"meadows"、"countryside"、"mountains"。
  • postprocessType —— 分类后执行清理模型的后期处理器类型。可选值："none"、"soft_edges"、"hard_edges"。
  • sensitivity —— 0 到 1 之间的值。设为 0 时全部归为 "Artificial object"，设为 1 时全部归为 "Ground"。
