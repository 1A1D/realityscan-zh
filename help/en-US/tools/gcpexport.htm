地面控制点导出

在 RealityScan 中，你可以很方便地导入和导出地面控制点（GCP）。本页介绍如何把地面控制点导出为文本文件。

  • 注意：RealityScan 只导出所选的控制点。要导出全部地面控制点，请不要选中任何控制点。
  • 进入 ALIGNMENT / Export / Ground Control。
  • 填写文件名并选择文件类型。
  • 点击 Save 按钮，会弹出“导出地面控制点”对话框（见下图）。
  • 在设置面板中选择导出的coordinate system。

  • 点击 OK 导出。

注意：只有项目中至少存在一个控制点时，此选项才可用。
  • 地面控制点也可以用命令行导出。

导出设置

  • File Format:
    RealityScan 支持多种不同类型的 csv 文件。导出文件格式的完整列表存放并定义于 controlpoints.xml as simple scripts. Advanced users can easily modify or create their own format. To export measurements of control points, use the $ExportControlPoints(...) function and inside the brackets put everything which should be printed for each measurement.
    The expansion system will automatically substitute variables/terms inside the brackets starting with a dollar sign ($). Everything else will be left untouched like it is, including new lines.

    Example script:
    $ExportControlPoints($If( isGroundControl,$(name), $(alt:g)
    ))

    上述脚本将导出类型为 'Ground control' 或 'Ground test' 的每个控制点的名称与高程。
    输出示例如下：

    gcp0, 1345.21
    gcp1, 964.36
    gcp2, 1512.24

    Supported tokens:

    Token Description Type
    index Index of a control point Integer
    name Name of the control point String
    x X - 地面控制点坐标 Double
    y Y - 地面控制点坐标 Double
    z Z - 地面控制点坐标 Double
    lat 地面控制点的纬度 Double
    lon 地面控制点的经度 Double
    alt 地面控制点的高程（与 z 相同） Double
    isGroundControl 控制点类型为 'Ground control' 或 'Ground test' 时为 True Boolean
  • Coordinate system:
    每个地面控制点都有自己的 coordinate system and the exporter transforms coordinates from this coordinate system to the one selected in the panel of export settings.

    Supported coordinate systems are:
    • Grid plane What you see in the 3D view.
    • Project output 该坐标系在 Application Settings 的 Coordinate Systems 中定义。要打开应用设置，进入 workflow 选项卡 / Settings。
    • Shifted project output 与上一项相同，但会沿指定方向偏移。
