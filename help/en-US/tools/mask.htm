遮罩图像

遮罩可让你把图像的特定区域排除在处理之外，例如窗户、水面、天空、阴影、植被或图像噪点。从多个角度或方向扫描物体时尤其有用，能通过剔除不需要的图像数据来提高重建的准确性与一致性。使用遮罩还有助于在重建过程中滤掉不需要的几何，使模型更干净，减少后续用过滤工具做大量处理的需要。

遮罩提供了一种非破坏性的方式来排除图像的部分内容。它既可以是单独的灰度图像（如 PNG 文件），也可以嵌在原图的 alpha 通道中（如 TIFF 文件）。遮罩中白色区域参与处理，黑色区域被排除。虽然可以使用多达 256 级的灰度（或部分透明），但不建议这样做，因为它们可能干扰处理、导致结果不一致。

生成遮罩

使用 AI Masking 工具甚至可以在对齐之前生成遮罩图像；模型创建之后也可以用 Masking from Mesh 工具生成。两个选项都在 Mask Images 下拉菜单中，该菜单位于 ALIGNMENT 选项卡的 Process 区域。

  • AI Masking 自动识别背景并分离出图像中的目标物体。对转台拍摄或背景特征很少的环境最为理想。
  • Masking from Mesh 依据场景中相机所见的重建网格生成遮罩图像。网格之外的区域会被遮掉，在后续处理中被忽略。

导入遮罩图像

遮罩图像在导入时必须遵循与图像图层相同的命名规则。具体采用哪种命名约定，取决于是逐个导入文件，还是从文件夹整体加载所有遮罩图像。若图像是用 AI Masking 或 Masking from Mesh 工具生成的，则无需如此，它们会被自动加入项目。

导出选项

用 AI Masking 或 Masking from Mesh 工具生成遮罩后，可以从这些工具所在的下拉菜单中导出遮罩。同一导出选项也可用来保存手动导入的遮罩。

也可以用 Maps and Masks 按钮自动生成并导出遮罩，该按钮位于 MESH & COLOR 选项卡的 Export 区域，或 SCENE 3D/TOOLS 之下。这些遮罩与 Masking from Mesh 生成遮罩的方式相同，都是由网格生成，但不会加入项目，而是与深度图一起直接导出。深度图存储相机与可见表面之间的距离信息，有助于确定插入物体的哪些部分是可见的。遮罩保存为 PNG 文件，深度图保存为 EXR 文件。
在 Export Depth Maps and Masks 对话框中，可以选择导出网格遮罩、深度图，或两者都导出。关于对话框中去畸变设置的更多信息，见 Undistorted Images。

可视化遮罩

要查看遮罩，在 2D 视图中打开目标图像，进入 Image 2D/VIEW 选项卡，在功能区的 Source 区域把 Input Layer 设为 Mask。若所选图像没有遮罩图层，该选项会置灰。

若 2D 视图中显示的图像被分配了多个图像图层，可用键盘上的 TAB 键在它们之间切换。

使用遮罩图像

至少选中一个输入时会显示 Selected input 面板。在 Image layers 区域可以看到分配给所选图像的所有图层，若有遮罩图层也会一并列出。对遮罩图层，可以通过修改相应设置来决定它在对齐、网格重建或贴图过程中是否生效。
