上色与贴图

模型建好后，就可以给它上色了：可以用Colorize (F8) 或 Texture (F9) 功能。理解两者的区别很重要：上色只给模型的顶点赋颜色，对较稠密的物体效果就不错，而且相比带纹理的模型体积更小；简单说，贴图是为模型的每个三角面生成一张小图像，实际会生成一张或多张称为纹理的图像，并定义它们与三角面之间的映射——这个映射就叫展开（unwrap）。因此贴图比上色更真实。

上色

在 WORKFLOW 或 MESH & COLOR 选项卡 Process 区域中点击 Colorize (F8) 按钮后即对模型上色。

  • 请注意，这不会创建新模型，只会为原模型着色。渲染着色图像后，仍可看到模型的未着色版本。

贴图

贴图包含两步：(i) 展开；(ii) 计算纹理图像的颜色。可以在 WORKFLOW 或 MESH & COLOR 选项卡 Process 区域中点击 Texture (F9) 按钮来计算模型纹理。

  • 若模型此前未贴纹理，则会按默认参数自动计算 UV 展开（本教程后面会介绍这些参数）。

  • 若模型已贴纹理，则只计算纹理图像的颜色，即沿用已有的 UV 展开。

  • 若要重新计算 / 创建模型的 UV 展开，可使用 Unwrap tool.


WARNING: The Simplify tool creates a new reduced model which loses its texture and keeps only the coloring.

使用哪些输入？

当某张图像在组件下 Camera poses 列表中的 Tx 标记背后有浅灰底色时，该图像会参与贴图/上色。点击 Tx 按钮即可禁用(D)该图像的贴图/上色，Tx 背后的浅灰底色会消失；再次点击 Tx 可重新启用(E)。



也可以多选图像/相机，在组件的面板中启用(E)/禁用(D)贴图/上色。
