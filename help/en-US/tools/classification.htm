网格分类

分类就是把模型的顶点划分到不同类别中。这一步是生成数字地形模型（DTM）的必要前提，而 DTM 可在生成正射投影时一并创建。分类工具位于 SCENE 3D/TOOLS 选项卡的 Tools 区域。选择 Classification 工具后，会出现 Classification Tool 面板：

  • Type of classificator 依据待分类场景的性质选择分类器类型。
  • Type of postprocessor 设置分类完成后用于清理模型的后期处理器类型。多数情况下选 Soft edges 就足够。
  • Postprocessor sensitivity 该值仅在后期处理器类型不是“None”时可设，取值范围 0 到 1。设为 0 时全部归为“Artificial object”，设为 1 时全部归为 Ground 类。
  • Classify model 按上述设置执行分类。
  • Transfer labels from images 也可以把标签层图像直接转移到网格顶点上来完成分类。

选中的分类

创建好的分类可在 1Ds 视图中被分类的模型下、Model Classes 内找到。选中创建的分类和/或其下的类之后，可在 Selected Classification 表格中看到更多细节。

  • Classification name 所创建分类的名称，可在此重命名。
  • Format name 所创建类的类型。使用 AI 工具时，格式名为 DTM，含预定义类别——Ground、Artificial Object、None 和 Ignored。从图像转移标签时，可以自定义格式与自己的类别。
  • Class Name 所选分类中该类的名称。
  • Classification Color 用于表示该类的颜色示例，以及对应的十六进制色码。
  • Select Classification 选中模型中归属于所选类的全部部分。

编辑分类

分类可以手动编辑：在 1Ds 视图里目标分类下点击想编辑的类，再选择要重新分配到其他图层的模型部分（例如用 SCENE 3D/TOOLS 选项卡 Model & Texture 区域的 Lasso 工具）。选择完成后会出现 Override classification 按钮；覆盖所选部分后，它就会被重新分配到该分类的目标图层。

分类也可以自动重做：选中要编辑的模型部分，用不同设置重新运行分类。当模型中存在不同类型的地形时，这种方法很好用。
分类完成并确认某些部分可用不同设置改善后，打开 Classification 工具，修改设置，然后选择 Classify selection according to settings，RealityScan 会重新分类所选部分。

转移分类

可以用此前标注的标签层图像或 LiDAR 类别来给模型分类。你可以把图像中的对象按颜色划分为不同类别，也可以把已有的 ASPRS LiDAR 类别（如地面、植被、建筑）转移过来，生成新的模型分类。每个数据集最多可使用 250 个类别。

用标签层图像创建新分类并不要求每张图像都已标注，只要覆盖了所有需要区分和分类的区域，少量已标注图像就足够。关于图像图层的更多内容，请见此处。

导入标签层图像或自带分类的 LiDAR 扫描后，先创建模型，SCENE 3D/TOOLS 选项卡中的 Classification 工具才可用。点击该按钮打开 Classification Tool 面板，其中提供 Transfer labels from images 子面板。

  • Classification format 定义新转移分类的格式，其中每个类由一种颜色和一个指定名称表示。若选择已有格式，该格式中的名称会按颜色匹配应用到新分类。要把 LiDAR 分类转移到模型上，请把此选项设为 LAS ASPRS Classification。
  • Label layer validator 检查标签层图像的有效性。仅在标签层图像已正确导入时可用。
  • Optimize resulting classes 使用内置优化算法，依据模型结构对生成的分类做微调。
  • Transfer labels from images 从标签层图像转移标签；若选择了 LAS ASPRS Classification 分类格式，则从 LiDAR 分类转移。
  • Import classification format 导入此前导出的分类格式。
  • Export classification format 导出当前选中的分类格式。

创建好的分类会出现在 1Ds 视图中所分类的模型下、Model Classes 内。选中某个具体的类后，可在 Selected Class 面板中查看更多细节。

  • Class name 所选分类中该类的名称，可在此重命名。
  • Classification Color 用于表示该类的颜色示例，以及对应的十六进制色码。
  • Select Classification 选中模型中归属于所选类的全部部分。
  • Use as ground for DTM 计算数字地形模型时把该类视为“Ground”。
  • Export class LAS 设置导出为 LAS 格式时使用的分类代码。分类代码由美国摄影测量与遥感学会（ASPRS）为 LAS 1.3 格式定义（更多信息见此处）。

可以像编辑 RealityScan 中创建的任何其他分类那样编辑这些类，请参考上文“编辑分类”一节。
