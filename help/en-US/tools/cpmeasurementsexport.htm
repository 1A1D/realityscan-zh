控制点测量导出

若你已在图像中放置control points，可以很方便地把它们的位置导出为文件。

  • 注意：RealityScan 只导出所选控制点的测量值（至少选中 2 个）。要导出全部测量值，请不要选中任何控制点。
  • 进入 ALIGNMENT / Export / Control Points。
  • 填写文件名并选择文件类型：

  • 点击 Save 导出。

注意：只有项目中至少存在一个控制点时，此选项才可用。
  • 控制点测量值也可以用命令行导出。

文件格式

  • RealityScan 支持 3 种与我们的导入兼容的基本导出格式：逗号分隔、空格分隔和制表符分隔的 csv 文件。
  • 导出格式清单保存在 measurementsexport.xml 中，其中所有格式都以简单脚本的形式定义。

    注意：最近使用的 5 种格式会优先显示在导出对话框窗口顶部。
  • 高级用户可通过我们的 API 轻松修改现有格式或创建自己的格式。
    To export measurements of control points, use the $ExportControlPointsMeasurements(...) function and inside the brackets put everything which should be printed for each measurement.
    The expansion system will automatically substitute variables/terms inside the brackets starting with a dollar sign ($). Everything else will be left untouched like it is, including new lines.

    An example script:

    $ExportControlPointsMeasurements($(imagePath)$(imageName)$(imageExt), Point$(pointIndex + 1), $(x:g), $(y:g)
    )

    上述脚本的输出示例：

    Z:\Dataset\DSC_0010.JPG, Point1, 2906.45, 1345.21
    Z:\Dataset\DSC_0011.JPG, Point1, 2632.51, 964.36
    Z:\Dataset\DSC_0011.JPG, Point3, 2786.19, 1512.24

    Supported tokens:


    Token Description Type
    measurementIndex Index of a measurement Integer
    imageIndex 含测量值的影像索引 Integer
    imagePath 含测量值影像所在文件夹的路径 String
    imageName 含测量值影像的名称（不含扩展名） String
    imageExt Extension of an image String
    pointIndex Index of a control point Integer
    pointName Name of the control point String
    x X - 该点相对左上角的坐标（像素） Double
    y Y - 该点相对左上角的坐标（像素） Double
