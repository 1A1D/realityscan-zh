创建与放置控制点

RealityScan 支持多种创建控制点的方式：在 2D 或 3Ds 视图中用控制点工具创建；从 1Ds 视图把控制点拖放到 2D 视图（起点是 1Ds 视图）；或直接导入控制点。

在 2D 图像视图中添加一个或多个控制点：

  • 要启用该工具，点击 ALIGNMENT 选项卡中的 Add Control Points 按钮；也可以按键盘上的 F3 键。
  • 要指定控制点，只需在图像中点击并按住鼠标左键不放。系统会自动创建控制点并放大，便于微调位置。微调时可在按住左键的同时滚动 鼠标滚轮来改变缩放。松开左键即放置并确认控制点，或右键取消放置。控制点编辑器会自动创建并选中该点。若你在另一张图像中点击，会在那张图像中创建对应的连接点，并把两点关联起来。
  • 应用会把所有显示同一点的视图一起放大，因此你可以借助其他视图更精准地放置。
  • 任何时候都可以按住鼠标左键来调整控制点位置，应用会进入微调模式并放大视图。
  • 应用总是把新建的点与当前选中的点关联起来。若想新建一个独立的控制点（而不是关联点，例如建筑另一个角上的点），你有几种做法：
    1. 在同一张图像中放置新的控制点
    2. 用鼠标右键取消选中当前控制点
    3. 点击其他控制点即可切换选中 —— 可在应用视图或 1Ds 视图中操作

TIP: Use a left/right arrow to switch among images in the 2D 视图。只要图像是绕物体依次拍摄的，这就是在其他图像中放置同一控制点最简便的方式。若先多选了图像，那么按 left/right arrow 就只在选中的图像之间切换。

在 3Ds 视图中添加控制点：

  • 点击 SCENE 3D/TOOLS 中的 Add Control Points 按钮启用控制点工具，也可以按键盘上的 F3 键。
  • 在 3Ds 视图中移动鼠标划过点云或网格时，会显示灰色连线。这些线连向能看到鼠标当前位置的相机；与这些线相连的所有相机，会作为「建议测量」显示在 1Ds 视图中新建的点下方。单击点云或网格即可创建点。
  • 每点击一次就会创建一个新控制点。要改变控制点位置，需在它所属的图像上微调。

删除控制点

  • 要删除刚创建的控制点，按 CTRL+Z 撤销上一步即可。
  • 要删除任意控制点，请在 1Ds 视图中展开控制点列表，把鼠标移到该控制点上，点击关闭图标。

拖放控制点

可以在视图之间拖放控制点，也可以在 1Ds 中的控制点之间拖放。

  • 可以从 1Ds 视图列表中拖放控制点。
  • 在二维图像视图中按住 ctrl 键拖动控制点，放下到另一张图像上。这会创建新点并自动与源点关联，之后可按住鼠标左键在其上微调位置。
  • 如果误建了本应关联到其他点的新点，或把点搞混了，也很容易修正：在 1Ds 视图中展开受影响的控制点树，把放错的图像名拖到正确的控制点树上即可。

提示：可通过以下方式合并控制点： drag and dropping 把一个控制点拖到另一个控制点上，两者会合并到 1Ds view.

控制点测量建议

对任何带三维坐标的控制点（Ground Control，或已分配至少 2 张图像的 Tie Point），都可以给出测量建议。
使用 Suggest Measurements 按钮，它位于 SCENE 1D/TOOLS 选项卡的 Constraints 区域，或 IMAGE 2D/TOOLS 选项卡中。
要移除这类建议，点击 Clear Suggestions，或点击 1Ds 面板控制点列表中对应行上的 X 按钮。请注意：被移除的建议会被「封禁」，即清除掉的测量建议在后续操作控制点后也不会再次出现。
若要让被封禁的测量重新参与，请点击 Unban Suggestions，或再次点击 Suggest Measurements 重新生成建议。


用地图视图做地理参考

若没有任何地面控制点，也可以在 map 视图中创建。
先把控制点以 Tie points 的形式放进图像中容易在地图上定位的位置；打开 map 视图，在 Control points 工具处于激活状态、且已选中要放到地图上的控制点时，在地图上目标位置点击，该点会自动变为 Ground control point。注意：这些点的高度总是同一个值（默认 1）。若要更改地面控制点在地图上的位置，把类型改回 Tie point，再用 Control points 工具重新放置。
这在多种场景下都有用：例如没有先验坐标、又想在地图制图软件中使用正射影像时，可以更快定位；又如想把多个已地理参考的组件合并成一个、但没有任何先验地理位置信息时。需要注意，这种地理参考方式的精度可能有米级偏差，因为它取决于所用地图的精度。


更新地面控制点

创建并放置好控制点后，点击 Align Images (F6)。也可以改用 Update 按钮，应用对地面控制点或距离约束所做的改动。与完整对齐（会考虑所有控制点和关系）不同，Update 只用地面控制点和距离约束来定位与缩放场景，不改变场景中相机的相对位置，因此也能对已创建的所有模型进行缩放和定位。完整对齐总是更精确，但相机位姿也可能随之改变，导致之前创建的模型与相机不再匹配 —— 所以会生成新组件，原模型保留在之前的（父）组件中。


重命名控制点

要修改控制点名称：在 1Ds 视图中点击该控制点，在同一窗口下方出现的 Selected control point(s) 面板中用鼠标选中其名称，输入新名称后按 Enter 键。

也可以一次重命名多个控制点（注意：系统会自动在输入的名称后加上序号，以便与列表中已有名称区分）：

  1. 连续多选的便捷做法（在 1Ds 窗口中）：点击要选的第一个控制点名称，按住 Shift 并同时点击最后一个控制点，然后在下方 Selected control point(s) 面板中选中「Name」值，重新输入名称。
  2. 若要选择不连续的控制点（在 1Ds 列表中），先点击第一个，再在选其他点时按住 Ctrl。选好后同样在 Selected control point(s) 面板中选中名称并重新输入。

排序控制点

1Ds 视图中的控制点列表可在 SCENE 1D / VIEW 选项卡中排序：可按创建顺序对应的索引排序，也可按名称排序。




注意：在 SCENE 1D / VIEW tab, the image order in the 1Ds view will also change.

与相机的关系

在 1Ds、2D 或 3Ds 视图中把鼠标移到控制点上或点击控制点时，3Ds 视图中会出现该控制点与对应相机的连线，帮助你在 3Ds 视图中判断这些控制点位于哪些图像中。


提示：应用还能在图像中查找控制点（前提是这些点已放置到图像中）。在 1Ds/2Ds view or in the 3Ds view using the Camera Rect or Camera Lasso tool, go to the Registration & Sparse Point Cloud part of the SCENE 3D/TOOLS tab and click Find Control Points。该功能会在 1Ds and 3Ds view.
