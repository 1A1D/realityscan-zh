对齐质量

评估图像对齐质量最粗略的基本方法，是看生成的相机数与点数，以及 Alignment report 中的数值（见下图）。
此外还可以显示图像之间的匹配点：只要找到的关联是正确的，这种方式更准确。也可以在 2D 图像视图的上下文功能区显示 Lens Distortion，检查畸变网格的弯曲是否合理。还有一种更直观、更全面（或许也是最好的）检查方式：使用 Quality Analysis 工具。

对齐报告

对齐过程产生的统计值保存在 Alignment report 中。这些数值也能反映对齐质量：

Total projections 该值表示三维点在图像中被看到的次数。例如一个三维点在三张图像中可见，就会产生 3 个投影。Total projections 等于 Average track length 乘以 Points count。
Average track length 指投影数。用总投影数除以点数，就得到 Average track length 行中的数值。它表示一个点平均出现在多少张图像中，数值越大，场景内部的关联性越好。
Maximal error (pixels) 点投影的最大误差。
Median error (pixels) 所有点误差的中位数，越小越好，理想情况低于 0.5px。在本文顶部的示例中，全部投影误差的中位数优于 0.478360 像素。
Mean error (pixels) 平均误差，越小越好，理想情况低于 0.5px。
Geo-referenced 该字段表示场景是否已做地理配准，并说明是哪个过程完成的配准（对齐或更新）。
Metric 该字段表示场景是否使用正确的度量单位，并说明是在哪个过程中设为度量单位（对齐或更新）。
Alignment time 到对齐完成所经过的时间。
