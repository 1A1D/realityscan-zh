体积与表面积测量

体积与表面积是依据正射投影上创建的形状计算出来的，因此至少需要一个正射投影，且形状要用 2D TOOLS 上下文选项卡中的工具创建。

至少创建一个形状后选中它，就会出现 Selected 2D region(s) 面板。

可以多选形状，查看这些形状合计的体积与面积信息。

体积信息

体积信息分为 Cut volume（基准面以上的体积）与 Fill volume（基准面以下的体积），从定义的基准面算到模型表面。修改 Base plane type 设置即可选择基准面：

  • None 未选择基准面时，体积信息不会更新，仍显示上次计算的体积。
  • Interpolated 对所选形状内的地形做插值生成一个面。这种情况下该面不必是平的。
  • 在最小与最大高度处取平 会生成两个基准面：底面位于所选测量形状内最低点的高度，顶面位于最高点的高度。据此，挖方体积从底面算到模型表面，填方体积从顶面算到模型表面。
  • Flat at user-defined height 可通过修改 Base plane at height 的值来自定义基准面高度。
  • Best-fit plane 用线性回归结合测量形状内的地形高度值，算出一个平面。

启用 Show base plane 可以在 3D 视图中显示所选基准面。若选择 在最小与最大高度处取平 类型，还可以选择显示顶面、底面，或都不显示。


面积信息

定义面积的只有两个值：

  • Area 2D 形状表面中平行于创建正射投影所用重建区域上表面的面积。
  • Area 3D 形状表面映射到模型上的面积。
