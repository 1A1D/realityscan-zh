图像多选

本节介绍高效使用 RealityScan 的基础知识 —— 如何一次选中多张图像。
可以在 1Ds、2Ds、3D 以及 MAP 视图中多选图像。所有选择会同时显示在所有已打开的视图中。

适用于 1Ds/2Ds 视图

  • 要同时选择/取消选择多张照片，请按住 ctrl 键，并点击要加入或移出选择的图像。
  • 要连续选择多张图像，先点击第一张，再按住 shift 键点击最后一张。

适用于 1Ds、2Ds、3Ds 和 MAP 视图

  • 也可以用快捷键 ctrl+a 一次选中全部图像。要取消选中所有对象，用 ctrl+d，或直接在选区外任意位置点击。也可点击 SCENE 3D/TOOLS 选项卡 Registration & Sparse Point Cloud 区域中的 Select All/Deselect 按钮。
  • ctrl+i 可反选 —— 此前未选中的图像都会变成选中状态。也可点击 SCENE 3D/TOOLS 选项卡 Registration & Sparse Point Cloud 区域中的 Invert 按钮。

适用于 3Ds 和/或 MAP 视图

  • 在 3Ds 和 MAP 视图中，也可以用 Camera Lasso 工具（c 键）选择相机 —— 按住 鼠标左键，并向所需方向和范围拖动。该工具也可在 SCENE 3D/TOOLS 选项卡的 Registration & Sparse Point Cloud 区域找到，或直接按 c 键。
  • 另一种方式是用 Camera Rect 工具选择相机 —— 按住 鼠标左键，一边移动一边确定矩形大小。该工具也可在 SCENE 3D/TOOLS 选项卡的 Registration & Sparse Point Cloud 区域找到，或使用快捷键（shift+c）。
  • 选择项目时按住 CTRL 键可将其加入当前选择。
  • 选择项目时按住 SHIFT 键可将其从当前选择中移除（对 Camera Lasso 与 Camera Rect 工具同样适用）。
  • 在 3Ds 视图中可以隐藏和显示选中的相机，或一次性取消隐藏全部相机 —— 只需点击 SCENE 3D/VIEW 选项卡 Alignment Cameras 区域中的相应按钮。

已选图像数量显示在 1Ds/2Ds 视图的 Selected Inputs 表格中。


导出与导入图像列表

  • 用 ALIGNMENT 选项卡 Export 区域的 Registration 按钮可以导出图像列表，在文件资源管理器窗口中把导出类型设为 Image list。图像列表包含项目中所有已启用或已选中的图像和/或 LiDAR 扫描。利用上面讲的图像多选方法，可以只导出特定的图像集合。导出会生成一个文本文件，按字母顺序列出图像和/或 LiDAR 扫描的名称，并带上它们在磁盘上的位置。
  • 要导入图像列表（其中也可以包含 LiDAR 扫描），请用 WORKFLOW 选项卡 Import Metadata 区域的 Image Selection 按钮。
  • 也可以借助图像列表来选择图像。
