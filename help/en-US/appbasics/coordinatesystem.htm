坐标系选择

坐标系按所属国家或常用 ID 组织。所选坐标系决定项目的测量单位。

RealityScan 自带 EPSG 数据库，以及一个含欧氏坐标系的本地数据库。

  • 要导入本地数据库，点击导入按钮，并定位到应用安装目录中的 local.xml。也可以通过编辑/添加数据库文件（格式正确的 xml）来轻松创建自定义坐标系。
  • 对话框中会优先显示最近使用的坐标系。
  • 在搜索框中输入关键词（例如 "WGS 84"）即可搜索坐标系。

项目坐标系与导出坐标系

RealityScan 允许同时使用多个不同坐标系，甚至每个地面控制点都可以相对于不同坐标系测量。但仍有一个全局的项目坐标系，作为测量、坐标显示和精度报告的基准。

  • 要设置项目坐标系，进入 WORKFLOW / Settings / Coordinate Systems / Project coordinate system。
  • 要以其他坐标系导出模型/网格，进入 WORKFLOW / Settings / Coordinate Systems / Output coordinate system。部分导出工具允许直接在导出设置对话框中指定导出坐标系。

提示：建议对所有 control points 处于同一坐标系，因为坐标转换可能带来微小误差。
