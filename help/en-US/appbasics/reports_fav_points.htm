点（报告中可用的函数与变量）

点

ExportPoints —— 该函数用于输出每个已配准点的信息。

语法：

  $ExportPoints( noParametersJustAnyText )

可用变量：

index —— 点的索引

trackLength —— 该点被追踪到的图像数量

x —— 点在输出坐标系中的 x 坐标

y —— 点在输出坐标系中的 y 坐标

z —— 点在输出坐标系中的 z 坐标

euclidX —— 点在欧氏坐标系中的 X 坐标

euclidY —— 点在欧氏坐标系中的 Y 坐标

euclidXZ —— 点在欧氏坐标系中的 Z 坐标

aX —— 点在组件坐标系中的 X 坐标

aY —— 点在组件坐标系中的 Y 坐标

aZ —— 点在组件坐标系中的 Z 坐标

r —— 点 RGB 颜色的红色分量，取值范围 0 到 255

g —— 点 RGB 颜色的绿色分量，取值范围 0 到 255

b —— 点 RGB 颜色的蓝色分量，取值范围 0 到 255

可用函数：

ExportTrack —— 该函数遍历该点被追踪到的所有图像

语法：

  $ExportTrack( noParametersJustAnyText )

可用变量：

featureIndex —— 点在图像中的索引

imageIndex —— 图像索引

x —— 点在图像中的 x 坐标，归一化到 -0.5 到 0.5

y —— 点在图像中的 y 坐标，归一化到 -0.5 到 0.5

scale —— 其值等于 width 与 height 变量中较大者

width —— 图像宽度

height —— 图像高度

示例：

  $ExportPoints(
    Point index: $(index)
    Number of images: $(trackLength)
    x: $(x)
    y: $(y)
    z: $(z)
    r: $(r)
    g: $(g)
    b: $(b)
    $ExportTrack(
      Feature index: $(featureIndex)
      Image index: $(imageIndex)
      Projected x (normalized): $(x)
      Projected y (normalized): $(y)
      Image scale: $(scale)
      Image width: $(width)
      Image height: $(height) 
      Projected x [pixels]: $(x * scale + width * 0.5)
      Projected y [pixels]: $(y * scale + height * 0.5)
    )
  )

TiePointsHistogram —— 该函数用于输出连接点最大误差的直方图。每个连接点都有其最大投影误差（即投影到误差最大的那张图像上的误差），以像素计。

语法：

  $TiePointsHistogram( componentGUID, stepSize, stepCount, anyText )

参数：

componentGUID —— 组件的 GUID：可用 IterateComponents 函数获取所有组件的 GUID

stepSize —— 步长，即分箱大小（正的双精度数）

stepCount —— 步数（分箱数）

可用变量：

histTotalSum —— 投影误差落在区间 [ 0, stepSize * stepCount ) 内的连接点数量

histMaxCount —— 所有步中最大的 histCount（各步相同）

histMinValue —— 直方图的最小值（纵轴）

histMaxValue —— 直方图的最大值（纵轴）

histStepCount —— 所定义的步数

histIndex —— 当前步的索引（第一步索引为 0，最后一步索引为 stepCount - 1）

histCount —— 投影误差落在区间 [ histValue - stepSize, histValue ) 内的连接点数量

histValue —— 当前区间的上界，即本步中每个连接点的投影误差小于 histValue、且大于或等于 histValue - stepSize

histCumsum —— 本步与之前所有 histCount 的累计和，最迟在最后一步会等于 histTotalSum

示例：

  $IterateComponents(
    $TiePointsHistogram( "$(componentGUID)", 0.5, 5,
      Total sum: $(histTotalSum)
      Index: $(histIndex)
      Count: $(histCount)
      Upper bound value: $(histValue)
      Cumulative sum: $(histCumsum)
      Max count: $(histMaxCount)
    )
  )

TracksStats —— 该函数用于输出连接点轨迹长度的直方图。

语法：

  $TracksStats( componentGUID, stepSize, stepCount, anyText )

参数：

componentGUID —— 组件的 GUID：可用 IterateComponents 函数获取所有组件的 GUID

stepSize —— 步长，即分箱大小（正的双精度数）：可以用小数，但轨迹长度始终是整数，所以若设为等于或小于 0.5 的数，必然会出现某些分箱里没有连接点

stepCount —— 步数（分箱数）

可用变量：

histTotalSum —— 轨迹长度落在区间 [ 0, stepSize * stepCount ) 内的连接点数量

histMaxCount —— 所有步中最大的 histCount（各步相同）

histMinValue —— 直方图的最小值（纵轴）

histMaxValue —— 直方图的最大值（纵轴）

histStepCount —— 所定义的步数

histIndex —— 当前步的索引（第一步索引为 0，最后一步索引为 stepCount - 1）

histCount —— 轨迹长度落在区间 [ histValue - stepSize, histValue ) 内的连接点数量

histValue —— 当前区间的上界，即本步中每个连接点的轨迹长度小于 histValue、且大于或等于 histValue - stepSize

histCumsum —— 本步与之前所有 histCount 的累计和，最迟在最后一步会等于 histTotalSum

示例：

  $IterateComponents(
    $TracksStats( "$(componentGUID)", 1, 17,
      Total sum: $(histTotalSum)
      Index: $(histIndex)
      Count: $(histCount)
      Upper bound value: $(histValue)
      Cumulative sum: $(histCumsum)
      Max count: $(histMaxCount)
    )
  )
