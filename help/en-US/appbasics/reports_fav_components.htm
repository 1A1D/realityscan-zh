组件（报告中可用的函数与变量）

组件

IterateComponents —— 该函数用于输出所有组件的基本信息。

语法：

  $IterateComponents( noParametersJustAnyText )

可用变量：

componentGUID —— 组件的 GUID

componentName —— 组件名称

componentCamerasCount —— 组件中已配准的相机数量

示例：

  $IterateComponents(
    Component GUID: $(componentGUID)
    Component name: $(componentName)
    Cameras count: $(componentCamerasCount)
  )

ComponentInfo —— 该函数用于输出某个组件的基本信息。

语法：

  $ComponentInfo( componentGUID, anyText )

参数：

componentGUID —— 组件的 GUID：可用 IterateComponents 函数获取所有组件的 GUID

可用函数：

GetImageCamera —— 直接输出局部相机索引。

语法：

  $GetImageCamera( sfmIndex )

可用的表达式函数：

GetImageCamera —— 结果为局部相机索引。

语法：

  GetImageCamera( sfmIndex )

可用变量：

componentName —— 组件名称

componentId —— 组件的 GUID

componentReconstructionId —— 重建运行的 GUID

componentCameraCount —— 已配准的相机数量

componentPointCount —— 已配准的点数量

componentControlPointCountUsed —— 已使用的控制点数量

componentConstraintCountUsed —— 已使用的距离约束数量

示例：

  $IterateComponents(
    $ComponentInfo( "$(componentGUID)",
      Component name: $(componentName)
      Component GUID: $(componentId)
      Reconstruction-run GUID: $(componentReconstructionId)
      Cameras' count: $(componentCamerasCount)
      Points' count: $(componentPointsCount)
      Control points' count used: $(componentControlPointsCountUsed)
      Constraints' count used: $(componentConstraintsCountUsed)
    )
  )

ComponentStats —— 该函数用于输出某个组件的对齐精度信息与统计结果。

语法：

  $ComponentStats( componentGUID, anyText )

参数：

componentGUID —— 组件的 GUID：可用 IterateComponents 函数获取所有组件的 GUID

可用变量：

componentTotalProjection —— 图像投影的总数

componentAverageTrackLength —— 每个被观测三维点平均出现在多少张图像中

componentMaximalError —— 以像素计的最大重投影误差

componentMedianError —— 以像素计的重投影误差中位数

componentMeanError —— 以像素计的平均重投影误差

componentIsGeoreferenced —— 组件是否已做地理配准

componentMetric —— 组件是否已缩放到真实尺寸

componentAlignmentTime —— 单次运行中所有组件的总对齐耗时

示例：

  $IterateComponents(
    $ComponentStats( "$(componentGUID)",
      Total projections: $(componentTotalProjection)
      Average track length: $(componentAverageTrackLength)
      Maximal reprojection error [pixels]: $(componentMaximalError)
      Median reprojection error [pixels]: $(componentMedianError)
      Mean reprojection error [pixels]: $(componentMeanError)
      Geo-referenced: $(componentIsGeoreferenced)
      Metric: $(componentMetric)
      Alignment time: $(componentAlignmentTime)
    )
  )

ComponentSettings —— 该函数用于输出对齐设置信息。

语法：

  $ComponentSettings( componentGUID, anyText )

参数：

componentGUID —— 组件的 GUID：可用 IterateComponents 函数获取所有组件的 GUID

可用变量：

componentAlignmentEngine —— 对齐引擎

componentAlignmentMode —— 对齐模式

componentMaxFeaturesPerMpx —— 每百万像素的最大特征数

componentMaxFeaturesPerImage —— 每张图像的最大特征数

componentDetectorSensitivity —— 检测器灵敏度

componentPreselectorFeatures —— 预筛选器特征数

componentImageDownscaleFactor —— 图像降采样系数

componentMaxFeatureReprojectionError —— 以像素计的最大特征重投影误差

componentUseCameraPositions —— 是否使用了相机中心的 GPS 位置

componentLensDistortionModel —— 镜头畸变模型

componentFinalOptimization —— 是否使用了最终优化

示例：

  $IterateComponents(
    $ComponentSettings( "$(componentGUID)",
      Alignment engine: $(componentAlignmentEngine)
      Alignment mode: $(componentAlignmentMode)
      Max features per Mpx: $(componentMaxFeaturesPerMpx)
      Max features per image: $(componentMaxFeaturesPerImage)
      Detector sensitivity: $(componentDetectorSensitivity)
      Preselector features: $(componentPreselectorFeatures)
      Image downscale factor: $(componentImageDownscaleFactor)
      Maximal feature reprojection error [pixels]: $(componentMaxFeatureReprojectionError)
      Use camera positions: $(componentUseCameraPositions)
      Lens distortion model: $(componentLensDistortionModel)
      Final optimization: $(componentFinalOptimization)
    )
)

SelectComponent —— 为 IteratorsFunctionSet 函数集的内部使用选中一个组件。它只影响 IterateImages 与 IterateCameras 两个函数，可在这两个函数之前或内部调用。

语法：

  $SelectComponent( componentGUID )

参数：

componentGUID —— 组件的 GUID

示例：

  $IterateComponents(
    $SelectComponent ( "$(componentGUID)"
    )
  )
