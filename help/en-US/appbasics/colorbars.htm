彩色光标

给 1D, 2D 和/或 3Ds 视图分配一个或多个彩色光标（色条）（蓝、绿、洋红或珊瑚色），有助于在复杂场景中导航，也便于整理数据。可以把多个视图都设为显示同一个光标（比如蓝色）；之后当你把某个对象分配给蓝色光标，所有关联蓝色光标的视图都会立即显示该对象的信息。

把对象分配给光标

RealityScan 定义了四个光标。

  • 在 1Ds 或 2Ds 面板中，按住 1/2/3/4，并点击图像、正射投影或其他可拾取对象，即可「切换」其光标：1 = 蓝，2 = 绿，3 = 洋红，4 = 珊瑚色。所以按住 1/2/3/4 点一次是分配光标，再按住同一个数字点一次则是移除光标。
  • 同样，在 3Ds 或 MAP 视图中点击对象时按住 1/2/3/4，也能分配颜色。

让视图显示某个光标

给视图分配颜色后，该视图就会显示光标所指对象的信息。按视图类型不同，可能是对象属性（1D 视图）、图像（2D 视图）或空间位置（3Ds 视图）。借助光标，给多个视图分别分配颜色就能同时看到这些信息。用户选择或更改光标对象时，系统会自动刷新视图。

  • 要给视图分配彩色光标，可在活动视图（带蓝色边框的当前窗口）中按 ctrl+1/2/3/4。
  • 也可以在视图的上下文功能区中更改视图光标颜色。

在光标与视图之间移动对象

有时我们希望保持视图光标不变，却在视图中显示另一个对象。

  • 当你拖放一张图像（按住鼠标左键并移动），例如从 1Ds 面板拖到 2D 视图窗口，并在放下时按住 shift，程序会把拖动的图像设为光标对象并显示它，而不是直接查看该图像。
  • 3Ds 视图同样支持光标。需要按 enter 键「进入」相机空间。要退出 3Ds 视图中的色条分配，转动一下视图即可。

在图像间导航

依据彩色光标和选中的 2D 视图，可以用键盘快捷键在图像间导航：

  • 用 左/右 方向键在图像列表中前后切换。
  • 用 SHIFT + 左/右 方向键在所选组件的已对齐相机之间切换。
  • 用 上/下 方向键在当前所选控制点的图像之间切换。
  • 用 Page Up/Down 键 在图像列表中一次跳过 20 张。

注意：即使没有为视图分配颜色光标，也可以浏览图像： 2D view.
