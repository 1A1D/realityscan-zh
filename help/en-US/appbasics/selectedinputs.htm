选中的输入

导入图像或 LiDAR 扫描后，可以在设置为 1Ds 或 2Ds 的视图左侧的输入列表中选择它们。选中后，输入的属性会显示在 Selected Input(s) 面板中。如果在配准（对齐）之后选择输入，输入属性中会多出几项设置：Enable in component 和 Lock pose for continue。

  • File name 所选输入文件的名称和位置。
  • Model 生成输入文件所用相机的厂商与型号。
  • Width 图像宽度（像素）。
  • Height 图像高度（像素）。
  • Pixel format 每像素位数及颜色通道规格。
  • Features 上次对齐时在该图像中检测到的特征数量。
  • Features source 通过选择希望纳入组件新对齐的特征（按每个组件中的每张图像分别设置），可以选用更多组件整合策略。选对策略能显著降低对齐时所需的 RAM。
    Merge using overlaps 只使用各组件共有的图像/点，即相互重叠的图像；该策略可减少计算时间和内存占用。
    Use component features 只使用导入组件对齐时用到的点，速度最快，内存紧张时最合适。
    Use all image features 会使用全部图像/点，速度最慢、内存需求最高。
  • Visible 在三维视图中显示或隐藏所选输入的相机锥体。
  • Enable alignment 若要让所选输入参与配准及后续处理，请设为 Enable；否则选择 Disable。
  • Enable meshing 若要让所选输入参与模型计算/网格化，请设为 Enable；否则选择 Disable。此功能对所有组件生效。
  • Enable texturing and coloring 若要让所选输入参与模型的纹理或着色计算，请设为 Enable；否则选择 Disable。
  • Weight in texturing 设置所选输入在纹理或着色过程中所计的权重。设为小于 1 的值可降低所选输入在着色/纹理过程中的影响。
  • Color correction reference 若要将此输入作为颜色校正计算的基准，请设为 Enable；否则选择 Disable。启用后该输入的颜色不会被改变。
  • Color correction 若要将此输入纳入颜色校正计算，请设为 Enable；否则选择 Disable 跳过该图像（例如仅用于几何的结构光（投影图案）图像）。
  • Downscale for depth maps 设置深度图计算的图像降采样系数。整数越大计算越快，但细节越少。取 1 表示不缩放（100% 分辨率），取 2 表示图像每边缩小一半（原分辨率的 25%），以此类推。请注意，深度图计算的最终降采样按以下方式相乘得出：Downscale for depth maps（在 1Ds Selected input(s) 面板中为所选图片设置）× Image downscale（在 Reconstruction settings 中设置）
  • Registered 指示该输入是否已在所选组件中完成配准。
  • Enable in component 启用后，会用所选组件中的相机配准数据来优化后续对齐。禁用不会影响其他组件的配准数据或相机图像先验，但会限制该组件内配准数据的使用，包括网格化和纹理等流程。与 Enable alignment 不同，此选项只作用于所选组件，而非整个输入。当组件中已知有部分相机未对齐（其数据可能拖累后续对齐）时，这个设置很有用。
  • Lock pose for continue 锁定所选组件中已选相机的相对位置，以便后续处理。分批处理图像时这个选项很有用：先对齐第一批图像、微调组件、锁定组件中相机的位置，再加入另一批图像重新对齐。这样相机位置不会被改动（例如组件不会被拆分）。

图像图层

图像可以按不同处理步骤组织成图层，例如遮罩不需要的部分，或为纹理指定特定图像。命名规范的图像会一起加载，图层按图像名或文件夹名自动分配。

  • [Type] layer 分配给该输入的图像图层。[Type] 标签会随图层类型变化，因此一个输入可以有多个图层条目。
  • Enable masks for alignment 使遮罩图像图层可用于对齐过程。
  • Enable masks for meshing 使遮罩图像图层可用于网格化过程。
  • 启用蒙版用于纹理生成与着色 使遮罩图像图层可用于着色和纹理过程。

相机先验

先验是在对齐之前已知的属性（相机/场景信息），可用于影响对齐质量。它们可以是固定的、近似的，或完全未知的。
选中一张或多张图像时，位姿、标定和镜头畸变先验都可以在选择面板中设置。选中 LiDAR 扫描输入（其内部格式为 .lsp）时，面板中只显示位姿先验。


位姿先验

以下参数定义我们对某个相机位置的已知信息：

  • Locked pose group 输入正整数即可设为一个组。留空或输入负整数可取消位姿分组。
  • Relative pose - 输入的先验位置类型，定义相机之间的相对位置，可设为：
    Unknown - 未定义相机间的相对位置
    Draft - 相机间的相对位置已知到一定精度，可在对齐过程中优化
    Exact - 相机间的相对位置已知，对齐过程中不会被改动
  • Relative coordinates 为预标定组件中各相机之间的相对位置定义坐标系。此选项仅对装置内相连的输入可见（例如同一 LiDAR 扫描站位下的各个 .lsp 文件，或带有精确/锁定 XMP 文件的图像）。
  • Absolute pose - 输入的先验位置类型，定义全局相机位置（相对于相机所在的系统，而非相机之间），可设为：
    Unknown - 未定义输入的先验位置
    Position - 相机位置已知到一定精度，可在对齐过程中优化
    Position and orientation - 相机的近似位置与朝向均已知，但可在对齐过程中优化
    Locked - 对齐过程中不允许改动相机位置与朝向
  • Absolute coordinate 定义先验坐标所用的坐标系。此设置下的坐标类型取决于所选坐标系。
  • Latitude/X,Y,Z... 视所选坐标系而定，可以用角度坐标或笛卡尔坐标定义地面控制点的物理坐标。
  • 偏航 / 航向，俯仰 / 仰角，翻滚 / 倾斜 相机分别绕 Y、X、Z 轴的旋转角。
  • Pose accuracy 定义相机位置的精度，可使用全局设置或自定义值。若 Accuracy settings source 设为 Global camera prior settings，则采用 Alignment settings 中设定的值；若 Accuracy settings source 设为 Edit custom values，则可手动修改所选输入的精度。

标定先验

以下参数给出相机内参标定先验的信息（焦点、投影中心等）：

  • Calibration group 对齐后，整数相同（且不为 -1）的图像将共享同一套标定参数。可以自动或手动把图像归入相同的标定组。详情参见 此处。
  • Prior 定义标定先验参数的精度。
    Unknown 先验值缺失，或处理时不予采用。
    Approximate 先验值已知，处理过程中会被调整。
    Fixed 先验值已知，处理过程中不会被改动。
  • Focal length (35mm) 相机焦距的 35mm 等效值（毫米）。
  • Principal point x [mm] 投影中心在 x 轴上的位置（毫米）。
  • Principal point y [mm] 投影中心在 y 轴上的位置（毫米）。
  • Skew 图像平面的偏斜。
  • Aspect ratio 像素的宽高比。

镜头畸变先验

定义镜头的光学信息：

  • Lens Group 对齐后，整数相同（且不为 -1）的图像将共享同一套镜头参数。可以自动或手动把图像归入相同的镜头组。详情参见 此处。
  • Prior 定义镜头畸变先验参数的精度
    Unknown 适用于镜头畸变明显、广角镜头，以及镜头先验未知的情况。
    Approximate 起始值已知，会被调整。
    Fixed 先验值已知，处理过程中不会被改动。
  • Model 指定用于建模镜头畸变的畸变模型。更多信息见 此处。
  • Radial 1/2/3/4 所选畸变模型的径向畸变系数。
  • Tangential 1/2 所选畸变模型的切向畸变系数。

默认情况下，镜头畸变模型设为 No lens distortion、先验设为 Approximate，即 RealityScan 会尽量求出镜头畸变接近零的解。若图像存在可见的镜头像差，这个假设并不现实；此时应设置合适的畸变系数，或把镜头先验改为 Unknown。


装置

装置参数仅适用于在同一装置内相连的输入（例如同一 LiDAR 扫描站位下的各个 .lsp 文件）。

Rig ID 装置类型，例如 LiDAR 扫描点云。
Prior 某一位置上装置实例的标识。同一 LiDAR 扫描站位的全部 6 个 .lsp 文件共享同一编号。
Model 装置内的相机索引（例如同一 LiDAR 扫描站位中 .lsp 文件的序号（0-5））。
