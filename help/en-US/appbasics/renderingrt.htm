实时场景渲染器

三维场景视图（3Ds）可以用多种渲染模式显示场景或其对象。可在 SCENE 3D/VIEW 选项卡的 Model Render 区域切换渲染模式。渲染模式影响模型在 3Ds 视图中的显示方式，此外还有一些选项可在 Scene 区域设置：

  • Grid 默认显示网格。要在 3Ds 中隐藏它，取消勾选此框。
  • Shapes 勾选后可在模型上显示在正射投影中创建的形状。这些形状的详情见 此处。
  • Bright Background 勾选后背景会更亮。

渲染模式

可用的模型渲染模式如下：

  • Vertices 只渲染模型顶点的一个合理子集，并带烘焙颜色。子集大小可在应用设置中调整。
  • Solid 平面着色的三角面，配四向动态光。
  • Color/Texture 显示最佳效果。这里有两种情况：没有纹理时用烘焙颜色着色，有纹理时显示纹理。


工作原理

首先需要计算出网格 —— 也就是图像已对齐、模型已计算，并且布局中有一个 3Ds 视图。如果只看到点云，说明要么目前只完成了图像对齐，要么模型太大装不进内存。后者请继续往下看，了解如何渲染大数据。

为保证浏览流畅，会执行以下操作：

  • 模型从磁盘载入 GPU 期间，会显示模型点云。
  • 纹理载入完成后，点云消失。
  • 纹理会缩放到适配 GPU（最大 16k），因此显示效果可能低于模型本身的画质。

处理进行中

任何占用 GPU/CPU/内存/显存的密集计算（例如对齐、重建或纹理计算）都会临时把渲染模式切回低负载模式，即点云渲染。处理结束后系统会自动切回原模式 —— 当然，前提是系统资源允许。

便于操作的细节

为便于编辑，背面三角面始终会被渲染，且用不同颜色显示 —— 更准确地说，与正射投影工具渲染背面几何时使用同一色调。可在 Ortho Projection (F11) 工具中选择其颜色与透明度。


限制

纹理的数量和尺寸没有限制，只会按需缩放。

实体或 sweet 模式下显示的三角面数量在应用设置中设定（WORKFLOW 选项卡 / Application）。共有 3 档：使用显存的 20%、40% 或 80%。可显示的三角面数取决于 GPU 显存，例如 16GB 显存对应约 7200 万（20%）、1.43 亿（40%）、2.85 亿（80%）。

一旦超过所设上限，就只会显示点云，渲染模式仍保持不变。不过此时可以用 Clipping Box 工具来显示模型的局部；该工具位于 View part of the SCENE 3D / VIEW context tab.
