选中所有相机与点

这里列出 SCENE 3D/TOOLS 选项卡 Registration & Sparse Point Cloud 区域中 Select All (CTRL+A) 与 Invert 按钮的全部用法。


WARNING: Do not confuse the Select All button from the Registration & Sparse Point Cloud part with the one in the Model & Texture part.

全选

选中所有相机

若你在组件/模型的 3Ds 视图中选中了部分相机或未选，点击 Select All 按钮（来自 Registration & Sparse Point Cloud 面板）会选中 1Ds/2Ds 以及 3Ds 视图中的全部已对齐相机。

若你在项目的 1Ds/2Ds 视图中选中了部分相机或未选，点击 Select All 按钮（来自 Registration & Sparse Point Cloud 面板）会选中 3Ds 视图中的所有相机（这些都是已对齐的），以及 1Ds/2Ds 视图中的所有相机（其中部分可能未对齐）。当然，若项目中没有任何组件，3Ds 视图中不会选中任何相机。

选中所有点

当图像已对齐形成组件、你想选中全部三维点时（此时模型尚不能重建，否则此功能无效），先选中若干三维点，再用 Select All 按钮（来自 Registration & Sparse Point Cloud 面板）选中当前 3Ds 场景中的全部点。

选中所有控制点

当你选中一个或多个控制点后，Select All 按钮（来自 Registration & Sparse Point Cloud 面板）会选中 1Ds 视图中列出的所有控制点，选择结果在 1Ds 与 3Ds 视图中都能看到。

选中所有控制点测量

当你在 1Ds 面板中选中某个控制点下的一个或多个图像（控制点测量）后，Select All 按钮（来自 Registration & Sparse Point Cloud 区域）会选中该控制点下的全部测量。


取消选择

Deselect (CTRL+D) 按钮（来自 Registration & Sparse Point Cloud 区域）会取消所有当前选择，对上述各类选择都适用。


反选

此工具的行为取决于当前选中了什么：

  • 未选相机也未选三维点：会选中 3Ds 视图中活动组件的全部相机。
  • 选中了活动组件中的一台或多台相机：将相对于该组件中全部已对齐相机做反选。
  • 选中的相机不只来自活动组件：将相对于项目中所有相机做反选。
  • 选中的是三维点：将选中点云中其余所有三维点。
