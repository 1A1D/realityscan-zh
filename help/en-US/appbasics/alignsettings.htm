对齐设置

对齐是通过匹配图像的共同特征与位姿来配准相机的过程。已配准的相机会被归入组件。可以在 ALIGNMENT 选项卡 Registration 区域的 Alignment Settings 中调整对齐过程。

Feature detection quality 选择图像特征检测的质量等级。设为 High 会提升特征检测效果、对齐更精确，但会增加处理时间与内存占用。
Max features per mpx 设置对齐时特征检测器每百万像素最多提取的特征数。特征用得越多处理越慢，但可能减少产生的组件数量。
Max features per image 设置每张图像的最大特征数，作用类似 Max features per mpx。
Image overlap 定义相邻图像中同一部分物体所占画面空间的比例。下图中红色区域表示投影到图像上的共同物理空间。共同区域越大，相机位姿越容易计算。图像重叠低于 20% 时选 Low。要获得最佳质量，相邻图像重叠应大于 60%。重叠越大速度越快；重叠太小且照片不足时，可能出现互不连通的组件。


Image downscale factor 特征检测前图像缩小的倍数。要获得最佳精度，请使用完整图像分辨率（降采样系数 1）。
Max feature reprojection error 对齐时使用的内部精度等级。建议最大设为 3px，并尽量把误差控制在此范围内。


相机先验

定义初始相机位置与旋转的精度，以及它们的硬度（即对对齐的影响强度）。



  • Use camera priors for georeferencing 设为「是」时，图像的先验位置会用于对齐过程和场景地理参考。
  • Position accuracy 指定相机先验位置的精度，即计算位置被视为与先验值相等的范围。
  • Units 显示相机先验及其精度所用坐标系的单位。
  • Position prior hardness 定义计算位置与先验位置的接近程度。值越大，计算位置越接近先验位置。这可能改变相机之间的视觉连接。
  • Yaw/Pitch/Roll accuracy 指定相机先验朝向的精度，即计算朝向被视为与先验值相等的范围。
  • Orientation prior hardness 定义计算朝向与先验朝向的接近程度。值越大，计算朝向越接近先验朝向。这可能改变相机之间的视觉连接。

控制点先验设置

定义控制点与地面控制点位置的精度。



  • Image measurements accuracy [px] 定义图像中手动放置控制点的偏差范围。
  • Position accuracy 按各坐标分别指定地面控制点位置的精度。
  • Defined distance accuracy 设置距离约束的常规精度值。
  • Units 显示控制点先验及其精度所用坐标系的单位。

草稿

这些设置在执行 Draft 对齐时生效。



Image overlap 定义图像之间预期的共同特征量。可选 Low、Medium 或 High：Low 表示重叠最少，High 表示重叠最多。
Image downscale factor Draft 对齐时用于缩小图像尺寸的倍数。
Final model optimization 设为「是」时，会执行最后一次光束法平差以优化相机配准。


高级设置

高级设置面向熟悉运动恢复结构（SfM）处理的用户。除非你清楚其影响，否则不要改动这些设置。



  • GPU acceleration 启用 GPU 以加快对齐过程。
  • 对齐后添加重建区域 设为「是」后，对齐一结束就会自动创建重建区域。
  • Enable measurement suggestions 可在此启用放置控制点时在 3Ds 视图中给出的图像测量建议。
  • Force component rematch 设为「是」时，应用会重新对齐图像与相机以寻找更好的连接。它利用现有相机位姿搜索新匹配，可能提升最终对齐质量。
  • Background feature detection 选择是否让系统以较低的处理器优先级在后台自动检测特征点。例如在需要放置控制点时很有用：电脑会预先处理图像，从而节省你的时间。
  • Background thread priority 后台检测的优先级，可选低或普通。
  • Preselector features 检测到的特征中实际用于对齐的数量。建议设为已检测特征的 1/4 到 1/2。
  • Detector sensitivity 控制特征检测器如何评估图像中的点在视角或光照变化等条件下的稳定性。较高灵敏度（如 Ultra）能在纹理较弱的区域也检测出更多特征，但也可能引入由图像噪声导致的不可靠点。较低灵敏度（如 Low）更具选择性，会忽略较弱的特征，可减少噪声，但可能丢弃对配准有用的数据。
  • Merge georeferenced components 当生成多个组件且各自都已地理参考时，启用此设置可在没有视觉重叠的情况下也把它们合并。
  • Distortion model 指定要使用的畸变模型 —— 详见下一节。
  • 导入时优先使用影像作为特征来源 设为「是」会导入 .zfprj 镶嵌图像，并在对齐过程中把它们作为特征来源。这有助于配准尚未配准的扫描，或在把 LiDAR 扫描与图像合并时自动找到相同特征。仅对 Z+F 扫描有效。
