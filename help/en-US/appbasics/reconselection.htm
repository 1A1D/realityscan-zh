在三维中选择三角面

要在重建出的模型中选中一些三角面，请在 SCENE 3D/TOOLS 选项卡的 Model & Texture 区域选择一个工具。这些选择对所有重建工具都生效，例如滤波、简化、正射投影和平滑。
可选的选择工具有：

  • Rect：按住左键并移动鼠标，用矩形选择三角面。
  • Lasso：按住左键并移动鼠标，沿环状轨迹选择。
  • Box：按住左键并移动鼠标确定框的底面，再按住左键并移动光标确定框的高度。之后在 1Ds 面板的 Box Selection Tool 中点击相应按钮，即可选中/取消选中框内或框外的三角面。
  • Expand：把当前选择扩展到所有传递相连的三角面。要能点击此按钮，需先用其他选择工具选中一些三角面。
  • Advanced：高级选择工具可以让你：
    • Select marginal triangles：边缘三角面是重建算法额外添加的三角面，用于保证模型水密。
    • Select largest connected component
    • Select large/small triangles：选中至少有一条边超过/低于阈值的全部三角面。阈值 = 平均边长 × Edge threshold multiplier 字段中的用户自定义值。
  • Select All：选中当前三维场景中的全部三角面。
  • Deselect 清除当前所有三角面选择。
  • Invert 把当前选择切换为模型的其余三角面。
提示：也可以用以下方式修改选择： CTRL for union, SHIFT for subtraction, and CTRL + SHIFT for intersection.
