应用设置

在 Workflow 选项卡的 Application 区域打开应用设置。

  • Log file 启用后会在 Windows 临时文件夹中写入并保存日志文件。
  • Operation log data 启用后会把所用功能、设置和处理过程的数据上传到我们的服务器。这些数据可用于改善使用体验，或在出错、崩溃时作为复现步骤。请注意不会发送其他任何数据，我们也无法访问你的输入数据或项目文件。不会转发或存储任何敏感数据。
  • Tutorial mode 启用后，会根据当前使用的工具显示帮助中的相应内容。
  • Auto save mode 启用或关闭项目自动保存。项目会保存在原项目旁边，扩展名为 .autosave。新项目的改动则保存在缓存文件夹中。自动保存详情见 此处。
  • Navigation style 更改 3Ds 视图的浏览方式，可选默认、Autodesk 或 Leica。
  • Cache location 选择缓存文件的存放位置。选好自定义位置后会询问是否移动旧缓存文件：选择移动则全部文件迁到新位置；选择不移动则旧文件留在原处，新缓存位置为空。缓存文件详情见 此处。
  • Clear cache on exit 选择应用清理缓存的周期。请注意，保留 RealityScan 的临时（缓存）文件有助于复用已检测的点与已重建的深度图。
  • Clear cache 点击按钮清空缓存文件夹。
  • Cache image metadata 启用后会为输入图像保存一个隐藏的系统文件（crmeta.db），内含 EXIF 元数据（如分辨率），以加快图像访问速度。
  • GPUs to use 若电脑有多块 GPU，可在此选择使用哪一块。

渲染设置

调整 3Ds 视图中可显示的点（网格顶点）和模型三角面数量。

  • Max points to display 3Ds 视图中可渲染的最大点数。设置越大渲染越密，但速度越慢。
  • 最大显示三角形数（最大 GPU 显存） 选择渲染可使用的显存比例，它决定了能显示多少三角面。共有三档：20%、40%（默认）或 80% 显存。每档旁边会根据你机器的显存标注可显示的三角面数。

视觉与语言设置

用这些设置更改应用的视觉风格和界面语言。

  • Zoom 更改所有界面元素（文本、面板、窗口）的大小，功能区除外。
  • Animated UI 启用或关闭应用窗口显示/隐藏时的淡入淡出效果。
  • UI language 切换整个应用（含帮助）使用的语言。
  • Reset layout and dialogs 点击按钮把界面恢复为默认状态。

控制点编辑器亮度增强

更改放置控制点时用于增强图像亮度与对比度的设置。

  • Brightness enhancement 放置控制点时启用亮度与对比度增强。
  • Automatic adjustment 基于图像可见区域启用自动调整。
  • Autodetection focus 选择用于自动调整的区域。
  • Maximal brightness change 定义亮度可变化的幅度。启用 Automatic adjustment 时显示。
  • Maximal contrast 设置可显示的最大对比度。启用 Automatic adjustment 时显示。
  • Brightness 将亮度设为固定值。关闭 Automatic adjustment 时显示。
  • Contrast 将对比度设为固定值。关闭 Automatic adjustment 时显示。

导入与导出设置

这些设置在导入输入或保存项目时生效。

Use relative image paths 启用（设为 Yes）后，项目文件（.rsproj）中的输入路径将以相对路径保存。
Group calibration by exif 若要根据 EXIF 数据自动对相机参数分组，在把图像加入项目时把此参数设为 Yes。分组详情见 此处。
Copy imported components to cache 若缓存位于 SSD、且希望加快组件访问速度，可设为 Yes。
Ignore exif GPS 若图像的 EXIF 中含 GPS 坐标，可在此全局开启/关闭其使用。也可以在 sensorsdb.xml 中按相机单独设置。
Prefer Exif over XMP 启用后，导入新文件时 Exif 元数据优先于 XMP 元数据。

处理结束通知

处理结束后，可用这些设置定义一个立即执行的后续动作。

Minimal process duration 设置最短处理时长，超过后 RealityScan 才执行通知任务。单位为秒，实际使用建议大于 60。
Action 选择上述时间到达后要执行的动作：无 / 播放声音 / 执行程序。选择「执行程序」时，还可定义命令行参数（例如错误信息、时长、处理类型、RealityScan 设置、场景名称），用于调用外部程序。

例如：

在设置面板的 Command-line process 字段中写入以下命令序列：

"C:\Users\user\Desktop\post-op.bat" "处理 $(processId) 已在场景 $(sceneName) 上完成，结果码 $(processResult)，耗时 $(processDuration:d) 秒"
注意：若文件路径含空格，必须用双引号（""）括起来，如示例 "C:\Users\user\Desktop\post-op.bat"。

创建一个 "post-op.bat" 文件，内含把处理结果写入「以当前日期和时间命名」的文件的命令：

@echo off
cd %~dp0
echo %1>"RS_%date:~-4,4%%date:~-8,2%%date:~-12,2%_%time:~0,2%%time:~3,2%%time:~6,2%.log"

%date:~-4,4% 是当前日期的最后四个字符（年）。
%date:~-8,2% 是从右数第 8、7 个字符（月）。
%date:~-12,2% 是从右数第 12、11 个字符（日）。

时间的处理方式相同。
日期和时间格式取决于 Windows 的区域与语言设置。要查看实际格式，请在命令提示符窗口中执行以下命令：

echo %DATE%
echo %TIME%

处理完成（且满足 Minimal process duration）后，会生成一个 RS_date_time.log 文件，内容形如：

"处理 020735 已在场景 New scene 上完成，结果码 00，耗时 120 秒"

屏幕录制

RealityScan 集成了文档记录系统，可在工作流中录制视频。屏幕录制会抓取窗口区域，按下面设定的质量、分辨率和帧率存到磁盘。系统会自动识别是否有耗时处理正在运行；若有，则自动降低抓取频率并加速播放，使每个处理在最终视频中最多占 8 秒，无论实际耗时多久。这样你就不必担心出现几小时毫无变化的视频。

  • Output folder 屏幕录制工具生成的文档存放位置。另见这个简短教程：Video Screen Grabber。
  • File prefix 屏幕录制生成的视频的文件前缀。
  • Frames per second 设置帧率。
  • Stop when process finished 设为「是」时，处理完成后屏幕录制会自动停止。
  • Play sound on start/stop 若希望在录制开始/结束时收到提示音，设为「是」。
  • Output type 可选输出类型：JPG/PNG 序列帧、Windows Media Video，或 mp4 视频。
  • Resolution SVGA 800x600 / 720p HD ready / 1080p Full HD / 4k / 窗口大小。
  • Bit rate 256/400/700/1500/2500/4000 kbps 或 40/80 mbps。详情可展开应用设置面板该行的下拉菜单。
  • Audio recording 在视频中同时录制默认音源的音频。可选：无音频 / 普通质量（96 kbps）/ YouTube 质量（128 kbps）/ 明星质量（160 kbps）。

Epic Games 账户

在 RealityScan 中退出账户；若之前跳过了登录，也可在此登录。

  • Signed in as 当前登录的 Epic Games 账户。若跳过了登录，则不显示具体用户。
  • Sign out 退出 RealityScan。
  • Sign in with Epic Games 若你之前跳过了登录，会显示此选项，方便之后登录 Epic Games 账户。
