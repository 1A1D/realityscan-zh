开始按钮

Start 按钮提供了一键自动建模的方式，直接在界面内完成。根据当前设置配置，它可以生成简化模型，并从高模重投影纹理，同时生成法线图层。

要运行自动流程，请使用 WORKFLOW 功能区 Process 区域的 Start 按钮。直接点击按钮即运行自动流程；打开下拉菜单则可选择启动流程或进入工具设置。同一功能区中还有其他工具，部分已包含在自动流程里，其余则是把工作流中常用的工具放在便于取用的位置。

处理设置

从按钮的下拉菜单打开 Start 按钮设置，即可打开 Start Button Settings 面板。

  • Mask background with AI 启用后可将图像背景与目标物体分离，并生成遮罩图层图像。
  • Alignment precision 设置对齐精度，它同时影响对齐质量与速度。选 High 等同于在 ALIGNMENT 功能区点击 Align Images 按钮所执行的流程。
  • Select component 选择对齐之后用于后续处理的组件。
  • Reconstruction region 设为 Automatic 可根据稀疏点云大小自动生成重建区域。选 Do not restrict 可禁用重建区域，但不推荐。
  • Reconstruction mode 选 Preview 可快速重建、细节较低；选 Normal 为兼顾细节与速度的平衡模式；选 High 分辨率最高，但计算时间更长。
  • Mesh filtration 启用后，模型中与最大连通部分不相连的部件会被过滤掉，可用来清除漂浮或断开的几何。
  • Colors and texturing 选择给模型上色的方式。White color scheme 会让模型保持无色的实体显示。Per-vertex color 为每个网格顶点计算颜色并在三角面上插值（等同 Colorize 工具）。Textures 会生成 UV 展开并据此为模型贴纹理（等同 Texture 工具）。Both vertex colors & textures 同时应用顶点着色与纹理。
  • Texturing settings 这些设置仅在勾选生成纹理时可用。
    • Texturing style The Visibility-based 风格速度快，能生成锐利的纹理。 Photo-consistency based 风格较慢，但生成的结果更精细、更复杂。 Mosaicing based 风格（实验性）会把模型表面划分为若干区域，每个区域只用单一图像来源贴图，并在接缝处混合。与对多个来源纹理取平均的混合方法不同，这种方式的结果比 Visibility-based 风格更锐利，但速度更慢，不建议用于大型数据集。 Maximal intensity, Minimal intensity, and Average intensity 风格会依据观测该点的所有相机，为每个点赋予单色强度值。
    • Maximal texture count 选择要生成的纹理数量。若数据足够，应用会尝试生成 8K 纹理。
  • Smooth 启用后对模型进行平滑，等同于运行 Smooth 工具。
  • Simplify 启用后简化模型，相当于 Simplify 工具。
  • Simplification settings 这些设置仅在启用简化时可用。
    • Type 按目标三角面数的定义方式来选择简化类型；根据所选类型会显示不同的附加设置。
  • Color reprojection 启用后把颜色（纹理）从初始模型重投影到简化模型上。仅在启用 Simplify 时可用。
  • Normal reprojection 启用后把法线贴图从初始模型重投影到简化模型上。仅在启用 Simplify 时可用。
