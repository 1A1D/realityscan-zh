地图（报告中可用的函数与变量）

地图

ExportMap —— 该函数创建并保存一块地图裁剪图。

语法：

  $ExportMap( mapSourceIndex or "mapSourceName", destinationImagePath, lonWest, lonEast, latSouth, latNorth, width, height )

参数：

mapSourceIndex 或 "mapSourceName" —— 地图提供者的 ID 值或完整名称，可在安装目录下的 mapproviders.xml 中找到。

destinationImagePath —— 相对于附件文件夹的路径，或形如 global://globalPathToFile 的路径

lonWest —— 用于构成地图裁剪边界的西经坐标值（lonWest 不能与 lonEast 相同）

lonEast —— 用于构成地图裁剪边界的东经坐标值（lonEast 不能与 lonWest 相同）

latSouth —— 用于构成地图裁剪边界的南纬坐标值（-90 <= latSouth，latNorth <= 90，latSouth < latNorth）

latNorth —— 用于构成地图裁剪边界的北纬坐标值（-90 <= latSouth，latNorth <= 90，latSouth < latNorth）

width —— 地图图像的宽度

height —— 地图图像的高度

GetExportedMapInfo —— 该函数返回已导出地图的信息。

语法：

  $GetExportedMapInfo( mapFilepath, anyText )

参数：

mapFilePath 或 "mapSourceName" —— 本次报告导出会话中保存的地图路径，应与 ExportMap 中使用的路径一致。

可用变量：

requestedWest —— 设置的、用于构成地图裁剪边界的西经坐标值

requestedEast —— 设置的、用于构成地图裁剪边界的东经坐标值

requestedSouth —— 设置的、用于构成地图裁剪边界的南纬坐标值

requestedNorth —— 设置的、用于构成地图裁剪边界的北纬坐标值

exportedWest —— 构成导出地图边界的西经坐标值

exportedEast —— 构成导出地图边界的东经坐标值

exportedSouth —— 构成导出地图边界的南纬坐标值

exportedNorth —— 构成导出地图边界的北纬坐标值

可用的表达式函数

MapProviderCredentialsAreValid —— 结果为 BOOL 值（true/false）。若提供者有效，返回 "true"。

语法：

  MapProviderCredentialsAreValid( mapSourceIndex or "mapSourceName" )

参数：

mapSourceIndex 或 "mapSourceName" —— 地图提供者的 ID 值或完整名称，可在安装目录下的 mapproviders.xml 中找到。

MapProviderCredentialsAreNeeded —— 结果为 BOOL 值（true/false）。若需要凭据，返回 "true"。

语法：

  MapProviderCredentialsAreNeeded( mapSourceIndex or "mapSourceName" )

参数：

mapSourceIndex 或 "mapSourceName" —— 地图提供者的 ID 值或完整名称，可在安装目录下的 mapproviders.xml 中找到。
