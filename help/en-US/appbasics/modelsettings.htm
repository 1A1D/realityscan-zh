重建设置

与重建过程相关的设置位于 MESH & COLOR 选项卡的 建立网格 区域。

图像深度图计算

模型计算的第一步是逐张图像计算深度图，这里可以设置这一阶段的参数。该阶段主要使用 GPU，请关闭所有占用 GPU 的程序以降低显存占用。

提示：在模型计算之前，可以通过多选图像并在选中输入面板中，把不想参与计算的图像排除。


  • Preview model 这些设置仅在你使用“预览质量”模型计算时生效。
    • Image downscale 计算深度图时，图像会按此系数降采样，而不用原始分辨率。数值越大计算越快，但细节越少。取 1 表示尺度不变（100% 分辨率）；取 2 表示图像每边缩小为原来的二分之一（即原分辨率的 25%），依此类推。
    • Maximal depth-map pixel count 深度图的最大像素数。该值不会覆盖 Image downscale，两者都会生效并可能影响分辨率。默认值 0 表示忽略此设置；要使用它，请设一个较高的值。
  • Normal model 这些设置仅在你选择“正常质量”模型计算时生效。
    • Image downscale 计算深度图时，图像会按此系数降采样，而不用原始分辨率。数值越大计算越快，但细节越少。取 1 表示尺度不变（100% 分辨率）；取 2 表示图像每边缩小为原来的二分之一（即原分辨率的 25%），依此类推。而 High Detail 网格重建模式始终使用全分辨率（值 1），因此不包含此选项。
    • Maximal depth-map pixel count 深度图的最大像素数。该值不会覆盖 Image downscale，两者都会生效并可能影响分辨率。默认值 0 表示忽略此设置；要使用它，请设一个较高的值。

NOTE: Downscale for depth maps （在 1Ds 的 Selected input(s) 面板中为所选图像设定）× Image downscale （在 Reconstruction settings 中设定）＝ 所选图像用于深度图计算时的最终降采样系数。

LiDAR 扫描

在模型计算中使用 LiDAR 扫描时，会用到这些设置。


  • Minimal distance between two points 用此设置定义模型中与扫描相关部分的最终密度。不过来自图像（摄影测量）的部分可能更密。要控制最终模型的整体密度，请使用 网格计算 / 两顶点间最小距离。
  • Point-cloud cropping radius 距扫描仪位置超过该值的点将不参与模型计算。当你已知远处点精度较低、不希望它们进入最终模型时，用此设置。
  • Minimal intensity 用此设置排除强度低于该值的点。请参考扫描仪规格。通常低强度点的精度不足，你可能不希望它们参与重建。
  • Filtering based on classification 选择哪些 LiDAR 类别参与网格创建、哪些排除。为便于选择，也可以一次性全部启用或禁用。

网格计算

网格在深度图计算完成后创建，这些参数用于控制最终网格的属性。


  • GPU acceleration 启用可加快网格计算，默认已开启。
  • Remove marginal triangles 启用后会移除边缘三角面，得到非水密网格。
  • Minimal distance between two vertices 用此设置定义模型的最终密度。警告：仅在你确定模型尺度时才使用。若场景已地理参考，该数值的单位是米/英尺。下个项目再做模型计算前，别忘了相应修改。
  • Preview model 这些设置仅在你选择“预览质量”模型计算时生效。以预览模式计算的模型始终是单分块（singleton），即只包含一个分块。
    • 网格计算策略 你可以选择 Use sparse point cloud。如果使用此设置，那么 影像深度图计算 / 预览模型 / 影像降采样 and 网格计算 / 预览模型 / 最大顶点数 将不会被使用，并会因无关而隐藏。或者你也可以选择 Max vertex count。使用此选项可以定义最终模型可包含的最大顶点数，此时会估算一个合适的抽稀系数；当然，最终顶点数不会与你设定的完全一致。
    • Max vertex count 当 Mesh calculation strategy 设为 Max vertex count 时显示此项。它定义最终模型可包含的最大顶点数，此时会自动估算合适的抽稀系数。当然，实际顶点数不会与你设定的完全一致。

高级


  • Maximal vertex count per part 定义单个部件中的最大顶点数，不建议修改。
  • Detail decimation factor 值越大，细节越少，最终模型的三角面数也越少。
  • Depth map algorithm version 选择计算深度图所用的算法版本（版本 1 为旧版算法）。
  • Adaptive blending start 主要用于 LiDAR 扫描和度量数据，决定将要生成的细节层级。值越大细节越多，不建议改用非默认值（0.45）。
  • Smoothing 平滑设置的作用类似 Smooth 工具，数值越大模型越平滑。
  • Photogrammetry settings
    Default grouping factor and Low-texture grouping factor 决定网格顶点的最终密度。
    Default noise factor and Low-texture noise factor 决定网格的最终平滑程度。
    • Default grouping factor 默认密度。若设为 2，顶点数应减少为原来的四分之一（2×2=4）。设为高于默认值也可能损失细节。当图像对网格质量有负面影响时也可用此设置；当图像与 LiDAR 扫描一起用于构建网格时，提高该值意味着优先使用激光扫描数据来构网。
    • Low-texture grouping factor 值越大，网格中纹理较弱部分的顶点密度越低。
    • Default noise factor 噪声系数越大，网格越平滑。设得比默认值更高时也会丢失细节。
    • Low-texture noise factor 值越大，网格中纹理较弱的部分越平滑。
  • Mesh filtration settings
    • Filter radius 滤波半径用于深度图计算，此设置不应修改。
    • Filter strength 滤波强度用于深度图计算，不建议修改此设置。
  • Model import settings
    • Maximal vertex count per part 定义导入模型单个分块的最大顶点数。
