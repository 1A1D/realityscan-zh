组件工作流

组件是模型的一部分 —— 一组对齐到一起的图像。有时对齐后会得到多个组件，原因可能是照片集中含有多个互不相连的物体、物体纹理太弱、图像数量不足，或视角变化过大。

合并或修复场景

组件有多种用途，其中最重要的几项是：

  • 把场景拆成小块来创建、逐块检查，之后再合并成一个整体。

    有时把任务先拆小再合并会更方便，尤其是在做大型重建时。比如你在扫描一座城堡：可以先分别对齐每个房间的照片，再把房间合并成楼层，把楼层合并成完整内部，最后把内部与外部合并。需要多台电脑并行处理时，使用组件格外有用。组件框架只保留与组件连接相关的信息、而不是全部输入数据，因此在计算资源有限的情况下也能高效地创建超大型重建。

  • To correct an existing scene, e.g. cracks on walls.

    场景里有时会出现一些不需要的瑕疵，原因可能是反光、图像缺失、对齐错误等等。借助组件框架，可以把场景中有问题的部分选中并导出为一个组件，再把这个组件导入一个空场景，通过添加控制点、补充图像或添加约束的方式单独修复，最后把修好的组件导回原场景并按下 Align Images 按钮。RealityScan 引擎会把修正后的组件中的修复应用过来。


导出组件

任意一组已对齐的相机都可以导出为组件。

  • 选择要导出的模型部分（图像 / 相机 / 点）。若要导出全部组件，保持选择为空。
  • 要导出组件，请点击 ALIGNMENT 选项卡 Export 区域中的 Registration 按钮。
  • 弹出的是几种另存格式。导出组件时务必选第一个（RealityScan alignment component —— 只有它保留应用的全部特性），输入名称、选择目标文件夹，然后点击 Save：
  • 当前选择为空、或只选中一台相机时，会导出完整组件。
  • 若组件上放置了控制点，它们也会随组件一起导出。

导入组件

RealityScan 对齐组件实际上是一个小型场景文件，内含图像列表、图像属性、相机位姿等。你可以向项目添加任意多个组件。组件中也可能包含重复的图像或点。

  • 要导入组件，找到 WORKFLOW 选项卡的 Import Metadata 区域，点击 Component。另一种方式是直接把组件文件（保存在磁盘上）拖放到项目的 1Ds 视图中。
  • 注意：导入的组件在 1Ds 视图中会带一个小星标。
  • 若导入组件中的控制点与项目中已有控制点同名但位置不同，导入时会以「导入组件名」为后缀重命名该控制点。

与组件相关的实用设置

根据组件类型，可以选择希望纳入组件新对齐的特征（按每个组件分别设置），从而采用更多组件整合策略。操作位置在选中输入面板的 Features source：


  • Merge using overlaps 软件只使用各组件共有的图像/点（在所有组件中都相同）= 两个组件中相同图像的重叠部分，见下方插图。按重叠合并组件能极大加快重建速度，同时降低内存占用。

  • Use component features 最常用、最快的一种，内存紧张时尤其有用。选中后，应用只使用导入组件对齐时用到的点，因此创建组件时应尽量让它们有更多共同点。
  • Use all image features 三种方式中最慢，适合相机位姿数量不多的情况。程序会使用全部图像/点。
