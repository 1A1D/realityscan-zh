在三维中选择点

图像对齐后若想选中一些点，请在 SCENE 3D/TOOLS 选项卡的 Registration & Sparse Point Cloud 区域选择一个工具。可选的选择工具有：

  • Point Rect：按住左键并移动鼠标，用矩形选择点。
  • Point Lasso：按住左键并移动鼠标，沿环状轨迹选择。
  • Expand：先部分选中一些三维点，再点击 Expand 按钮。该工具会把「某组相机可见的三维点」这一选择，扩展为这些相机能看到的全部点。
  • Select All：若已选中部分点，此按钮会选中当前三维场景中的全部三维点。
  • Deselect：清除当前所有三维点（及相机）的选择。
  • Find Points：选中若干相机，点击 Find Points，所选相机可见的全部点都会被选中。

提示：也可以用以下方式修改选择： CTRL for union, SHIFT for subtraction, and CTRL + SHIFT for intersection.

以下工具与上述工具密切相关：

  • Find Images 会选中能看到所选点云的全部相机。
  • Find Control Points 会找出并选中所选图像中的全部控制点。

点云导出

ALIGNMENT 选项卡 Export 区域的 Sparse Point Cloud 按钮会导出场景中的全部连接点，与当前的点选择无关。
先选择格式和点云文件的保存路径，随后会弹出下面的对话框：



Coordinate system

  • Grid plane - 与 3Ds 视图中看到的一致。
  • Project output - 仅在模型已完成地理参考时可用。输出坐标系可在 WORKFLOW 选项卡 / Application / Settings / Coordinate systems 中选择。
  • Shifted project output - 与 Project output 相同，只是平移到重建体的中心。

Move X / Y / Z - 按坐标系定义的单位沿任意方向移动对象，默认单位为米。
Scale X / Y / Z - 通过改变默认缩放数值来缩放坐标，例如把单位从米换成厘米时很有用。
