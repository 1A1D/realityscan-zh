正射投影（报告中可用的函数与变量）

正射投影

IterateOrthoProjections —— 该函数遍历所选的正射投影；若没有选中任何投影，则遍历全部正射投影。

语法：

  $IterateOrthoProjections( noParametersJustAnyText )

可用变量：

orthoIndex —— 正射投影的索引

orthoGuid —— 正射投影的 GUID

orthoName —— 正射投影的名称

示例：

  $IterateOrthoProjections(
    orthoIndex: $(orthoIndex), orthoGuid: $(orthoGuid), orthoName: $(orthoName)
  )

ExportOrthoProjection —— 该函数用于输出正射投影的信息。

语法：

  $ExportOrthoProjection( orthoGuid, anyText )

参数：

orthoGuid —— 正射投影的 GUID：可用 IterateOrthoProjections 函数获取所选正射投影的 GUID（见下例）

可用变量：

orthoGUID —— 正射投影的 GUID

componentGUID —— 创建该正射投影时所在组件的 GUID

orthoName —— 正射投影的名称

orthoWidth —— 宽度（像素）

orthoHeight —— 高度（像素）

orthoUppx —— 每列像素对应的单位数

orthoUppy —— 每行像素对应的单位数

orthoDepthInOrthoCoordUnits —— 包围盒深度（x 方向长度）

orthoWidthInOrthoCoordUnits —— 包围盒宽度（y 方向长度）

orthoHeightInOrthoCoordUnits —— 包围盒高度（z 方向长度）

orthoType —— 正射投影的类型

orthoCoordSystem —— 坐标系

orthoCoordProjection —— 投影

orthoCoordPrimeMeridian —— 本初子午线

orthoCoordUnits —— 单位

orthoCoordUnitsShort —— 单位的短名

orthoCentreLat —— 包围盒中心的纬度（该变量及随后 10 个变量仅当正射投影类型为 "Map (GPS)"、即 orthoType 值为 "Map (GPS)" 时有效，且以 epsg:4326 - GPS（WGS 84）坐标系导出）

orthoCentreLon —— 包围盒中心的经度

orthoCentreAlt —— 包围盒中心的高程

orthoCornerNWLat —— 正射投影西北角的纬度

orthoCornerNWLon —— 正射投影西北角的经度

orthoCornerNELat —— 正射投影东北角的纬度

orthoCornerNELon —— 正射投影东北角的经度

orthoCornerSELat —— 正射投影东南角的纬度

orthoCornerSELon —— 正射投影东南角的经度

orthoCornerSWLat —— 正射投影西南角的纬度

orthoCornerSWLon —— 正射投影西南角的经度

示例：

  $IterateOrthoProjections(
    $ExportOrthoProjection( "$(orthoGuid)",
      GUID: $(orthoGUID)
      Component GUID: $(componentGUID)
      Ortho projection name: $(orthoName)
      Width [pixels]: $(orthoWidth)
      Height [pixels]: $(orthoHeight)
      Units per column pixel: $(orthoUppx)
      Units per row pixel: $(orthoUppy)
      Bounding box depth: $(orthoDepthInOrthoCoordUnits)
      Bounding box width: $(orthoWidthInOrthoCoordUnits)
      Bounding box height: $(orthoHeightInOrthoCoordUnits)
      Ortho projection type: $(orthoType)
      Coordinate system: $(orthoCoordSystem)
      Projection: $(orthoCoordProjection)
      Prime meridian: $(orthoCoordPrimeMeridian)
      Units: $(orthoCoordUnits)
      Units short name: $(orthoCoordUnitsShort)
      Bounding box centre: lat: $(orthoCentreLat), lon: $(orthoCentreLon), alt: $(orthoCentreAlt)
      NW corner: lat: $(orthoCornerNWLat), lon: $(orthoCornerNWLon)
      NE corner: lat: $(orthoCornerNELat), lon: $(orthoCornerNELon)
      SE corner: lat: $(orthoCornerSELat), lon: $(orthoCornerSELon)
      SW corner: lat: $(orthoCornerSWLat), lon: $(orthoCornerSWLon)
    )
  )

SaveOrtho —— 该函数把正射影像保存到所选文件夹。

语法：

  $SaveOrtho( orthoGuid, inputLayer, filePath, width, height )

参数：

orthoGuid —— 正射投影的 GUID：可用 IterateOrthoProjections 函数获取所选正射投影的 GUID（见下例）

inputLayer —— 可选值：DSM 图层用 "color"、"altitude" 或 "depth"；DTM 图层（若存在）用 "color@1"、"altitude@1" 或 "depth@1"

filePath —— 相对于附件文件夹的路径，或形如 global://globalPathToFile 的路径

width —— 宽度（像素）

height —— 高度（像素）

示例：

  $IterateOrthoProjections(
    $SaveOrtho( "$(orthoGuid)", "color", "ortho_$(orthoIndex)_color.jpg", 800, 800 )
  )

SaveOrthoWithRegions —— 该函数把带区域的正射影像保存到所选文件夹。

语法：

  $SaveOrthoWithRegions( orthoGuid, inputLayer, filepath, width, height )

参数：

orthoGuid —— 正射投影的 GUID：可用 IterateOrthoProjections 函数获取所选正射投影的 GUID（见下例）

inputLayer —— 可选值：DSM 图层用 "color"、"altitude" 或 "depth"；DTM 图层（若存在）用 "color@1"、"altitude@1" 或 "depth@1"

filePath —— 相对于附件文件夹的路径，或形如 global://globalPathToFile 的路径

width —— 宽度（像素）

height —— 高度（像素）

示例：

  $IterateOrthoProjections(
    $SaveOrthoWithRegions( "$(orthoGuid)", "color", "ortho_$(orthoIndex)_color.jpg", 800, 800 )
  )

BeginOrthoProjections —— 该函数内含 Project 函数，用于把三维点投影到正射影像中。

语法：

  $BeginOrthoProjections( orthoGuid, width, height, anyText )

参数：

orthoGuid —— 正射投影的 GUID：可用 IterateOrthoProjections 函数获取所选正射投影的 GUID（见下例）

width —— 宽度（像素）

height —— 高度（像素）

可用函数：

Project

语法：

  $Project( x, y, z, anyText )

参数：

x —— 三维点的 x 坐标

y —— 三维点的 y 坐标

z —— 三维点的 z 坐标

可用变量：

oxpx —— 投影点的 x 坐标

oypx —— 投影点的 y 坐标

示例：

  $IterateOrthoProjections(
    $BeginOrthoProjections( "$(orthoGuid)", 100, 100,
      $ExportControlPoints(
        $Project( euclidx, euclidy, euclidz,
          oxpx: $(oxpx)
          oypx: $(oypx)
        )
      )
    )
  )

IterateOrthoMapTiles —— 该函数仅对已做地理配准的组件可用。

语法：

  $IterateOrthoMapTiles( orthoGuid, inputLayer, anyText )

参数：

orthoGuid —— 正射投影的 GUID：可用 IterateOrthoProjections 函数获取所选正射投影的 GUID（见下例）

inputLayer —— 可选值：DSM 图层用 "color"、"altitude" 或 "depth"；DTM 图层（若存在）用 "color@1"、"altitude@1" 或 "depth@1"

可用函数：

SaveOrthoMapTile —— 用于保存正射影像的瓦片。导出的瓦片可用于展示正射影像，例如在 Google Maps 中。每块瓦片为 256 x 256 像素。

语法：

  $SaveOrthoMapTile( "filePath" )

参数：

filePath —— 相对于附件文件夹的路径，或形如 global://globalPathToFile 的路径。支持的格式：png、bmp、dib 与 tiff。

SaveOrthoMapTileMask —— 用于保存带遮罩的正射影像瓦片。导出的瓦片可用于展示正射影像，例如在 Google Maps 中。每块瓦片为 256 x 256 像素。

语法：

  $SaveOrthoMapTileMask( "filePath" )

参数：

filePath —— 相对于附件文件夹的路径，或形如 global://globalPathToFile 的路径。支持的格式：png、bmp、dib 与 tiff。

可用变量：

tileX —— 瓦片索引的第一部分：自西向东递增

tileY —— 瓦片索引的第二部分：自北向南递增

tileZ —— 瓦片索引的第三部分：缩放级别

示例：

  $IterateOrthoProjections(
    $IterateOrthoMapTiles( "$(orthoGuid)", "color",
      $SaveOrthoMapTile("$(orthoIndex)-color_$(tileZ)_$(tileX)_$(tileY).png")
    )
  )

IterateOrthoMapPalette —— 该函数遍历正射投影高程或深度图层调色板的颜色与数值。

语法：

  $IterateOrthoMapPalette( orthoGuid, inputLayer, anyText )

参数：

orthoGuid —— 正射投影的 GUID：可用 IterateOrthoProjections 函数获取所选正射投影的 GUID（见下例）

inputLayer —— 可选值："altitude" 或 "depth"

可用变量：

orthoMapPalIndex —— 索引范围为 0 到 255

orthoMapPalRed —— RGB 颜色的红色分量，取值范围 0 到 255

orthoMapPalGreen —— RGB 颜色的绿色分量，取值范围 0 到 255

orthoMapPalBlue —— RGB 颜色的蓝色分量，取值范围 0 到 255

orthoMapPalValue —— 高程或深度值

示例：

  $IterateOrthoProjections(
    $ExportOrthoProjection( "$(orthoGuid)",
      $IterateOrthoMapPalette( "$(orthoGuid)", "altitude",
        Index: $(orthoMapPalIndex)
        Red: $(orthoMapPalRed)
        Green: $(orthoMapPalGreen)
        Blue: $(orthoMapPalBlue)
        Altitude: $(orthoMapPalValue:.2f) $(orthoCoordUnitsShort)
      )
    )
  )

IterateOrthoMeasurements —— 该函数遍历正射测量值。

语法：

  $IterateOrthoMeasurements( orthoGuid, anyText )

参数：

orthoGuid —— 正射投影的 GUID

可用变量：

regionIndex —— 区域的索引

regionColor_A —— alpha 通道值

regionColor_R —— 红色值（RGB）

regionColor_G —— 绿色值（RGB）

regionColor_B —— 蓝色值（RGB）

dimensionality —— 区域的维度（1D/2D）

regionGuid —— 区域的 GUID

regionName —— 区域名称

hasOrthoVolume —— 是否含体积信息（true/false）

hasOrthoArea —— 是否含面积信息（true/false）

hasOrthoBoundary —— 是否不含孔洞（true/false）

cutVolume —— 挖方体积

fillVolume —— 填方体积

area2d —— 区域的面积（2D）

area3d —— 区域的面积（3D）

isClosed —— 是否不含孔洞（true/false）

isAllHoles —— 是否落在正射投影之外（true/false）

orthoPerimeter —— 区域的周长

boundaryMinBoxHeight —— 重建区域的最小高度

boundaryMaxBoxHeight —— 重建区域的最大高度

boundaryMinOrthoCSHeight —— 正射投影坐标系中的最小高度

boundaryMaxOrthoCSHeight —— 正射投影坐标系中的最大高度

numPolygonVertices —— 多边形中的顶点数量

numBoundarySamples —— 边界采样点数量

boundaryMinAltitude —— 若正射投影已做地理配准，则为区域的最小高程

boundaryMaxAltitude —— 若正射投影已做地理配准，则为区域的最大高程

gpsPerimeter —— 若正射投影已做地理配准，则为区域的周长

示例：

  $IterateOrthoProjections(
    $IterateOrthoMeasurements( "$(orthoGuid)",
      Region index: $(regionIndex )
      Alpha channel value: $(regionColor_A)
      Red value (RGB): $(regionColor_R)
      Green value (RGB): $(regionColor_G)
      Blue valuere: $(regionColor_B )
      Dimensionality: $(dimensionality)
      RegionGuid: $(regionGuid)
      Region name: $(regionName)
      Has volume: $(hasOrthoVolume)
      Has area: $(hasOrthoArea)
      Has boundary: $(hasOrthoBoundary)
      Cut volume: $(cutVolume)
      Fill volume: $(fillVolume)
      Area of the region (2D): $(area2d)
      Area of the region (3D): $(area3d)
      Is closed: $(isClosed)
      Off ortho: $(isAllHoles)
      Perimeter: $(orthoPerimeter)
      Minimal box height: $(boundaryMinBoxHeight)
      Maximal box height: $(boundaryMaxBoxHeight)
      Minimal box height in ortho CS: $(boundaryMinOrthoCSHeight)
      Maximal box height in ortho CS: $(boundaryMaxOrthoCSHeight)
      Polygon vertices: $(numPolygonVertices)
      Boundary samples: $(numBoundarySamples)
      Minimal altitude (georeferenced): $(boundaryMinAltitude )
      Maximal altitude (georeferenced): $(boundaryMaxAltitude )
      Perimeter (georeferenced): $(gpsPerimeter )
      )
    )
  )

IterateOrthoBoundarySamples —— 该函数遍历区域的边界点（2D）。

语法：

  $IterateOrthoBoundarySamples( regionGuid, start, step, end, anyText )

参数：

regionGuid —— 区域的 GUID

start —— 第一个点的索引

step —— 沿边界的点数步长

end —— 若步长为正，最后一个点的索引是小于 end 的最大数；若步长为负，则是大于 end 的最小数

可用变量：

pointIndex —— 点的索引

isHole —— 是否落在正射投影之外（true/false）

boxX —— 点在重建区域中的 X 坐标

boxY —— 点在重建区域中的 Y 坐标

boxZ —— 点在重建区域中的 Z 坐标

orthoX —— 点在正射投影坐标系中的 X 坐标

orthoY —— 点在正射投影坐标系中的 y 坐标

orthoZ —— 点在正射投影坐标系中的 z 坐标

orthoDistanceFromStart —— 在正射投影坐标系中距起始点的距离

euclidx —— 欧氏坐标系中的 x 坐标

euclidy —— 欧氏坐标系中的 y 坐标

euclidz —— 欧氏坐标系中的 z 坐标

longitude —— 经度（GPS）

latitude —— 纬度（GPS）

altitude —— 高程（GPS）

gpsDistanceFromStart —— 在 GPS 系统中距起始点的距离

示例：

  $IterateOrthoProjections(
    $IterateOrthoMeasurements( "$(orthoGuid)", 
      $IterateOrthoBoundarySamples( "$(regionGuid)", 1, 50, 1000,
        Point index: $(pointIndex)
        Is hole: $(isHole)
        Box X: $(boxX)
        Box Y: $(boxY)
        Box Z: $(boxZ)
        Ortho X: $(orthoX)
        Ortho Y: $(orthoY)
        Ortho Z: $(orthoZ)
        Distance from start: $(orthoDistanceFromStart)
        Euclidean x: $(euclidx)
        Euclidean y: $(euclidy)
        Euclidean z: $(euclidz)
        GPS longitude: $(longitude)
        GPS latitude: $(latitude)
        GPS altitude: $(altitude)
        GPS distance from start: $(gpsDistanceFromStart)
      )
    )
  )

IteratePolylines —— 遍历某条等高线的折线。

语法：

  $IteratePolylines( noParametersJustAnyText )

可用变量：

polylineLastPointX —— 折线中最后一个点的图像 X 坐标

polylineLastPointY —— 折线中最后一个点的图像 Y 坐标

polylineLastPointZ —— 折线中最后一个点的图像 Z 坐标

polylineFirstPointX —— 折线中第一个点的图像 X 坐标

polylineFirstPointY —— 折线中第一个点的图像 Y 坐标

polylineFirstPointZ —— 折线中第一个点的图像 Z 坐标

polylineRealLength —— 折线在世界度量下的长度

polylineRealLengthImg —— 折线的长度（像素）

polylineIndex —— 折线的索引值

polylineIsClosed —— 该变量表示折线是否闭合（即首尾点是否不同）

polylinePointCount —— 折线中的点数

可用函数：

IteratePoints —— 遍历构成折线的各个点。

语法：

  $IteratePolylines( noParametersJustAnyText )

可用变量：

pointX —— 点的图像 X 坐标

pointY —— 点的图像 Y 坐标

pointZ —— 点的图像 Z 坐标

pointIndex —— 折线中的点数

示例：

  $IterateOrthoProjections( 
    $Declare("setID", GetSelectedContourSetId("$(orthoGuid)"))
    $ExportOrthoProjection( "$(orthoGuid)", 
      $Declare("pixelSize" , GetSimplifyingFactor(orthoUppx))
      $ExportContourSet( "$(orthoGuid)", setID, pixelSize,
        Contour Set Name: $(contoursName)
        Pixel type: $(contoursPixelType)
        Layer: $(contoursLayer)
        Minimal value: $(contoursMin)
        Maximal value: $(contoursMax)
        Interval: $(contoursInterval)
        Contour count: $(contoursCount)
        $IterateContours(1, contoursCount, 2,
          Altitude: $(contourAltitude)
          $IteratePolylines( 
            Real length: $(polylineRealLength)
            Point count in polyline: $(polylinePointCount)
          )
        )
      )
    )
  )
