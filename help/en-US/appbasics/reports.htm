报告

要导出报告，请点击 WORKFLOW 选项卡 Output 区域的 Reports 按钮。



点击后会要求选择报告保存的文件夹；点 Save 之后会弹出 Export Report 对话框：



选择其中一个可用模板，生成后会自动在浏览器中打开。

预置模板

  • Overview Report - 整个项目的基本统计：输入数、组件数、模型数。
  • Registration and Georeferencing Accuracy Report - 组件的基本信息、相机位置及其与先验位置的偏差、相机的详细信息，以及地面控制点的先验位置与计算位置。
  • Selected Component Report - 所选组件的详细统计：对齐报告、对齐设置、所用控制点的统计以及模型信息。
  • Selected Ortho Projection Report - 所选正射投影的全部信息，包括各图层的预览与地面控制点信息。
  • Selected Model Report - 所选模型的详细统计：纹理信息与处理耗时。
  • Tie Points of Selected Component - 所选组件连接点的全部信息，包括重投影误差与轨迹长度直方图。
  • Map View Report - 把带地面控制点和相机的所选正射投影导出到 Google 地图。注意组件必须已完成地理参考。

修改预置模板与添加新模板

预置模板是 HTML 格式，可以编辑或新建。HTML 模板位于安装目录 C:\Program Files\Epic Games\RealityScan\Reports。也可以通过编辑 CSS 文件来修改和定义报告样式。



Note: We recommend you to 备份编辑过的模板与样式文件 到本地磁盘，因为软件更新或重装会覆盖它们。

若要添加新模板，请到安装目录 C:\Program Files\Epic Games\RealityScan 编辑 report.xml，在其中定义模板文件路径。建议把模板存放在本机硬盘上，以免软件更新或重装时丢失。修改过的样式文件也可以放在本地 —— 样式文件路径直接写在模板里。

模板中还包含特殊函数和变量，详见本教程的下一部分。
