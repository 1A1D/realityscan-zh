全局变量与项目信息（报告中可用的函数与变量）

正如本教程上一部分所述，有些变量和函数会被替换。下面列出全局变量与函数，后续部分还会列出针对点、坐标、颜色、数值、组件等信息的专用变量与函数。

全局变量

dateTime - 输出当前的日期和时间

fileName - 报告文件的名称

appVersion - RealityScan 的版本号

appLanguage - RealityScan 当前所选界面语言的语言标记（代码）

programDataLangPackFolder - 语言包所在文件夹的路径

attachmentPath - fileName 与报告附件文件夹之间的相对路径。除主文件外，所有文件都会自动保存到附件文件夹中。在主文件中可用 attachmentPath 引用附件。

cameraCount - 所选组件中已注册的全部 / 已选相机数量

pointCount - 所选组件中已注册点的数量

measurementCount - 所选组件中测量值的数量

commonWidth - 未畸变图像的宽度

commonHeight - 未畸变图像的高度

isGeoreferenced - 所选组件已地理配准时输出 1，否则输出 0

units - 输出所选组件的测量单位，例如米（meter）

unitsShort - 输出测量单位的简称，例如 m

coordSystemName - 若所选组件已地理配准（isGeoreferenced 的值为 1），则输出坐标系的名称，否则输出 "Grid Plane"

isCoordSystemLatLon - 输出坐标系为地理坐标系时为 true，为笛卡尔坐标系时为 false

coordSystemUnit2Meter - 把坐标系单位换算为米所需的系数

displayScale - 渲染时推荐的一个单位尺寸

true - BOOL 值 "true"

false - BOOL 值 "false"


组件锚点变量

为尽可能提高计算精度，组件在接近零的坐标系中进行计算。锚点（旋转 + 平移）把这样的局部场景变换到全局欧几里得空间。

  EuclideanX = anchor.Rotation * X + anchor
  EuclideanY = anchor.Rotation * Y + anchor
  EuclideanZ = anchor.Rotation * Z + anchor

anchorX - 锚点的 X 坐标

anchorY - 锚点的 Y 坐标

anchorZ - 锚点的 Z 坐标

anchorR00 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR01 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR02 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR10 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR11 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR12 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR20 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR21 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorR22 - 锚点旋转矩阵相对于锚点坐标系的一个元素

anchorYaw - 锚点的偏航角（Yaw）值

anchorPitch - 锚点的俯仰角（Pitch）值

anchorRoll - 锚点的翻滚角（Roll）值

基础函数

If - 仅当条件成立时，该函数才输出指定文本。

语法：

  $If( expression operator expression, anyText )

参数：

expression operator expression - 条件；可用的运算符为：≤ < ≥ > == !=

可以使用逻辑运算符构造更复杂的表达式：

! - 逻辑非运算符

!true == false

!false == true

| | - 逻辑或

true || true == true

false || true == true

true || false == true

false || false == false

&& - 逻辑与

true && true == true

false && true == false

true && false == false

false && false == false

使用逻辑运算符时需注意它们的优先级不同：逻辑与 > 逻辑或 > 相等判断。

示例（注意 isGeoreferenced 和 units 是全局变量）：

  $If( 1 > 0, One is more than zero. )
  $If( 1, One is more than zero. )
  $If( isGeoreferenced == 1, The selected component is geo-referenced. )
  $If( "$(units)" == "meter", The measurement unit of the selected component is meter. )

Map - 该函数把所有变量与表达式比较，只返回最符合比较结果的那一个。比较规则如下：
若 t[i] <= expression < t[i+1]，返回 R[i]；若 expression < t1，返回 R0；若 expression > tn，返回 Rn

语法：

$Map( expression, "R0", t1, "R1", t2, R2, ..., tn, "Rn" )

参数：

expression - 用于保存结果的变量名称

R1, ..., RN - 比较后可能返回的任意值

t1, ..., tN - 与所定义 expression 参数进行比较的任意值（或表达式）

示例（将返回值 #ff1040）：

$Declare( "lvl1", 1 )   $Declare( "lvl1Color", "#fff040" )
$Declare( "lvl2", 1.5 ) $Declare( "lvl2Color", "#ff8040" )
$Declare( "lvl3", 2 )   $Declare( "lvl3Color", "#ff1040" )
$Declare("cpxStd", 3)
$Declare("cpxMeanAcc", 1.5)
"$Map(Abs(cpxStd),"",lvl1*cpxMeanAcc,"$(lvl1Color)",lvl2*cpxMeanAcc,"$(lvl2Color)",lvl3*cpxMeanAcc,"$(lvl3Color)")"

格式化

格式化用于表达式，且始终以字符 ":" 开头。

语法：

[FORM][FILLER][LENGTH].[PRECISION][FORMAT]

参数：

Form 选项：

b - 启用二进制模式

- - 左对齐

+ - 输出正号（仅对数字有效）

Filler 可以是 "0" 或 " "（空格），默认为空格。仅在非二进制形式下有效。

Length 用正数定义，决定被格式化值的总长度。仅在非二进制形式下有效。

Precision 仅对浮点数（FLOAT 或 DOUBLE）有效，且所选 format 须为 f、e 或 g。若选择 f，精度为小数位数；若选择 e 或 g，则为显示的有效位数。

Format 决定值的格式。可用格式为：

c - 以二进制形式表示字节

d - 以十进制形式表示整数

x - 以十六进制形式表示整数

f - 以常规十进制浮点数（32 位）表示

e - 以指数形式表示浮点数

g - 在浮点数的常规十进制形式与指数形式之间选择占用位数更少的一种。

示例：

$(cpxMean/coordSystemUnit2Meter:.3f)

格式化字符串的所有部分均为可选。

$[mode]

b - 该模式会删除所有空白字符

n - 移到下一行的行首

直方图

创建直方图并获取其相关信息。

CreateHistogram - 该函数用于输出直方图，会创建若干步长（区间 / 箱）。每个箱都有大小为 "1/((maxValue-minValue)*steps)" 的区间，初始元素个数为 0。

语法：

  $CreateHistogram(minValue, steps, maxValue, anyText)

参数：

minValue - 直方图的最小值

steps - 步长大小，即箱的宽度

minValue - 直方图的最大值

可用函数：

AddData - 该函数为每个数值找到所属区间并增加其中的元素计数。若数值小于 minValue，则计入第一个箱；同理，若数值大于 maxValue，则计入最后一个箱。

语法：

  $AddData( num1, num2, ..., numN )

参数：

num - 数值

IterateHistogramBins - 遍历直方图的各个箱。

语法：

  $IterateHistogramBins( noParametersJustAnyText )

可用变量：

histTotalSum - 所有箱中数值的总和

histMaxCount - 所有步长中 histCount 的最大值（各步长中该值相同）

histMinValue - 直方图的最小值（纵轴）

histMaxValue - 直方图的最大值（纵轴）

histStepCount - 所定义的步长数量

histIndex - 当前步长的索引

histCount - 区间 ( histValue - steps size, histValue ) 内的数值个数

histValue - 当前区间的上界

histCumsum - 当前及之前所有 histCount 的累计和，最迟在最后一步会等于 histTotalSum

GetHistogramStats - 遍历直方图的各个箱。

语法：

  $GetHistogramStats( noParametersJustAnyText )

可用变量：

histTotalSum - 所有箱中数值的总和

histMaxCount - 所有步长中 histCount 的最大值（各步长中该值相同）

histMinValue - 直方图的最小值（纵轴）

histMaxValue - 直方图的最大值（纵轴）

histStepCount - 所定义的步长数量
