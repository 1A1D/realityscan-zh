本地化

本节说明如何把本应用（界面、帮助系统及部分可导出内容）本地化为另一种语言，并列出对译者的要求。
完成之后，即可在 Application Settings / Visual and language settings / UI Language 中切换到新语言。

要求：请勿更改原有文件夹名称、结构（位置）或文件扩展名。如有疑问，请联系指定人员确认。

第 1 步 - 应用的 XML

翻译界面有 2 种方式：

方式一 - 手动

  1. 需要从 ProgramData 文件夹（通常为 C:\ProgramData\Epic\RealityScan\LanguagePack\languages）复制 en-US\ui.xml 文档。建议新建一个 languages 文件夹（例如 languagesMY），在其中新建子文件夹并按 en-US 的方式命名（参见 语言代码），把复制的 ui.xml 放进去，用文本编辑器打开，从上到下逐条翻译后保存。
    （注意：重新安装、修复或卸载应用时，若文件时间戳较旧，受支持语言的 xml 文件及 languages.xml 会被覆盖或删除。因此建议把成果存放在单独的 languages 文件夹中。）
  2. xml 翻译完成后，把语言描述加入 languages.xml，位置在：ProgramData\Epic\RealityScan。只需复制文件中的一行，修改语言 代码、ID（区域设置标识符）、名称（见上一步）和源文件路径。

方式二 - 使用 RS 翻译工具（推荐）

  1. 请联系我们获取该工具。
  2. 按工具帮助中的说明操作。查看帮助文件的方法：选择一种语言，然后按 F1 或点击工具图标中的问号。
注意：译文会自动保存到 ProgramData（ProgramData\Epic\RealityScan\languagesMY）。若要把最新译文另存到其他文件夹，点击工具菜单中的向下箭头图标。最新译文始终保存在 ProgramData 中。

补充说明

不要翻译（也不要删除）：
&#10;（文本中用于换行的符号），
&amp;（和号；当它出现在词首或词中时，如 &Exit 或 Co&ntinue，符号后紧跟的字母会加下划线，表示该操作有快捷键），
&quot;（单引号的替代符号），
&lt;（小于号的替代符号），
&gt;（大于号的替代符号），
&lt;br/&gt;（换行的替代符号，也可能不带斜杠，或斜杠放在 br 前，或 br 元素后带空格），
<li>（缩进行的替代符号，是起始标签，配套的结束标签为 </li>），
<span>（用于给特定文本设置样式的 span 标签替代符号，<span 与 </span> 之间的内容一律不得翻译），
%s, %d（用于在界面上格式化并显示特定内容的符号），
$(stat), $Get(key), $(minutes:02d)（以美元符号开头的词是变量或函数名，在所有语言版本中必须保持不变，包括美元符号词后面括号内的内容），
postprocess.exe（可执行文件名，以 .exe 结尾的词不得翻译），
name="..."（字符串标识符）。

复数相关结构

xml 文档中有一些命令会自动为词加上指定的复数词尾，或根据表达式关联的实时读数把单数表达替换为对应的复数形式。下面用几个例子说明：

以下是待翻译的 xml 文档中的一行：
命令 '$(cmdName)' 还需要更多参数。请再添加 $(maxParamCount-paramCount) 个参数$if(maxParamCount-paramCount>1,s)。

  • '$(cmdName)' 代表命令名，不要翻译。
  • $(maxParamCount-paramCount) 表示所用命令缺少的参数个数，不要翻译。
  • argument$if(maxParamCount-paramCount>1,s) 是待翻译的词（argument）与一条命令的组合：当它判断参数个数大于 1 时，会自动为该词的复数形式加上指定词尾（此处为 -s，也需翻译）。若你的语言中该规则不同，可能需要对译文中的其他词增删类似结构。
  • 上面这行中的其他文本都需要翻译。

再看一个例子：
正在执行命令 '$(cmdName)'$if(paramCount==1, 参数为 '$(params)')$if(paramCount>1, 参数为 '$(params)')
应用中的输出为：

  • 要么显示：正在执行命令 '$(cmdName)'，参数为 '$(params)'（找到 1 个参数），
  • 要么显示：正在执行命令 '$(cmdName)'，参数为 '$(params)'（找到多个参数）。

提示：可以用下面这条命令通过命令行启动 RealityScan： -translatorMode 并利用面板与窗口中各文本（字符串）的视觉辅助标识（数字即字符串 ID），这样能帮你准确把握语义。

要以这种“译者模式”运行应用：
  1. 打开（Windows）命令提示符，
  2. 在其中输入或粘贴 RealityScan 可执行文件的完整路径，
  3. 后面跟 -translatorMode 命令，
  4. 然后按回车键。

通常形如："C:\Program Files\Epic Games\RealityScan\RealityScan.exe" -translatorMode。


第 2 步 - 帮助

  1. 把整个 Help 文件夹从 C:\Program Files\Epic Games\RealityScan\help\en-US 复制到 C:\Program Files\Epic Games\RealityScan\help。
  2. 按 en-US 的方式重命名。语言代码见 此处。
  3. 用文本编辑器逐个打开 Help 文件夹下的每个 .htm 文件，以及 C:\Program Files\Epic Games\RealityScan\Help\en-US\scripts 中的 textVars.js，翻译后保存到相同位置（文件夹结构必须保持不变）。
警告：当你修改应用中已有的帮助译文时，务必随时备份已翻译的文档。这一步必须在改动应用安装之前完成。

确保按钮、面板、设置和窗口的名称（帮助中通常显示为蓝色）与第 1 步 xml 文档中的译文完全一致，帮助正文中提到的教程名称也要与帮助首页一致。
若遇到维基百科链接，请在浏览器中打开，并把左侧菜单的语言切到你正在翻译的语言；若该语言版本不存在，跳过此步。
不要翻译 html 标签、代码示例（帮助教程中通常为黑底蓝字）和命令名称，也不要删掉任何看不懂的部分。

提示：可用帮助的全文搜索功能快速定位帮助文件中的某段文字；也可以使用快捷键 CTRL+F to browse contents of individual Help pages.

第 3 步 - 报告

报告同样有 2 种翻译方式：

方式一 - 手动

  1. 在此处新建文件夹（若已存在则跳过，见第 2 步）：C:\Program Files\Epic Games\RealityScan\Reports。
  2. 按 en-US 的方式重命名。语言代码见 此处。
  3. 把 C:\Program Files\Epic Games\RealityScan\Reports\en-US 中的所有 xml 文件复制到第 1 步创建的文件夹并翻译。

方式二 - 使用 RS 翻译工具（推荐）

参见上文第 1 步 / 方式二。

注意：译文会自动保存到 ProgramData（ProgramData\Epic\RealityScan\Reports）。若要把最新译文另存到其他文件夹，点击工具菜单中的向下箭头图标。最新译文始终保存在 ProgramData 中。
