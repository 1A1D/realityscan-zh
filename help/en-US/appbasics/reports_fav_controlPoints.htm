控制点与约束（报告中可用的函数与变量）

控制点与约束

IterateControlPoints —— 该函数用于输出所有控制点的基本信息。

语法：

  $IterateControlPoints( noParametersJustAnyText )

可用变量：

controlPointId —— 控制点的索引

controlPointGUID —— 控制点的 GUID

controlPointName —— 控制点名称

controlPointMeasurementsCount —— 测量值数量（即该控制点分配到多少张图像）

示例：

  $IterateControlPoints(
    Index: $(controlPointId)
    GUID: $(controlPointGUID)
    Name: $(controlPointName)
    Images count: $(controlPointMeasurementsCount)
  )

ExportControlPoints —— 该函数含一个函数与若干变量，用于输出所有控制点的信息。

语法：

  $ExportControlPoints( noParametersJustAnyText )

可用变量：

index —— 控制点的索引

name —— 控制点名称

measurementCount —— 测量值数量（即该控制点分配到多少张图像）

isGroundControl —— 若为地面控制点或地面测试点则为 true，否则 false

isGroundTest —— 若为地面测试点则为 true，否则 false

calibrationType —— 连接点为 0，地面控制点为 1，地面测试点为 2

inputCSName —— 控制点输入坐标系的名称

inputCSIsLatLon —— 控制点的输入坐标系为地理坐标则为 true，为直角坐标则为 false

inputCSUnit —— 控制点所在坐标系的单位

inputCSUnitToMeter —— 用于换算单位的乘数

inx —— 控制点输入坐标系中的输入 x 坐标（仅当坐标系为直角坐标、即 inputCSIsLatLon 为 false 时有效）

iny —— 控制点输入坐标系中的输入 y 坐标（仅当坐标系为直角坐标时有效）

inz —— 控制点输入坐标系中的输入 z 坐标（仅当坐标系为直角坐标时有效）

inlat —— 控制点输入坐标系中的输入纬度坐标（仅当坐标系为地理坐标、即 inputCSIsLatLon 为 true 时有效）

inlon —— 控制点输入坐标系中的输入经度坐标（仅当坐标系为地理坐标时有效）

inalt —— 控制点输入坐标系中的输入高程坐标（仅当坐标系为地理坐标时有效）

euclidx —— 欧氏坐标系中的输入 x 坐标

euclidy —— 欧氏坐标系中的输入 y 坐标

euclidz —— 欧氏坐标系中的输入 z 坐标

x —— 输出坐标系中的输入 x 坐标（仅当 isGroundControl 为 true 且输出坐标系为直角坐标、即 isCoordSystemLatLon 为 false 时有效）

y —— 输出坐标系中的输入 y 坐标（仅当 isGroundControl 为 true 且输出坐标系为直角坐标时有效）

z —— 输出坐标系中的输入 z 坐标（仅当 isGroundControl 为 true 且输出坐标系为直角坐标时有效）

lat —— 输出坐标系中的输入纬度坐标（仅当 isGroundControl 为 true 且坐标系为地理坐标、即 isCoordSystemLatLon 为 true 时有效）

lon —— 输出坐标系中的输入经度坐标（仅当 isGroundControl 为 true 且坐标系为地理坐标时有效）

alt —— 输出坐标系中的输入高程坐标（仅当 isGroundControl 为 true 且坐标系为地理坐标时有效）

gpsLat —— epsg:4326 - GPS（WGS 84）坐标系中的输入纬度坐标（仅当该控制点已做地理配准时有效）

gpsLon —— epsg:4326 - GPS（WGS 84）坐标系中的输入经度坐标（仅当该控制点已做地理配准时有效）

gpsAlt —— epsg:4326 - GPS（WGS 84）坐标系中的输入高程坐标（仅当该控制点已做地理配准时有效）

weight —— 控制点的权重

hasUncertainty —— 已为控制点定义先验精度则为 true

uncertaintySize —— 三角化不确定度（坐标系单位）

uncertaintyVectorX —— X 轴方向的三角化不确定度

uncertaintyVectorY —— Y 轴方向的三角化不确定度

uncertaintyVectorZ —— Z 轴方向的三角化不确定度

inAccuracyX —— X 坐标的先验精度

inAccuracyY —— Y 坐标的先验精度

inAccuracyZ —— Z 坐标的先验精度

inA1 —— 先验精度矩阵的元素 a1,1（通常等于 inAccuracyX）

inA2 —— 先验精度矩阵的元素 a1,2（通常等于 0）

inA3 —— 先验精度矩阵的元素 a1,3（通常等于 0）

inA4 —— 先验精度矩阵的元素 a2,1（通常等于 0）

inA5 —— 先验精度矩阵的元素 a2,2（通常等于 inAccuracyY）

inA6 —— 先验精度矩阵的元素 a2,3（通常等于 0）

inA7 —— 先验精度矩阵的元素 a3,1（通常等于 0）

inA8 —— 先验精度矩阵的元素 a3,2（通常等于 0）

inA9 —— 先验精度矩阵的元素 a3,3（通常等于 inAccuracyZ）

isAligned —— 对齐前为 false，对齐后为 true

actualXInCS —— 输入坐标系中的 x 坐标

actualYInCS —— 输入坐标系中的 y 坐标

actualZInCS —— 输入坐标系中的 z 坐标

actualLatInCS —— 输入坐标系中的纬度坐标

actualLonInCS —— 输入坐标系中的经度坐标

actualAltInCS —— 输入坐标系中的高程值

actualXEuclid —— 欧氏坐标系中的 x 坐标

actualYEuclid —— 欧氏坐标系中的 y 坐标

actualZEuclid —— 欧氏坐标系中的 z 坐标

actualX —— 对齐过程中算出的控制点实际位置的 x 坐标（仅当 isAligned 为 true 且输入坐标系为直角坐标、即 inputCSIsLatLon 为 false 时有效）

actualY —— 对齐过程中算出的控制点实际位置的 y 坐标（仅当 isAligned 为 true 且输入坐标系为直角坐标时有效）

actualZ —— 对齐过程中算出的控制点实际位置的 z 坐标（仅当 isAligned 为 true 且输入坐标系为直角坐标时有效）

actualLat —— 对齐过程中算出的控制点实际位置的纬度坐标（仅当 isAligned 为 true 且输入坐标系为地理坐标、即 inputCSIsLatLon 为 true 时有效）

actualLon —— 对齐过程中算出的控制点实际位置的经度坐标（仅当 isAligned 为 true 且输入坐标系为地理坐标时有效）

actualAlt —— 对齐过程中算出的控制点实际位置的高程坐标（仅当 isAligned 为 true 且输入坐标系为地理坐标时有效）

actualGpsLat —— 对齐过程中算出的控制点实际位置在 epsg:4326 - GPS（WGS 84）坐标系中的纬度坐标（仅当 isAligned 为 true 且组件已做地理配准时有效）

actualGpsLon —— 对齐过程中算出的控制点实际位置在 epsg:4326 - GPS（WGS 84）坐标系中的经度坐标（仅当 isAligned 为 true 且组件已做地理配准时有效）

actualGpsAlt —— 对齐过程中算出的控制点实际位置在 epsg:4326 - GPS（WGS 84）坐标系中的高程坐标（仅当 isAligned 为 true 且组件已做地理配准时有效）

可用函数：

ControlPointError

语法：

  $ControlPointError( index, anyText )

参数：

index —— 控制点的索引：可用 ExportControlPoints 函数获取所有控制点的索引（见下例）

可用变量：

cpIndex —— 控制点的索引

cpError3D —— 总偏差：算出的位置与给定位置之间的距离，以输入坐标系单位表示

cpErrorX —— X 方向的对齐误差

cpErrorY —— Y 方向的对齐误差

cpErrorZ —— Z 方向的对齐误差

maxPlacementError —— 最大投影误差：算出位置的最大误差，以像素计

示例：

  $ExportControlPoints(
    Index: $(index)
    Name: $(name)
    Number of measurements: $(measurementsCount)
    Ground control: $(isGroundControl)    
    Ground test: $(isGroundTest)    
    Calibration type: $(calibrationType)  
    Coordinate system name: $(inputCSName)    
    Geographic coordinate system: $(inputCSIsLatLon)    
    Input x: $(inx)    
    Input y: $(iny)    
    Input z: $(inz)    
    Input lat: $(inlat)    
    Input lon: $(inlon)    
    Input alt: $(inalt)    
    Euclidean x: $(euclidx)    
    Euclidean y: $(euclidy)    
    Euclidean z: $(euclidz)
    Input x in output coordinate system: $(x)    
    Input y in output coordinate system: $(y)    
    Input z in output coordinate system: $(z)    
    Input lat in output coordinate system: $(lat)    
    Input lon in output coordinate system: $(lon)    
    Input alt in output coordinate system: $(alt)
    Input lat in epsg:4326 - GPS (WGS 84) coordinate system: $(lat)
    Input lon in epsg:4326 - GPS (WGS 84) coordinate system: $(lon)
    Input alt in epsg:4326 - GPS (WGS 84) coordinate system: $(alt)
    Weight: $(weight)
    isAligned: $(isAligned)
    actualx: $(actualx)
    actualy: $(actualy)
    actualz: $(actualz)
    actualLat: $(actualLat)
    actualLon: $(actualLon)
    actualAlt: $(actualAlt)
    actualLat in epsg:4326 - GPS (WGS 84) coordinate system: $(actualGpsLat)
    actualLon in epsg:4326 - GPS (WGS 84) coordinate system: $(actualGpsLon)
    actualAlt in epsg:4326 - GPS (WGS 84) coordinate system: $(actualGpsAlt)
    $ControlPointError( index,
      Index: $(cpIndex)    
      Total deviation: $(cpError3D)    
      Error X: $(cpErrorX)    
      Error Y: $(cpErrorY)    
      Error Z: $(cpErrorZ)    
      Maximal projection error: $(maxPlacementError)    
    )    
  )

ExportControlPointsMeasurements —— 该函数遍历所有控制点的所有测量值。对每个控制点，它导出该控制点被分配到的所有图像。

语法：

  $ExportControlPointsMeasurements( noParametersJustAnyText )

可用变量：

measurementIndex —— 测量值的索引

pointIndex —— 控制点的索引

imageIndex —— 图像索引

pointName —— 控制点名称

imagePath —— 图像路径

imageName —— 图像名称

imageExt —— 图像扩展名

x —— 控制点投影到图像上的 x 坐标，以像素计

y —— 控制点投影到图像上的 y 坐标，以像素计

inAccuracyX —— 手动放置的控制点在图像中的预期精度（像素）

inAccuracyY —— 手动放置的控制点在图像中的预期精度（像素）

inAccuracyAngle —— 误差区域的旋转角（使用自动标记检测时可计算得出）

可用函数：

ImageMeasurementError

语法：

  $ImageMeasurementError( pointIndex, measurementIndex, anyText )

参数：

pointIndex —— 控制点的索引：可用 ExportControlPointsMeasurements 函数获取所有控制点的索引（见下例）

measurementIndex —— 测量值的索引：可用 ExportControlPointsMeasurements 函数获取所有测量值的索引（见下例）

可用变量：

measurementError —— 偏差：投影位置与给定测量位置之间的误差，以像素计

measurementId —— 测量值的索引

示例：

$ExportControlPointsMeasurements(
    Measurement index: $(measurementIndex)
    Control point index: $(pointIndex)
    Image index: $(imageIndex)
    Control point name: $(pointName)
    Image path: $(imagePath)
    Image name: $(imageName)
    Image extension: $(imageExt)
    x: $(x)
    y: $(y)
    $ImageMeasurementError( pointIndex, measurementIndex,
      Measurement error: $(measurementError)
      Measurement index: $(measurementId)
    )
)

IterateMeasurements —— 该函数遍历某个控制点的所有测量值，导出该控制点被分配到的所有图像。

语法：

  $IterateMeasurements( controlPointId, anyText )

参数：

controlPointId —— 控制点的索引：可用 IterateControlPoints 函数获取所有控制点的索引（见下例）

可用变量：

measurementIndex —— 测量值的索引

measurementImage —— 图像索引

measurementFeature —— 控制点在图像中的索引

measurementImageX —— 控制点投影到图像上的 x 坐标，以像素计

measurementImageY —— 控制点投影到图像上的 y 坐标，以像素计

示例：

  $IterateControlPoints(    
    $IterateMeasurements( controlPointId,
      Measurement index: $(measurementIndex)
      Image index: $(measurementImage)
      Index of the control point in the image: $(measurementFeature)
      x: $(measurementImageX)
      y: $(measurementImageY)
    )
  )

ExportDistanceConstraints —— 该函数提供若干变量，用于输出全部或仅所选距离约束的信息。

语法：

  $ExportDistanceConstraints( noParametersJustAnyText )

可用变量：

constraintName —— 距离约束的名称

pointA —— 距离约束的第一个端点

pointB —— 距离约束的第二个端点

Enable —— 该距离约束应参与计算则为 true，否则 false

definedDistance —— 用户定义的两端点间距离

definedAccuracy —— 所定义两端点间距离的先验精度

calculatedDistance —— 算出的两端点间距离

distanceError —— calculatedDistance 减去 definedDistance

constraintCS —— 约束所在的坐标系

constraintCSUnit —— 约束所在坐标系的单位

constraintCSUnitShort —— 单位名称的短写形式

constraintCSUnitToMeter —— 用于换算单位的乘数

InCurrentComponent —— 若两个端点都投影到至少一张在所选组件中已配准的图像则为 true，否则 false

示例：

  $ExportDistanceConstraints(
    Constraint name: $(constraintName)
    Point A: $(pointA)
    Point B: $(pointB)
    Enable: $(Enable)
    Defined distance: $(definedDistance)
    Calculated distance: $(calculatedDistance)
    Distance error: $(distanceError)
    InCurrentComponent: $(InCurrentComponent)
  )

DistanceConstraintError —— 该函数提供若干变量，用于输出全部或仅所选距离约束的信息。

语法：

  $DistanceConstraintError( index, anyText )

参数：

index —— 距离约束的索引值

可用变量：

constraintError —— 所选距离约束的 calculatedDistance 减去 definedDistance

示例：

  $DistanceConstraintError( 1, 
    Error: $(constraintError)
  )
