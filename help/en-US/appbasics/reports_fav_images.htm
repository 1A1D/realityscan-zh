图像（报告中可用的函数与变量）

图像

GetImageInfo —— 该函数提供若干变量，可用于输出图像的基本信息。

语法：

  $GetImageInfo( filePath, anyText )

参数：

filePath —— 图像路径

可用变量：

width —— 图像宽度

height —— 图像高度

ratio —— 宽高比：宽度除以高度

relWidth —— 若 width 大于 height 则值为 1，否则等于 ratio

relHeight —— 若 height 大于 width 则值为 1，否则等于 ratio

示例：

  $IterateOrthoProjections(
    $SaveOrtho( "$(orthoGuid)", "color", "ortho_$(orthoIndex)_color.jpg", 800, 800 )
    $GetImageInfo( "ortho_$(orthoIndex)_color.jpg",
      orthoName: $(orthoName), width: $(width), height: $(height), ratio: $(ratio), relWidth: $(relWidth), relHeight: $(relHeight)
    )
  )

IterateImages —— 该函数提供若干变量，可用于输出项目中每个输入的信息。

语法：

  $IterateImages( noParametersJustAnyText )

可用变量：

inputImageName —— 不含扩展名的文件名

inputImageExt —— 图像扩展名

inputImagePath —— 不含文件名的绝对路径

inputIndex —— 索引

inputWidth —— 宽度

inputHeight —— 高度

inputIsAligned —— 该图像是否已对齐的信息

inputCameraIndex —— 若图像已对齐则显示相机索引，否则显示 -1

inputAlignmentEnabled —— 依据输入在对齐过程中是否可用返回 true 或 false。若该输入已启用于对齐，则返回 true。

inputMeshingEnabled —— 依据输入在网格重建过程中是否可用返回 true 或 false。若该输入已启用于网格重建，则返回 true。

inputTexturingEnabled —— 依据输入在着色与贴图过程中是否可用返回 true 或 false。若该输入已启用于着色与贴图，则返回 true。


NOTE: Variables inputIsAligned and inputCameraIndex give information based on the selected component

ExportImagePriors —— 该函数提供若干变量，可依据 inputIndex 输出项目中各个输入的先验信息。

语法：

  $ExportImagePriors( srcImage, anyText )

可用变量：

inputIsGeoreferenced —— 输入文件已做地理配准则为 true，否则 false

inputIsLatLong —— 输入文件的坐标系为地理坐标则为 true，为直角坐标则为 false

inputIsPointCloud —— 输入文件来自 LiDAR 扫描仪点云则为 true，否则 false

inputCalibrationPriorType —— 标定先验类型（Unknown、Approximate、Fixed）

inputIsPositionPrior —— 已定义位置先验则为 true

inputX —— 相机位置的 x 坐标（仅当输入坐标系为直角坐标时有效，即 inputIsLatLong 为 false）

inputY —— 相机位置的 y 坐标（仅当输入坐标系为直角坐标时有效）

inputZ —— 相机位置的 z 坐标（仅当输入坐标系为直角坐标时有效）

inputLat —— 相机位置的纬度坐标（仅当输入坐标系为地理坐标时有效）

inputLon —— 相机位置的经度坐标（仅当输入坐标系为地理坐标时有效）

inputAlt —— 相机位置的高程坐标（仅当输入坐标系为地理坐标时有效）

inputXOutCS —— 输入坐标系中的 X 值换算到输出坐标系

inputYOutCS —— 输入坐标系中的 Y 值换算到输出坐标系

inputZOutCS —— 输入坐标系中的 Z 值换算到输出坐标系

inputLatOutCS —— 输入坐标系中的纬度值换算到输出坐标系

inputLonOutCS —— 输入坐标系中的经度值换算到输出坐标系

inputAltOutCS —— 输入坐标系中的高程值换算到输出坐标系

inputXEuclid —— 输入坐标系中的 X 值换算到欧氏坐标系

inputYEuclid —— 输入坐标系中的 Y 值换算到欧氏坐标系

inputZEuclid —— 输入坐标系中的 Z 值换算到欧氏坐标系

inputCS —— 拍摄该图像时相机所处的坐标系

inputCSUnit —— 拍摄该图像时坐标系所用的单位

inputCSUnitShort —— 单位名称的短写形式

inputCSUnitToMeter —— 用于换算单位的乘数

inputIsOrientationPrior —— 若先验旋转是通过 Yaw、Pitch、Roll 角度定义的则为 true

inputYaw —— 先验旋转角 Yaw（绕 y 轴）

inputPitch —— 先验旋转角 Pitch（绕 x 轴）

inputRoll —— 先验旋转角 Roll（绕 z 轴）

inputIsOpkRotationPrior —— 若先验旋转是通过 Omega、Phi、Kappa 定义的则为 true

inputOmega —— 先验旋转角 Omega

inputPhi —— 先验旋转角 Phi

inputKappa —— 先验旋转角 Kappa

inputIsPriorAccuracy —— 若已定义先验位置与朝向精度则为 true

inputAccuracyX —— X（经度）坐标的先验精度

inputAccuracyY —— Y（纬度）坐标的先验精度

inputAccuracyZ —— Z（高程）坐标的先验精度

inputAccuracyYaw —— 旋转角 Yaw（Omega）的先验精度

inputAccuracyPitch —— 旋转角 Pitch（Phi）的先验精度

inputAccuracyRoll —— 旋转角 Roll（Kappa）的先验精度

inputIsInsOffsetValid —— 若已定义相机中心与位置传感器之间的偏移则为 true

inputInsOfsX —— 相机在 X 轴上的偏移

inputInsOfsY —— 相机在 Y 轴上的偏移

inputInsOfsZ —— 相机在 Z 轴上的偏移

inputInsOfsYaw —— 相机在 Yaw 旋转角上的偏移

inputInsOfsPitch —— 相机在 Pitch 旋转角上的偏移

inputInsOfsRoll —— 相机在 Roll 旋转角上的偏移

calibrationGroup —— 该图像所属的先验标定组

distortionGroup —— 该图像所属的先验畸变组

inputF —— 焦距（先验标定）

inputPX —— 主点 x（先验标定）

inputPY —— 主点 y（先验标定）

inputAspect —— 宽高比（先验标定）

inputSkew —— 输入斜切系数（先验标定）

inputK1 —— 径向 1（先验标定）

inputK2 —— 径向 2（先验标定）

inputK3 —— 径向 3（先验标定）

inputK4 —— 径向 4（先验标定）

inputT1 —— 切向 1（先验标定）

inputT2 —— 切向 2（先验标定）

inputLensModel —— 输入镜头畸变模型（先验镜头畸变）

inputLensModelIndex —— 输入镜头畸变模型索引

示例：

$IterateImages(
    Image name: $(inputImageName)
    Extension: $(inputImageExt)
    Path: $(inputImagePath)
    Index: $(inputIndex)
    Width: $(inputWidth)
    Height: $(inputHeight)

 $ExportImagePriors(inputIndex,
     Geo-referenced: $(inputIsGeoreferenced)
     LatLong: $(inputIsLatLong)
     PointCloud: $(inputIsPointCloud)
     Calibration prior type: $(inputCalibrationPriorType)
     Lat: $(inputLat)
     Lon: $(inputLon)
     Alt: $(inputAlt)
     X: $(inputX)
     Y: $(inputY)
     Z: $(inputZ)
     Focal length: $(inputF)
     Principal point x: $(inputPX)
     Principal point y: $(inputPY)
     Radial 1: $(inputK1)
     Radial 2: $(inputK2)
     Radial 3: $(inputK3)
     Radial 4: $(inputK4)
     Tangential 1: $(inputT1)
     Tangential 2: $(inputT2)
     Aspect ratio: $(inputAspect)
 )
)

SaveImage —— 该函数保存图像。

语法：

  $SaveImage( srcImage, dstImageFileName )
  or
  $SaveImage( srcImage, dstImageFileName, maxWidth, maxHeight )

参数：

srcImage —— 图像索引（不带引号的数字）或图像文件路径（带引号的字符串）：可用 IterateImages 函数获取所有输入的索引（见下例）

dstImageFileName —— 图像的存储路径

maxWidth —— 若图像宽度大于 maxWidth，图像会被缩放，使其宽度等于或小于 maxWidth。要保持原始尺寸，请使用负数。

maxHeight —— 若图像高度大于 maxHeight，图像会被缩放，使其高度等于或小于 maxHeight。要保持原始尺寸，请使用负数。

示例：

  $IterateImages(
    $SaveImage( inputIndex, "$(inputImageName)$(inputImageExt)", -1, -1 )
  )

ExportImageResolutionStats —— 该函数可输出所有图像分辨率及其图像数量。

语法：

  $ExportImageResolutionStats( noParametersJustAnyText )

可用变量：

imageWidth —— 图像宽度

imageHeight —— 图像高度

imageCount —— 宽度等于 imageWidth、高度等于 imageHeight 的图像数量

示例：

  $ExportImageResolutionStats(
    Image width: $(imageWidth)
    Image height: $(imageHeight)
    Number of images: $(imageCount)
  )
