全部 CLI 命令列表

使用 CLI 命令可自动化工作流程，让迭代处理更轻松。

项目与影像

向项目添加影像，或更改项目 / 实例设置。

命令名称 必需参数 可选参数 说明
headless 隐藏用户界面。关于该命令的更多信息请见 此处。
hideUI 隐藏用户界面。与 headless 不同，该命令不必在启动时运行，也不会屏蔽需要用户交互的操作。
showUI 显示已隐藏的用户界面。与 headless 不同，该命令不必在启动时运行。
newScene 创建一个空的新场景。
load MyProject.rsproj recoverAutosave|deleteAutosave 从 MyProject.rsproj 文件加载已有项目。若该项目存在自动保存文件，可用可选参数定义处理方式：使用 recoverAutosave 会打开自动保存的项目，而 deleteAutosave 会删除自动保存的项目并加载原始项目。有关自动保存功能的更多信息，请见 此处。
若要为所有项目统一设置该偏好，请使用带 appAutoSaveCliHandling 键的 set 命令。更多内容见 CLI 设置键与值 一节。
save MyProject.rsproj 把当前项目保存到原位置，或另存为 MyProject.rsproj。
start 运行为 Start 按钮配置的各个进程。可在 Start 按钮下拉菜单中的 Start button 设置里调整这些设置。
unlockPPIProject myProject.rcproj 保存并解锁 PPI 项目，使其可兼容最新版本的 RealityScan。请填写欲存放解锁项目的完整路径，包含项目名称与扩展名。
add imageName 从指定文件路径或影像列表导入一幅或多幅影像。影像列表是扩展名为 .imagelist 的文本文件，每行写一个影像的完整路径。
addFolder folderName 把指定文件夹中的所有影像添加进来。若要包含子目录，请使用带 appIncSubdirs 键的 set 命令，写法如下：-set "appIncSubdirs=true"。更多内容见 CLI 设置键与值 一节。
importVideo videoFileName
extractedVideoFramesLocation
jumpsLength		 导入从视频中抽取的帧（videoFileName 需含路径）。帧会按 jumpsLength 定义的间隔（单位：秒）抽取到文件夹 extractedVideoFramesLocation 中。
importLeicaBlk3D fileName 导入由 Leica BLK3D 采集、扩展名为 .cmi 的影像序列（fileName 需含路径）。
importLaserScan laserscanName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）添加 LiDAR 扫描或 LiDAR 扫描列表。这些设置可从应用程序中的 LiDAR Scan Import 对话框导出。
importLaserScanFolder folderName params.xml 使用 params.xml 文件中的设置，添加指定文件夹中的所有 LiDAR 扫描。这些设置可从应用程序中的 LiDAR Scan Import 对话框导出。
importHDRimages fileName|folderName|imageList params.xml 使用当前设置或 params.xml 中的设置，导入 HDR 影像（imageName）、影像列表（imageList）或文件夹（folderName）中的所有影像。这些设置可从应用程序中的 16-bit/HDR Images Import 对话框导出。
addImageWithCalibration fileName
xmpFileName		 导入影像及其对应的 XMP 文件，请使用文件的完整路径。
importImageSelection fileName 选中文件（filename 需含路径）中列出的部分场景影像和 / 或 LiDAR 扫描。
selectImage imagePath|regexp set
union
sub
intersect
toggle		 选中指定影像（imagePath）或由正则表达式（regexp）定义的影像，参见下文的 示例。可使用其中一个可选参数，以更灵活地筛选影像。
selectAllImages 选中项目中的所有影像。
deselectAllImages 取消选中项目中的所有影像。
invertImageSelection 反选当前影像选区。
removeCalibrationGroups 清除所有输入所属的标定组。
generateAIMasks 使用 AI 蒙版功能，把影像中感兴趣的对象分离出来以生成蒙版。
exportMasks folderPath params.xml 导出项目当前使用的蒙版影像。请指定输出文件夹与含导出参数的 XML 文件的完整路径（该文件可从 Export Mask Images 对话框导出）。
params.xml 把蒙版影像导出到原始影像所在文件夹。请指定含导出参数的 XML 文件的完整路径（该文件可从 Export Mask Images 对话框导出）。
setImageLayer index pathImage layerType 把由 pathImage 参数指定的影像（图层影像的路径）中的图层，设置到由 index 参数指定的影像上。索引对应 1Ds 视图中的影像顺序，从 0 开始。layerType 参数定义要设置到所选影像上的图层类型（例如 mask、texture）。
setImagesLayer pathImage layerType 把由 pathImage 参数指定的影像（图层影像的路径）中的图层，设置到当前选中的影像上。layerType 参数定义要设置到所选影像上的图层类型（例如 mask、texture）。
removeImageLayer layerType 从所选影像中移除与 layerType 参数对应的图层（例如 mask、texture）。
importCache folderName 从指定文件夹导入资源缓存数据。
clearCache 清除应用程序缓存。清除前必须先保存项目。
execRSCMD Commands.rscmd 执行 .rscmd（或 .rccmd）文件中的命令，可选用报告参数。文件格式与语法见 命令提示符之外执行命令 一节。可在 .rscmd 文件路径之后列出最多九个参数作为变量，在文件内部用 $(arg1)–$(arg9) 引用这些变量。
quit 退出应用程序。

针对所选影像的命令

以下命令用于为影像的后续处理设置一些偏好。

命令名称 必需参数 可选参数 说明
setFeatureSource 0|1|2 为所选影像定义特征来源模式：
0 – 按重叠区域合并，
1 – 使用组件特征，
2 – 使用全部影像特征。
enableAlignment true|false 启用 / 禁用所选影像参与配准过程。
enableMeshing true|false 启用 / 禁用所选影像参与模型计算 / 网格生成。
enableTexturingAndColoring true|false 启用 / 禁用所选影像参与着色与纹理计算。
setWeightInTexturing <0,1> 设置所选影像在着色与纹理计算中的权重。
enableColorNormalizationReference true|false 把所选影像设为颜色归一化过程中的颜色参考，这些影像的颜色不会被改变。
enableColorNormalization true|false 启用或禁用所选影像参与颜色归一化过程。
setDownscaleForDepthMaps integer 为所选影像设置深度图计算的降采样系数。
enableInComponent true|false 启用所选影像参与网格生成并继续。仅适用于已配准的影像。
setCalibrationGroupByExif 根据所有输入的 EXIF 信息设置其标定组。
setConstantCalibrationGroups 把所有选中的输入归入同一个标定组。
lockPoseForContinue true|false 在下一次配准时保持所选影像的相对相机位姿不变。仅适用于已配准的影像。
setPriorCalibrationGroup number 为所选影像设置先验标定组：
-1 - 不分组，
其它数值 - 归入同一个标定组。
setPriorLensGroup number 为所选影像设置先验镜头组。取 -1 表示不分组；取其它数值表示把所选影像归入同一个畸变组。
editInputSelection "key=value" 根据 Selected inputs 面板中的值或其键，编辑所选输入的设置。更多信息请见 此处。

委托命令

可用这些命令把操作委托给某个指定的 RealityScan 实例。有关命令委托的更多信息请见 此处。

命令名称 必需参数 可选参数 说明
setInstanceName instanceName 为 RealityScan 实例指定名称。
delegateTo instanceName|* 把一条命令或一组命令委托给指定的 RealityScan 实例（instanceName），或委托给第一个可用实例（以 * 符号作为参数）。
waitCompleted instanceName|* 暂停执行其它命令，直到指定 RealityScan 实例（instanceName）或第一个可用实例（以 * 为参数）中的当前进程结束。
getStatus instanceName|* 返回指定 RealityScan 实例（instanceName）或第一个可用实例（以 * 符号为参数）中正在运行进程的进度状态。
pauseInstance instanceName|* 暂停指定 RealityScan 实例（instanceName）或第一个可用实例（以 * 符号为参数）中正在运行的进程。
unpauseInstance instanceName|* 恢复指定 RealityScan 实例（instanceName）或第一个可用实例（以 * 符号为参数）中已暂停的进程。
abortInstance instanceName|* 中止指定 RealityScan 实例（instanceName）或第一个可用实例（以 * 符号为参数）中正在运行的进程。若处理由 CLI 命令执行，则该进程之后的所有进程也会被中止。
execRSCMDIndirect instanceName|* commands.rscmd 在指定实例中执行 .rscmd（或 .rccmd）文件里列出的命令，可选用报告参数。文件格式与语法见 命令提示符之外执行命令 一节。可在 .rscmd 文件路径之后列出最多九个参数作为变量，在文件内部用 $(arg1)–$(arg9) 引用这些变量。

Alignment

以下命令可用于计算相机位姿与标定，以及处理组件和控制点。

命令名称 必需参数 可选参数 说明
align 使用当前设置对齐影像。
draft 使用当前设置以草稿模式对齐影像。
update 通过刚性变换更新所有组件与模型，使其符合当前约束和控制点。
detectFeatures 按对齐设置执行特征检测，检测到的特征会保存到应用程序缓存中。
mergeComponents 合并已创建的组件。使用该命令时，不会向现有组件添加新影像。
exportXMP params.xml 使用当前设置或 params.xml 文件中的设置（可选参数），把最后一次对齐生成的组件的相机元数据按 XMP 格式导出。该设置文件可从 XMP 元数据导出 对话框导出。组件必须满足 setMinComponentSize 命令所定义的条件。
注意：XMP 文件与对应影像存放在同一文件夹中。
exportXMPForSelectedComponent 使用当前设置，把所选组件的相机元数据按 XMP 格式导出。下文的「Metadata (XMP) Export Settings」段落提供了示例。
注意：XMP 文件与对应影像存放在同一文件夹中。
importComponent component.rsalign 从 component.rsalign 文件导入组件。
loadBundler filePath params.xml 导入 Bundler 工程。该命令需要 Bundler 文件路径，还可选一个从导入对话框保存的场景变换设置配置文件。该配置文件可用于在导入时调整坐标系或应用自定义变换。
loadColmap filePath params.xml 导入 COLMAP 工程。该命令需要 COLMAP 文件路径（三个文本文件中的任意一个），还可选一个从导入对话框保存的场景变换设置配置文件。该配置文件可用于在导入时调整坐标系或应用自定义变换。
exportLatestComponents folderName 把最后一次对齐生成的组件以 RealityScan 对齐组件（.rsalign）形式导出到指定文件夹。组件必须满足 setMinComponentSize 命令所定义的条件。
setMinComponentSize size 指定使用 exportLatestComponents 和 exportXMP 命令时导出组件的最小尺寸。默认值为 5。
exportSelectedComponentDir folderName 把所选组件以 RealityScan 对齐组件（.rsalign）形式导出到文件夹（folderName 需含路径）。
exportSelectedComponentFile fileName 把所选组件导出为 RealityScan 对齐组件文件。
exportRegistration fileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数），把配准结果导出到指定文件。这些设置可从应用程序中的 Export Registration 对话框导出。
exportUndistortedImages folderName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数），把未畸变影像导出到指定文件夹。这些设置可从应用程序中的 Export Registration 对话框导出。
exportSTMap folderName params.xml 为所选影像导出 ST 贴图。若未指定 folderName 和 params.xml，结果将按当前设置保存在原影像旁边。设置文件可从应用程序中的 Export Registration 对话框导出。
exportSparsePointCloud fileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数），把 3D 连接点（稀疏点云）导出到指定文件（fileName 需含路径与格式扩展名）。这些设置可从应用程序中的 Export Point Cloud 对话框导出。
selectComponent componentName 按指定名称（componentName）选中组件以便后续处理。
selectMaximalComponent 选中最大的组件以便后续处理。
selectComponentWithLeastReprojectionError 根据计算出的平均误差 [像素] 选中重投影误差最小的组件，以便后续处理。
renameSelectedComponent newComponentName 重命名当前选中的组件。
deleteSelectedComponent 删除当前选中的组件。
deleteComponent index 按指定索引删除组件。注意索引从 0 开始。
deleteAllComponents 删除所有组件。
importTrajectory flFileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）导入轨迹文件。这些设置可从应用程序中的 Import Trajectory 对话框导出。
importGroundControlPoints gcpFileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）导入地面控制点。这些设置可从应用程序中的 Export Ground Control Points 对话框导出。
importControlPointsMeasurements cpmFileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）导入控制点（CP）测量值。这些设置可从应用程序中的 Export Control Points Measurements 对话框导出。
editControlPointSelection "key=value" 根据 Selected control point(s) 面板中的值或其键，编辑所选控制点的设置 / 参数。更多信息请见 此处。
listControlPoints fileName 把控制点列表导出到指定文件路径（含文件名与扩展名，fileName 参数），每个控制点附带其索引一并列出。
selectControlPoint controlPointName 按名称选中控制点。
invertControlPointSelection 反选控制点。若当前未选中任何控制点，则会选中全部。
renameControlPoint controlPointName newName 重命名控制点。用当前名称（controlPointName）指定控制点，并给出要设置的新名称（newName）。
renameSelectedControlPoint newName 把选中的控制点重命名为指定的新名称（newName）。
deleteControlPoint index 删除选中的控制点。若使用可选参数 index，则删除对应索引的控制点。索引从 0 开始，顺序与 1Ds 视图中的控制点顺序一致。
selectMeasurementByError errorValue controlPointName 选中位置误差（像素）大于或等于指定 errorValue（浮点值）的所有测量值。若未指定控制点（controlPointName），则选择范围涵盖所有测量值，不论其所属控制点。
selectMeasurementByIndex controlPointName index 按指定控制点内的索引选中该控制点的一个测量值。
deleteControlPointMeasurement 移除所选的控制点测量值（分配给控制点的影像）。影像需在 1Ds 视图中对应控制点下被选中。
exportGroundControlPoints gcpFileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）导出地面控制点。这些设置可从应用程序中的 Export Ground Control 对话框导出。
exportControlPointsMeasurements cpmFileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）导出控制点测量值。在 Alignment 选项卡的 Export 部分，按住 Shift 键点击 Control Points 按钮，即可从应用程序中的 Export Control Points Measurements 对话框导出这些设置。
defineDistance PointNameA PointNameB distance constraintName 定义两个控制点之间的距离约束。若未指定 constraintName，距离名称将自动生成。也可以从文件加载距离约束（见下文）。
defineDistance fileName params.xml 使用当前设置或 params.xml 文件中的设置（可选参数），从文件（filename 需含路径）导入距离约束。这些设置可从应用程序中的 导入距离定义对话框导出。安装文件夹中可找到所支持格式的列表 distancedefinitions.xml。
editConstraintSelection "key=value" 根据 Selected constraint(s) 面板中的值或其键，编辑所选约束的设置 / 参数。更多信息请见 此处。
deleteConstraint index 移除所选的距离约束。约束必须先在 1Ds 视图中选中。可用可选参数 index 指定要移除的约束。索引从 0 开始，顺序与 1Ds 视图中的约束顺序一致。
detectMarkers params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）在影像中检测标记点。这些设置可从应用程序中的 Detect Markers 工具导出。
setCamerasGravityDirection componentID 若影像的 XMP 文件包含重力信息（xcr:Gravity），组件将被旋转，使 -z 向量指向重力向量方向。该操作不适用于稠密点云（网格 / 模型），仅适用于稀疏点云（对齐结果）。作用于所选组件，或由可选参数（组件 ID）指定的组件。

Reconstruction

以下命令可用于计算模型以及执行着色与纹理生成。

命令名称 必需参数 可选参数 说明
resetGround 把地平面恢复到原始朝向和位置。
setGroundPlaneFromReconstructionRegion 使用重建区域自动把模型居中到网格中央，同时调整旋转与平移。
setReconstructionRegionAuto 自动设置重建区域。
setReconstructionRegion box.rsbox 从 box.rsbox 文件导入重建区域。
setReconstructionRegionOnCPs controlPoint
controlPoint
controlPoint
controlPoint|heightValue		 在已有控制点上设置重建区域。三个控制点定义区域的底面，区域高度由第四个控制点或直接输入高度值定义。该命令的更多示例请见 此处。
setReconstructionRegionByDensity 把重建区域设置到稀疏点云密度最高的部分。
scaleReconstructionRegion scaleX
scaleY
scaleZ		 origin|center absolute|factor 沿各轴缩放重建区域（scaleX、scaleY 和 scaleZ）。缩放参数既可视为绝对值（absolute），也可视为缩放系数（factor），以区域中心（center）或原点（origin）为基准；原点由使用 setReconstructionRegionOnCPs 命令时的第一个控制点定义。默认值为 "absolute" 和 "center"。该命令的更多示例请见 此处。
moveReconstructionRegion moveX
moveY
moveZ		 沿重建区域自身的各轴移动该区域，数值单位与坐标系一致。该命令的更多示例请见 此处。
rotateReconstructionRegion rotateX
rotateY
rotateZ		 绕重建区域自身的各轴旋转该区域，所有数值单位为度。该命令的更多示例请见 此处。
offsetReconstructionRegion offsetX
offsetY
offsetZ		 按区域自身尺寸的数值，沿各轴偏移重建区域。该命令的更多示例请见 此处。
exportReconstructionRegion box.rsbox 把重建区域导出为 box.rsbox 文件。
calculatePreviewModel 以预览质量计算 3D 网格。
calculateNormalModel 以常规质量计算 3D 网格。
calculateHighModel 以最高质量计算 3D 网格。
continueModelCalculation 若模型计算曾暂停或发生过崩溃，可用该命令继续计算。该命令的更多信息请见 此处。

模型工具

成功创建模型后，可用以下工具通过命令行对其做进一步处理。

命令名称 必需参数 可选参数 说明
selectModel modelName 按指定名称（modelName）选中模型。
deleteSelectedModel 删除当前选中的模型。
duplicateSelectedModel 复制选中的模型（含纹理）。
renameSelectedModel newModelName 重命名当前选中的模型。
correctColors layerName 对所选组件中的所有图层或指定图层（layerName）执行颜色校正。
unwrap params.xml 使用当前设置或 params.xml 中的设置（可选参数）计算模型的 UV 展开。这些设置可从应用程序中的 Unwrap 工具导出。
calculateTexture params.xml 使用当前设置或 params.xml 文件中的设置（可选参数）计算纹理。这些设置可从应用程序中的 Color and Texture Settings 面板导出。
calculateQualityTexture 使用网格质量数值计算纹理，这些数值可用 Quality Analysis 工具算出。使用该命令前不必预先计算这些数值。
reprojectTexture sourceModel resultModel params.xml 使用当前设置或 params.xml 文件中的设置（可选参数），把纹理从已贴纹理的模型（sourceModel）重投影到已完成 UV 展开的模型（resultModel）。sourceModel 与 resultModel 为应用程序中的模型名称。这些设置可从应用程序中的 Texture Reprojection 工具导出。
calculateVertexColors 使用当前设置计算着色。
calculatePreviewVertexColors 使用当前设置计算草稿着色。
calculateQualityColors 使用网格质量数值计算顶点颜色，这些数值可用 Quality Analysis 工具算出。使用该命令前不必预先计算这些数值。
simplify targetTriangleCount or params.xml 使用当前设置（不带任何参数即表示使用当前设置）把所选模型简化到指定三角形数量（targetTriangleCount），或使用 params.xml 文件中的设置。这些设置可从应用程序中的 Simplify 工具导出。
smooth params.xml 使用当前设置或 params.xml 文件中的设置平滑所选模型。这些设置可从应用程序中的 Smooth 工具导出。
closeHoles maxEdgesCount 使用当前设置或指定的最大边数（maxEdgesCount）封闭模型孔洞。
cleanModel 清理所选模型：移除非流形边与顶点、封闭小孔等。
selectTrianglesInsideReconReg 选中重建区域内的三角形。

设置与错误处理命令

可用这些命令更改应用程序的设置与行为。

命令名称 必需参数 可选参数 说明
set "key=value" 修改一项应用程序设置。该命令用法的更多信息请见 此处。
preset "key=value" 在设置阶段修改应用程序设置，适合需要重启应用程序才能生效的更改。该命令用法的更多信息请见 此处。
reset ui | cfg | cfgui | all 重置用户界面、设置或两者，也可让 RealityScan 恢复到全新安装的状态。该命令仅在批处理文件中使用时有效，不适用于委托命令。重置内容由所选参数决定：ui - 重置用户界面，cfg - 重置应用程序设置，cfgui - 同时重置界面与设置，all - 恢复为全新安装状态。
silent crashReportPath 屏蔽警告对话框并停止上传崩溃报告，应用程序会把报告存放到指定位置，而不再显示上传向导。该命令必须在启动时使用。
writeProgress fileName timeout 把所有新的进度变化写入指定文件（fileName 需含路径）。可选的 timeout 参数还可在指定时间段内持续输出（单位为秒）。文件结构的更多说明见 错误处理命令 一节。
printProgress timeout 每当进度发生变化时，把变化输出到 Windows 命令提示符。可选的 timeout 参数还可在指定时间段内持续输出（单位为秒）。
tag string 把字符串参数写出到 Windows 命令提示符。它遵循所用命令的顺序，会在其前面的进程结束后、整体完成之前执行。
stdConsole 启用把控制台内容重定向到应用程序标准输出。使用后，应用程序控制台内容会同步显示在标准 Windows 控制台中，同时也支持为 CLI 用途做进一步重定向。
disableOnlineCommunication 禁用所有在线通信。
importGlobalSettings settings.rcconfig 从 settings.rcconfig 文件导入应用程序全局设置。
exportGlobalSettings settings.rcconfig 把应用程序全局设置导出到 settings.rcconfig 文件。
setProjectCoordinateSystem authority:id 设置由权威机构定义的项目坐标系及其 ID（可在特定数据库中查到，例如 epsg.xml 和 local.xml）。示例请见 此处。
setOutputCoordinateSystem authority:id 设置由权威机构定义的输出坐标系及其 ID（可在特定数据库中查到，例如 epsg.xml 和 local.xml）。示例请见 此处。
