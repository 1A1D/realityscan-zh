模型（报告中可用的函数与变量）

模型

IterateModels —— 该函数用于输出某个组件内所有模型的基本信息。

语法：

  $IterateModels( componentGUID, anyText )

参数：

componentGUID —— 组件的 GUID：可用 IterateComponents 函数获取所有组件的 GUID

可用变量：

modelGUID —— 模型的 GUID

modelName —— 模型名称

modelTrianglesCount —— 模型的三角面数量

modelVerticesCount —— 模型的顶点数量

示例：

  $IterateComponents(
    $IterateModels( "$(componentGUID)",
      Model GUID: $(modelGUID)
      Model name: $(modelName)
      Triangles count: $(modelTrianglesCount)
      Vertices count: $(modelVerticesCount)
    )
  )

ExportModels —— 该函数用于输出所选组件内所有模型的详细信息。

语法：

  $ExportModels( noParametersJustAnyText )

可用变量：

modelName —— 模型名称

modelGuid —— 模型的 GUID

modelTriangleCount —— 模型的三角面数量

modelVertexCount —— 模型的顶点数量

modelPartCount —— 模型的分块数量

modelUnitSize —— 单位尺寸

modelUnits —— 单位名称

modelIsColored —— 模型已上色则为 true，否则 false

modelIsTextured —— 模型已贴图则为 true，否则 false

可用函数：

ExportTextureInfo —— 模型纹理图层的信息。

语法：

  $ExportTextureInfo( noParametersJustAnyText )

可用变量：

selectedTextureLayerGuid —— 所选纹理图层的索引值

modelTextureLayerCount —— 模型拥有的纹理图层数量

modelUnwrapStyle —— 展开风格

modelTextureCount —— 纹理数量

modelTextureResolutionX —— 纹理宽度

modelTextureResolutionY —— 纹理高度

modelGutterSize —— 各图表的留白尺寸

modelTextureUtilization —— 纹理利用率（含留白）

modelOptimalTexelSize —— 最佳纹素尺寸

modelTextureQuality —— 纹理质量

modelTexelSize —— 纹素尺寸

可用函数：

IterateTextureLayers —— 遍历纹理图层。

语法：

  $IterateTextureLayers( noParametersJustAnyText )

可用变量：

textureLayerGuid —— 纹理图层的索引值

ExportTextureLayerInfo —— 导出纹理图层的信息。

语法：

  $ExportTextureLayerInfo( textureLayerGuid, anyText )

参数：

textureLayerGuid —— 纹理图层的索引值

可用变量：

textureLayerGuid —— 纹理图层的索引值

textureLayerStyle —— 创建该纹理图层所用的贴图风格

textureLayerType —— 纹理图层的类型

textureLayerName —— 纹理图层的名称

textureLayerPixelFormat —— 纹理图层的像素格式

textureLayerHasInputLayer —— 若使用了纹理图层则返回 "true"（否则 "false"）

textureLayerInputLayer —— 用于创建该纹理图层的图像图层

textureLayerHasSourceModel —— 若纹理图层是用 Texture reprojection 工具创建的、且带有源模型信息，则返回 "true"（否则 "false"）

textureLayerSourceModelGuid —— 源模型的索引

textureLayerHasSourceLayer —— 若纹理图层是用 Texture reprojection 工具创建的、且带有源图层信息，则返回 "true"（否则 "false"）

textureLayerSourceLayerGuid —— 源图层的索引

textureLayerTime —— 计算该纹理图层所花的时间

ModelStats

语法：

  $ModelStats( modelGuid, anyText )

参数：

modelGuid

可用变量：

modelDepthMapsTime —— 深度图计算耗时（秒）

modelMeshingTime —— 网格重建耗时（秒）

modelPostprocessTime —— 后处理耗时（秒）

modelColoringTime —— 上色耗时（秒）

modelUnwrapTime —— 展开耗时（秒）

ModelSettings

语法：

  $ModelSettings( modelGuid, anyText )

参数：

modelGuid

可用变量：

modelQuality —— 质量等级

modelImageDownscaleFactor —— 深度图的图像降采样系数

Example（注意 ":.xf" 用于把小数四舍五入到 x 位）：

  $ExportModels(

    Model name: $(modelName)
    Model GUID: $(modelGuid)
    Triangles count: $(modelTriangleCount)
    Vertices count: $(modelVertexCount)
    Parts count: $(modelPartCount)
    Unit size: $(modelUnitSize)
    Units: $(modelUnits)
    Colored: $(modelIsColored)
    Textured: $(modelIsTextured)

    $ExportTextureInfo(
      Texturing style: $(modelTextureStyle)
      Unwrapping style: $(modelUnwrapStyle)
      Textures count: $(modelTextureCount)
      Texture resolution: $(modelTextureResolutionX) x $(modelTextureResolutionY)
      Charts gutter size: $(modelGutterSize) texels
      Texture utilization: $(modelTextureUtilization * 100 :.0f)%
      Optimal texel size: $(modelOptimalTexelSize:.6f) units per texel
      Texture quality: $(modelTextureQuality * 100 :.0f)%
      Texel size: $(modelTexelSize:.6f) units per texel
    )

    $ModelStats( "$(modelGuid)",
      Depth-map computation time: $(modelDepthMapsTimeStr) ($(modelDepthMapsTime)s)
      Meshing time: $(modelMeshingTimeStr) ($(modelMeshingTime)s)
      Post-processing time: $(modelPostprocessTimeStr) ($(modelPostprocessTime)s)
      Coloring time: $(modelColoringTimeStr) ($(modelColoringTime)s)
      Unwrapping time: $(modelUnwrapTimeStr) ($(modelUnwrapTime)s)
      Texturing time: $(modelTexturingTimeStr) ($(modelTexturingTime)s)
      Overall processing time: $(modelTotalTimeStr) ($(modelTotalTime)s)
    )

    $ModelSettings( "$(modelGuid)",
      Quality level: $(modelQuality)
      Image downscale factor: $(modelImageDownscaleFactor)
    )

  )

RenderMesh —— 把模型的图像导出为单独文件。

语法：

  $RenderMesh( modelGuid, “filepath”, width, height, cameraIndex )
  or
  $RenderMesh( modelGuid, “filepath”, width, height, cameraIndex, textureLayerGuid )

参数：

modelGuid —— 模型的索引

filePath —— 相对于附件文件夹的路径，或形如 global://globalPathToFile 的路径

width —— 渲染图像的宽度

height —— 渲染图像的高度

cameraIndex —— 用于渲染图像的相机索引（填 -1 则自动从能较好俯瞰模型的相机渲染）

textureLayerGuid —— 纹理图层的索引。这是可选参数；若不指定且模型已贴图，则使用当前选中的纹理图层。


RenderMeshFromCustomPositionYPR —— 从自定义位置与相机旋转渲染模型图像。

语法：

   $RenderMeshFromCustomPositionYPR( modelGUID, "outputFile", width, height, focalLength, x, y, z, yaw, pitch, roll )
   or
   $RenderMeshFromCustomPositionYPR( modelGUID, "outputFile", width, height, focalLength, x, y, z, yaw, pitch, roll, textureLayerGUID )

参数：

modelGuid —— 模型的索引

outputFile —— 渲染图像的完整路径（含格式扩展名）

width —— 渲染图像的宽度（像素）

height —— 渲染图像的高度（像素）

focalLength —— 渲染图像的焦距

x —— 相机的 X 坐标

y —— 相机的 Y 坐标

z —— 相机的 Z 坐标

yaw —— 相机的偏航旋转

pitch —— 相机的俯仰旋转

roll —— 相机的翻滚旋转

textureLayerGUID —— 渲染图像中要使用的纹理图层索引

示例：

   $IterateComponents(
      $IterateModels( "$(componentGUID)",
         $RenderMeshFromCustomPositionYPR( "$(modelGUID)", 
            "renderMesh.png", 6000, 4000, 24, -21, 19, 17, 0, 90, 0
         )
      )
   )

RenderMeshFromCustomPositionLookAt —— 从自定义位置朝自定义目标点渲染模型图像。

语法：

   $RenderMeshFromCustomPositionLookAt( modelGUID, "outputFile", width, height, focalLength, x, y, z, atX, atY, atZ )
   or
   $RenderMeshFromCustomPositionLookAt( modelGUID, "outputFile", width, height, focalLength, x, y, z, atX, atY, atZ, upX, upY, upZ )
   or
   $RenderMeshFromCustomPositionLookAt( modelGUID, "outputFile", width, height, focalLength, x, y, z, atX, atY, atZ, upX, upY, upZ, textureLayerGUID )

参数：

modelGuid —— 模型的索引

outputFile —— 渲染图像的完整路径（含格式扩展名）

width —— 渲染图像的宽度（像素）

height —— 渲染图像的高度（像素）

focalLength —— 渲染图像的焦距

x —— 相机的 X 坐标

y —— 相机的 Y 坐标

z —— 相机的 Z 坐标

atX —— 相机所看目标位置的 X 坐标

atY —— 相机所看目标位置的 Y 坐标

atZ —— 相机所看目标位置的 Z 坐标

upX —— 定义上向量的 X 坐标

upY —— 定义上向量的 Y 坐标

upZ —— 定义上向量的 Z 坐标

textureLayerGUID —— 渲染图像中要使用的纹理图层索引

示例：

   $IterateComponents(
      $IterateModels( "$(componentGUID)",
         $RenderMeshFromCustomPositionLookAt( "$(modelGUID)", 
            "global://D:\\Project\\Render\\renderMesh.jpg", 6000, 4000, 24, 120, 95, 25, 0, 10, 15, 0, 0, 1)
         )
      )
   )
