全身扫描

RealityScan 配合各类全身扫描仪有多种用法，具体取决于用户需求与扫描仪参数。

扫描选项

扫描需求：

  • （1）固定坐标系的扫描： 三维扫描中量得的距离必须代表现实世界的距离
  • （2）任意坐标系的扫描： 三维扫描中量得的距离不必代表现实世界的距离

扫描仪类型：

  • （a.）固定相机配置： 相机不移动、不旋转，也不改变焦距，各相机参数在多次扫描之间保持不变，即完全固定的相机配置（哪怕 1 毫米的相机位移或 1/10 度的旋转，在图像中都能看出来，所以相机配置必须固定得非常牢靠。）
  • （b.）可弯折相机配置： 相机可以有轻微移动，不属于完全固定的相机配置

扫描的用法：

  • （i.）人工操作： 每次扫描都由操作员单独处理
  • （ii.）自动处理： 每次扫描自动处理，之后可能再做后期

可行方案

把上述选项合理组合，用 RealityScan 处理全身扫描共有 8 种不同方案：

  • ( 1.a.i ) 使用固定坐标系的扫描 created using Fixed-camera setup with Operator-based processing:
    • 要求扫描中保持模型的位置与距离不变
    • 使用带 XMP 元数据的 RealityScan 工作流
    • 扫描在用户界面（UI）中处理
  • ( 1.a.ii ) 使用固定坐标系的扫描 created using Fixed-camera setup with Automatic processing:
    • 要求扫描中保持模型的位置与距离不变
    • 使用带 XMP 元数据的 RealityScan 工作流
    • 扫描在命令行界面（CLI）中处理

  • ( 1.b.i ) 使用固定坐标系的扫描 created using Bending-camera setup with Operator-based processing:
    • 要求扫描中保持模型的位置与距离不变
    • 使用带飞行日志数据的 RealityScan 工作流
    • 扫描在用户界面（UI）中处理
  • ( 1.b.ii ) 使用固定坐标系的扫描 created using Bending-camera setup with Automatic processing:
    • 要求扫描中保持模型的位置与距离不变
    • 使用带飞行日志数据的 RealityScan 工作流
    • 扫描在命令行界面（CLI）中处理

  • （2.a.i）用Fixed-camera setup创建、以Operator-based方式处理的任意坐标系扫描：
  • （2.a.ii）用Fixed-camera setup创建、以Automatic方式处理的任意坐标系扫描：
  • （2.b.i）用Bending-camera setup创建、以Operator-based方式处理的任意坐标系扫描：
  • （2.b.ii）用Bending-camera setup创建、以Automatic方式处理的任意坐标系扫描：

这 4 种情况只能用用户界面（UI）手动处理扫描，即方案（2.a.i）与（2.b.i），详见 快速入门教程。方案（2.a.ii）与（2.b.ii）中命令行界面（CLI）的自动处理不会被采用，因为现有数据与元数据都无法被合理复用。
