图像镶嵌

创建正射投影时，可以把 Rendering method 设为 Image mosaicing (aerial) 或 Image mosaicing (general)。这两种方法可以只用图像生成正射投影，而其他方法则要使用带纹理或已着色的稠密网格模型。Aerial 与 General 的区别在于相机的分布方式：用 Aerial 方法时建议相机位于同一平面或彼此平行的平面内，它也比 General 更快；General 方法用于相机环绕物体分布的项目，建议用于地面项目。
与其它渲染方法一样，该方法的前提是至少已创建一个模型。模型创建并选中后，Ortho Projection 工具即可使用。


显示方式

与任何正射投影一样，图像镶嵌也可以用任意 Input layers 来显示：Ortho、DSM 和 DTM。还有一个只对图像镶嵌可用的选项：Mosaicing。启用该选项时，正射投影会以一组接缝线的形式显示，这些接缝线代表各区域，并与生成每个区域的图像相关联。要更换 Input layer，先显示带正射投影的 2D 视图，再在 ORTHO 2D/VIEW 上下文选项卡的 Source 区域选择图层。

接缝线也可以叠加显示在其他输入图层之上，在 ORTHO 2D/VIEW 上下文选项卡中勾选 Seamlines 复选框即可启用。

在正射投影上点击某个区域，就会显示与之对应的图像。这里推荐使用颜色光标：例如另开一个 2D 视图，把它的颜色光标设为 Magenta（品红），然后按住小键盘上的数字 3 并点击目标区域，图像就会显示出来，并高亮用于生成该镶嵌区域的部分。


增强镶嵌

可以在图像镶嵌上新建区域，并选择用哪张图像来代表镶嵌中的该部分。ORTHO 2D/TOOLS 上下文选项卡中提供了多种新建区域的选项，点击 Enhance Mosaic 按钮即可启用这些选项。关于如何新建区域的更多内容，请见此处。
所有已创建的区域都能在 1Ds 视图中对应正射投影下的 Mosaicing 里找到。

在 1Ds 视图中选中某个区域后，2Ds 视图中会显示出可选图像，并分为三个区：

  • Active 依据形状所覆盖的接缝线，在此可以看到已创建区域范围内的图像。要启用某张图像，把它从其他区拖放到 Active 区；要停用，就拖放到 Disabled 区。若双击某张图像，其余图像都会被停用。
  • Suggested 依据位置推荐的图像，可启用或停用。
  • Disabled 肯定不会使用的图像。若在 MOSAIC EDITOR/VIEW 上下文选项卡中点击 Suggest 按钮，它们会变成推荐图像。

选好要用哪些图像后，在 MOSAIC EDITOR/VIEW 上下文选项卡中点击 Bake 按钮，创建好的形状就会用所选图像体现在图像镶嵌上。
