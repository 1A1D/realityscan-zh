找到你的图像

你可能想知道添加到项目里的输入在哪、怎么查看它们。

在介绍输入位置之前，建议先调整布局并多打开几个视图。随时可以按 F1 键回到帮助章节。

切换布局即可同时看到当前项目的图像列表、其中一张图像和本帮助。你也可以选择其他任意多视图布局。

  • 选择 Workflow 选项卡。
  • 点击 Application 区域右侧的 Layout 按钮。
  • 在展开的下拉菜单中选择 1+1+1 Layout。
继续之前请先更改布局。
请选择一个至少包含三个视图的布局。

1+1+1 Layout 会显示三个视图：1Ds、2D 和 help。每个视图右上角有一个视图类型按钮，指示该视图的类型。左侧应能看到完整的 Images 列表、一张选中的图像以及本帮助。

关于浏览输入，有几点需要知道：

场景 1Ds 与 2D 视图

  • 点击左侧的图像即可切换选中的图像。
  • 拖动图像并放下到任意视图。
  • 部分视图可以分配彩色光标。按住 ctrl 加数字键（1、2、3 或 4）选择图像，即可为它指定四个彩色光标之一。
  • 在 SCENE 1D 和 SCENE 2D / VIEW 选项卡中，可以按图像的不同属性排序。

二维图像视图

  • 按住鼠标左键并移动鼠标即可平移图像。
  • 用鼠标滚轮在光标所在位置缩放。
  • 按住 ctrl+鼠标左键并移动鼠标即可拖动图像。
  • 在 IMAGE 2D / VIEW 中可找到不同的显示选项。
