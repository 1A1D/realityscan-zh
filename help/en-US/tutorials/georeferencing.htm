地理配准场景

地理配准是把现实世界坐标赋给虚拟三维场景、并把它放进所需坐标系的过程。这些坐标通常由全球导航卫星系统（GNSS）设备获取，可以有几种不同方式导入 RealityScan 使用。既可以用地面控制点把坐标赋给场景中某个可辨识的位置，也可以通过相机先验、飞行日志或 XMP 文件把坐标直接赋给相机。

在 1Ds 视图中选中组件后会出现的 Selected component(s) 面板里，可以看到场景（组件）是否已做地理配准。组件名称旁的标记图标也是提示。

地面控制点

地面控制点（GCP）可以把任意坐标系下的三维坐标赋给任意一个二维图像点。一个地面控制点可确定场景原点；两个可确定原点与尺度；三个或更多则可确定整个场景及其朝向。每个点至少要分配到两幅图像（测量值），建议至少三幅。不必把系统建议的每幅图像都确认分配。

注意：增加点数以及分配给它们的图像数能提高精度，但数量过多也可能反而让对齐效果变差。
  • 在图像中目视找出一个你掌握其现实世界坐标的点。
  • 在该处放一个控制点。
  • 把该控制点的类型改为 Ground control 点。
  • 设置坐标系。
  • 输入三维坐标。
  • 也可以定义权重，反映该点放置的准确程度以及它对对齐的影响大小。

建议在对齐之前添加控制点与地面控制点，尽管已有的点云有助于在图像中寻找对应点。

若在对齐前添加了地面控制点，那么相机位姿确定后（即对齐完成后）、且至少有两幅图像（测量值）分配给它们时，这些地面控制点就会在 3Ds 视图中显示，从地面控制点引出的橙色线也会出现。这些线表示残差——初始（先验）位置与配准位置之间的差值。线越短，越接近初始位置。请注意，零误差几乎不可能，因为真实测量总带有一定系统性偏差。残差线在 2D 视图中也能看到。可在 2D 与 3Ds 视图的上下文功能区（IMAGE 2D / VIEW 或 SCENE 3D / VIEW）里勾选或取消 Residuals 复选框，以开关残差显示。

也可以在 map 视图中放置地面控制点。首先需要有设为 Tie point 类型的控制点。然后启用 Control Points 工具，选中想作为 Ground control 使用的控制点。在 map 视图中点击想要放置该地面控制点的位置，所选控制点会立即变为 Ground control 点，坐标取自地图。不过所有高度都会被设为默认值 1。若想在 map 视图中更改地面控制点的位置，把它改回 Tie point 类型并重复上述过程。

相机位姿先验

场景也可以通过赋给相机的现实世界坐标来完成地理配准。许多相机、智能手机或无人机相机都配有 GNSS 单元，会把现实世界坐标存进图像元数据（EXIF），或另外生成一个可导入 RealityScan 的外部文件。

  • 在 1Ds 视图中手动添加相机位姿约束（阅读更多）。
  • 导入飞行日志，一次性为多台相机提供坐标与朝向值（阅读更多）。
  • 使用内嵌于图像元数据（EXIF）中的坐标。要让 EXIF 数据被使用，需在对齐设置中启用用于地理配准的相机先验（阅读更多）。
  • 含坐标值的 XMP 文件也可用于对场景做地理配准。

XMP 文件

RealityScan 定义了一系列携带各类相机信息的 XML 标签，并以可扩展元数据平台格式（XMP）导出。每个导出的 XMP 文件与对应相机（图像）同名，且应放在同一文件夹中。
如果 XMP 文件与图像在同一文件夹，导入时图像就会使用其中存储的数据，现实世界坐标也可以是这些数据的一部分。

XMP 文件可包含相机位姿信息，可用于：

  • 定义相机位置
  • 定义相机位置与朝向
  • 定义相对或绝对相机位置

这为工业级应用场景提供了可能：同一套相机配置被反复使用，而你希望每次扫描结果都保持完全一致的位置与尺度。
