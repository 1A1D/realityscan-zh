设置地平面

地平面决定了点云的朝向，对齐后会自动检测。某些情况下它可能倾斜，此时可以手动调整位置。这一步并非必需，平时也很少用到，但知道场景可以调整是有好处的。

你的项目还没有任何组件。请返回前面的步骤对齐图像。

要调整地平面，先用视图右上角的视图类型按钮把某个视图切到 3Ds，以调出 SCENE 3D/TOOLS 选项卡。打开该选项卡，点击 Set Ground Plane 按钮，3Ds 视图中就会出现地平面控件。

用这个控件可以移动或旋转场景：

  • 按住并拖动圆形控件可旋转场景。
  • 按住左键拖动箭头控件，可沿箭头方向所定义的轴移动场景。
  • 按住右键拖动箭头控件，可在与箭头轴垂直的平面上移动场景。
  • 双击场景任意位置可重新放置控件。

要把地平面恢复到初始位置，打开 Set Ground Plane 下拉菜单并点击 Reset Ground。也可以在同一菜单中使用 Set Ground by Reconstruction Region，按现有重建区域来设置地平面。
