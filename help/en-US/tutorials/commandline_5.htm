错误处理命令

用以下命令与设置可以处理应用命令行处理过程中可能出现的错误。

命令名称 必需参数 可选参数 说明
silent crashReportPath 抑制警告对话框与崩溃报告上传。应用会把报告存到指定位置，而不再弹出上传向导。
set "key=value" 设置一个应用状态变量。
preset "key=value" 在初始化阶段修改应用设置，适合那些需要重启应用才能生效的改动。关于该命令的用法，见此处。
reset ui | cfg | cfgui | all 重置用户界面、设置，或两者都重置，也可以让 RealityScan 恢复到干净安装的状态。该命令只在批处理文件中使用才有效，且不支持委派命令。重置什么由所选参数决定：ui —— 重置用户界面，cfg —— 重置应用设置，cfgui —— 同时重置界面与设置，all —— 恢复为干净安装状态。
writeProgress fileName timeout 在指定时长内（timeout 以秒计）把进度变化写入指定文件（fileName 含路径）。文件结构见下文示例，所有进程 ID 见此处。
printProgress timeout 把任何新的进度变化打印到 Windows 命令提示符中。可选的 timeout 参数还会在指定时长内持续输出（timeout 以秒计）。
tag string 把字符串参数输出到 Windows 命令提示符。它遵循所用命令的顺序，也就是说只有在前一条命令所启动的进程结束后才会显示。
stdConsole 启用控制台重定向到应用的标准输出。启用后，应用控制台的内容会同时镜像到标准 Windows 控制台中，这也便于为 CLI 用途做进一步重定向。

设置名称 键 值 默认值
出错时退出 appQuitOnError bool false
需要重启时退出 appQuitOnReset bool false
抑制错误消息 suppressErrors bool false
最小进程时长 appProcessActionTime int 15
动作 appProcessAction None None
PlaySound
ExecuteProgram
命令行进程*

示例与更多信息

静默崩溃报告

RealityScan.exe -silent c:\\CrashReportFolder ^
-set "appQuitOnError=true" ^
-set "appProcessActionTime=0" ^
-set "appProcessAction=ExecuteProgram" ^
-set "appProcessExecCmd=c:\\MyScripts\\ErrorWriter.bat $(processResult) $(processId) $(processDuration:d) c:\\ErrorReportFolder\\ErrorReport.txt"

带 c:\\CrashReportFolder 参数的 -silent 命令会把崩溃报告的 minidump 重定向到目标文件夹 CrashReportFolder。

把 appQuitOnError 设为 True 会让应用在发生任何错误时退出。

appProcessActionTime 设为 0 表示我们关注所有时长至少为 0 秒的进程——也就是关注每一个进程。
把 appProcessAction 设为 2 相当于把它设为 Execute a program。
appProcessExecCmd 设为一个具体命令（批处理脚本）ErrorWriter.bat，其完整路径为 c:\\MyScripts\\ErrorWriter.bat，并带上必要的输入参数 $(processResult) $(processId) $(processDuration:d) c:\\ErrorReportFolder\\ErrorReport.txt。
这三项设置合起来可以这样理解：只要进程时长超过所指定的最小值（0 秒），应用就会执行 ErrorWriter.bat 程序。

可以把应用中的值作为被调用程序的输入参数，例如：
processResult —— 表示进程结果的数字（processResult 为 0 表示进程正常结束），
processId —— 进程 ID，
processDuration:d —— 表示进程耗时多久的数字。
也可以使用自己的输入参数（例如 c:\\ErrorReportFolder\\ErrorReport.txt），把必要数据传进脚本，比如用于写出错误报告文本文件的名称与完整路径。

下面是一个简短的批处理脚本示例 ErrorWriter.bat： 

if /i "%1" NEQ "0" ( 
                if /i "%1" NEQ "1" ( 
                    echo An error occured by process %2 which finished with result code %1 in %3 seconds. > %4 
                ) 
)

其中 %1, %2, %3, %4 是输入参数 $(processResult), $(processId), $(processDuration:d), c:\\ErrorReportFolder\\ErrorReport.txt。该脚本会检查输入参数 processResult 的值：若不为 0，说明进程以错误结束，脚本会向输出的 ErrorReport 文本文件写一份简短报告：

进程 20599 出错，在 0 秒内以结果代码 2181038335 结束。

退出码

RealityScan 进程成功结束时，应用返回的退出码为 0（可在 Windows 命令提示符中看到结果）。

若 RealityScan 进程以错误结束，应用会返回该具体错误的十进制代码（在使用 -set "appQuitOnError=true" 命令的情况下）。

若 RealityScan 进程崩溃并生成 minidump，应用返回的退出码为 3。

代码示例：

RealityScan.exe -silent c:\\CrashReportFolder ^
-set "appQuitOnError=true"
…
echo RealityScan.exe returned with %errorlevel%.

重启后退出

有些应用设置修改后需要重启应用。此时可以用 -set 命令配合键 appQuitOnReset=True 来抑制该对话框。请注意，使用该键并修改相应设置后应用会退出。下面是把缓存目录改到自定义位置、然后打开新场景的示例：

RealityScan.exe -set "appQuitOnReset=true" ^
-set "appCacheLocation=Custom"
RealityScan.exe -set "appQuitOnReset=true" ^
-set "appCacheCustomLocation=D:\cr-tmp"
RealityScan.exe -newScene

进度监控

用 -writeProgress 命令可以在指定时长（timeout）内把进度信息写入指定文件（fileName）。生成的文件包含 5 列：

algId —— 进程 ID，
progress —— 取值区间 <0,1> 的数字，表示进程所处阶段，
duration —— 已用时间（秒），
estimation —— 预计剩余时间（秒），
eventType —— {started, progress, timeout, completed}，表示产生该条记录的事件。

20561 0.00 0.04 404.08 #started
20561 0.45 0.10 0.22 #progress
20561 0.85 14.76 3.26 #progress
20561 0.90 15.04 1.70 #progress
20561 0.91 16.18 1.76 #progress
20561 0.94 16.72 1.82 #progress
20561 0.96 16.78 1.42 #progress
20561 0.97 17.06 0.55 #progress
20561 1.00 17.10 0.10 #progress
20561 1.00 17.13 0.00 #completed
