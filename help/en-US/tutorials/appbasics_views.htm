视图类型

RealityScan 区分多种视图类型（或称视图外观）。按所选视图类型，显示的信息可以是纹理、图形或三维信息。此外还有一些特殊的视图外观类型，例如控制台和帮助。

要切换视图类型，用鼠标左键按住视图窗口右上角的 Aspect 按钮，在你想使用的视图类型上松开即可。



不同布局、不同布局槽位的视图类型选项可能不同，大致如下所示：


如上图所示，视图类型不只按显示的信息区分，还用颜色做了标记。

  • Light gray 对应颜色光标。与视图同色光标所指对象搭配使用的视图外观会显示为浅灰色。
  • White 与该视图中当前显示的对象搭配使用的视图外观显示为白色。
  • Beige 这些是独立的视图外观。可以用，但它们既不关联颜色光标，也不关联视图中当前显示的对象。
  • Dark gray 特殊外观，例如控制台与帮助。

视图类型用法

  • 1Ds - Scene View 1D

    This view displays hierarchical relations among all objects. Use this view to access all the information available about the inputs, components, models, or various settings. It is not possible to use this view type with the Single View layout.

  • 2Ds - Scene View 2D - thumbnail view

    该视图方便查看场景中出现的所有输入。此视图中可查看简要信息，例如输入是否已配准。视图左下角还有一个信息面板，会显示当前鼠标悬停输入的相关信息。此视图类型不能与 Single View layout.



    When you drag and drop into a 2Ds view, you will see the following options:


    Images can be DRAGGED from other 2Ds views, also from the 1Ds view, and you can also make a camera selection in the 3Ds view, and hold CTRL key to drag into the 2Ds. All of these dragging methods will give the options shown above. Add and subtract are self explanitory. Intersect will leave images that are both already in the 2Ds view and also in the image selection being dragged in. Assign will make the 2Ds view show a fresh selection of only the images being dragged in.

  • 3Ds - Scene View 3D

    Shows 3Ds scene relations for the currently selected component and model.


  • 4Ds - Scene View 4Ds

    用于创建、修改（编辑相机路径与视角）和播放重建模型动画的面板；项目中只能有一个此类面板。 4Ds window open at the same time.

  • 1D - Input View 1D

    显示所选输入的所有可用纹理信息与计算结果。

  • 2D - Input View 2D

    This view type displays 2D image content of the selected object, e.g. an input image, a LiDAR scan, an orthographic projection, or an elevation map.
    根据输入类型，应用程序的上下文功能区会随之更新，提供额外的显示选项与工具，例如视线工具或距离测量工具。
    To display 2D image content, simply drag and drop an image, a LiDAR scan or an ortho projection to a 2D view.

    当影像显示在 2D view, in the lower-left corner the path to the image can be seen, as well as the information about whether the image is registered in the selected component. If it was registered, but not in the selected component, the name of the component in which it is registered will be displayed.

  • Con - Console View

    使用此视图可跟踪应用程序进度并创建命令序列。

  • Help - Context Help View

    This is the help view window. The application help provides many useful resources and can guide you to accomplish your goals. Press the F1 key at any time to open the help.

  • Map

    选择此视图类型会打开地图视图的 2D 版本，其中包含所选 Map Provider and other map objects (control points, ortho projections). After choosing the map view, it is possible to choose between the 1D and 2D versions of it by using the Aspect button again and choosing one of the white options (1D or 2D). The Map 1D version of the map view contains information about the map provider and can be used to enter an access token since it is required when using some providers.
