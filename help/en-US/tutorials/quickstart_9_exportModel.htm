导出模型

模型已创建并上色，现在可以导出了。进入 MESH & COLOR 选项卡，使用 Export 区域的 Model & Point Cloud 按钮。随后会弹出 Windows 资源管理器窗口，在其中设置模型名称、导出位置和格式。点击 Save 进入下一步——带导出设置的 Export Model 对话框。资源管理器窗口里设好的值之后无法更改，请谨慎选择。

选中的组件没有任何模型。请选择含有模型的组件；若都还没有模型，请返回上一步创建。

导出模型也可以使用 SCENE 3D/TOOLS 选项卡 Export 区域的 Model & Point Cloud 按钮，或 WORKFLOW 选项卡 Output 区域中通用的 Export 按钮。

导出并不要求先上色或贴纹理，所以重建完成后可以直接导出。

完成

教程到此结束。继续探索 RealityScan，祝你做出出色的模型。随时可以按 F1 回到帮助区查阅所需信息。
