命令行界面

RealityScan 的许多功能可以直接通过命令行或批处理文件调用。它们作为 RealityScan.exe 的参数传入并按顺序执行，行为与在图形界面中调用基本相同。应用会启动，计算过程中你依然可以照常与它交互。

你可以在 Windows 命令提示符中运行命令序列，也可以运行 .bat 文件。下面是一个命令序列示例：先用完整路径启动应用，之后每条命令以连字符开头，后面可跟参数。

"C:\Program Files\Epic Games\RealityScan\RealityScan.exe" -load C:\MyFolder\MyProject.rsproj -selectMaximalComponent -calculateNormalModel -simplify 1000000 -save C:\MyFolder\MyProject.rsproj -quit

要把完整的应用路径换成简单的 RealityScan.exe 命令，可把该路径存进系统变量 path。

在脚本开头加入下面这一行，可临时把 RealityScan 文件夹加入 path（直到本次命令行会话结束）。

set PATH=%PATH%;C:\Program Files\Epic Games\RealityScan\
RealityScan.exe -load ... -quit

基础工程与图像命令

以下是最基础的命令，用于控制当前工程、应用本身以及添加图像。

命令名称 必需参数 可选参数 说明
headless 隐藏用户界面。关于该命令的更多内容见此处。
hideUI 隐藏用户界面。与 headless 不同，该命令无需在启动时执行，也不会抑制需要用户交互的操作。
showUI 显示被隐藏的用户界面。与 headless 不同，该命令无需在启动时执行。
newScene 创建一个新的空场景。
load MyProject.rsproj recoverAutosave|deleteAutosave 从 MyProject.rsproj 文件加载已有工程。若该项目存在自动保存文件，可用可选参数指定处理方式：recoverAutosave 会打开自动保存的工程，deleteAutosave 会删除自动保存文件并加载原工程。关于自动保存功能的更多信息见此处。
要为所有工程全局设定该偏好，可用 set 命令加 appAutoSaveCliHandling 键，详见CLI 设置键与值一节。
save MyProject.rsproj 把当前工程保存到原位置，或另存为 MyProject.rsproj。
start 运行 Start 按钮所配置的流程。这些设置可在 Start 按钮下拉菜单中的 Start button 设置里调整。
unlockPPIProject myProject.rcproj 保存并解锁 PPI 工程，使其与最新版 RealityScan 兼容。请给出解锁后工程的完整目标路径（含工程名与扩展名）。
add imageName 从指定文件路径或图像清单导入一张或多张图像。图像清单是扩展名为 .imagelist 的文本文件，每行一个图像的完整路径。
addFolder folderName 添加指定文件夹中的所有图像。若还要包含子目录，用 set 命令加 appIncSubdirs 键：-set "appIncSubdirs=true"。详见CLI 设置键与值一节。
importVideo videoFileName
extractedVideoFramesLocation
jumpsLength		 导入从视频中抽取的帧（videoFileName 含路径）。帧会按 jumpsLength（秒）定义的间隔抽取到 extractedVideoFramesLocation 文件夹中。
importLeicaBlk3D fileName 导入 Leica BLK3D 采集的 .cmi 扩展名图像序列（fileName 含路径）。
importLaserScan laserScanName params.xml 用当前设置或 params.xml 中的设置（可选参数）添加一个 LiDAR 扫描或 LiDAR 扫描清单。这些设置可在应用的 LiDAR Scan Import 对话框中导出。
importLaserScanFolder folderName params.xml 用 params.xml 中的设置添加指定文件夹中的所有 LiDAR 扫描。这些设置可在应用的 LiDAR Scan Import 对话框中导出。
importHDRimages fileName|folderName|imageList params.xml 用当前设置或 params.xml 中的设置导入 HDR 图像（imageName）、图像清单（imageList）或某文件夹中的全部图像（folderName）。这些设置可在应用的 16-bit/HDR Images Import 对话框中导出。
addImageWithCalibration fileName
xmpFileName		 导入图像及其对应的 XMP 文件，请使用完整路径。
importImageSelection fileName 选中文件中列出的场景图像和/或 LiDAR 扫描（fileName 含路径）。
selectImage imagePath|regexp set
union
sub
intersect
toggle		 选中指定图像（imagePath）或由正则表达式（regexp）定义的图像。示例见下文。可用可选参数之一来更灵活地选择图像。
selectAllImages 选中项目中的所有图像。
deselectAllImages 取消选中项目中的所有图像。
invertImageSelection 反转当前的图像选择。
removeCalibrationGroups 清除所有输入的标定组。
generateAIMasks 用 AI Masking 分离图像中的目标物体来生成遮罩。
exportMasks folderPath params.xml 导出项目中当前使用的遮罩图像。需指定输出文件夹与导出参数 XML 文件的完整路径（该文件可从 Export Mask Images 对话框导出）。
params.xml 把遮罩图像导出到原图所在文件夹。需指定导出参数 XML 文件的完整路径（该文件可从 Export Mask Images 对话框导出）。
setImageLayer index pathImage layerType 把 pathImage 参数指定的图像（图层图像的路径）中的图层设置到 index 参数指定的图像上。索引对应 1Ds 视图中的图像顺序，从 0 开始。layerType 参数定义要设置到该图像上的图层类型（例如 mask、texture）。
setImagesLayer pathImage layerType 把 pathImage 参数指定的图像（图层图像的路径）中的图层设置到所选图像上。layerType 参数定义要设置到所选图像上的图层类型（例如 mask、texture）。
removeImageLayer layerType 从所选图像中移除 layerType 参数对应的图层（例如 mask、texture）。
importCache folderName 从指定文件夹导入资源缓存数据。
clearCache 清除应用缓存。清除前必须先保存工程。
execRSCMD Commands.rscmd 执行 .rscmd（或 .rccmd）文件中的命令，可选地带上报告参数。文件格式与语法见命令行之外的命令执行方式一节。在 .rscmd 文件路径后最多可列出九个参数作为变量；在文件内用 $(arg1)–$(arg9) 引用这些变量。
quit 退出应用。

图像选择示例

按直接路径选中一张图像：

-selectImage D:\sample\Images\IMG_0018.JPG

选中名称中含 "DSC" 的图像：

-selectImage g/DSC/

选中同时含 "2" 与 "1"、且两者之间有其他字符的图像（例如 image_1251.jpg）：

-selectImage g/2.1/

选中所有以偶数结尾、且扩展名为 .jpg 的图像（例如 222.jpg 或 img_0018.jpg）：

-selectImage g/[02468]\.jpg/

选中所有含 "DSC"、以偶数结尾、且扩展名为 .jpg 的图像（例如 img_DSC_222.jpg 或 DSC_14.jpg）：

-selectImage g/DSC.*[02468]\.jpg/

用于选择图像的命令可以带以下几种可选参数之一：

  • set —— 只选中符合条件的图像并取消选中其他所有图像。即使不使用任何可选参数，这也是默认行为。
  • union —— 与已选中的图像取并集。不会取消已选中的图像，只把符合条件的新图像加入选择。
  • sub —— 取消选中那些已选中且符合条件的图像。
  • intersect —— 只保留既已选中、又符合条件的图像，其余都从选择中移除。
  • toggle —— 反转符合条件图像的选中状态：已选中的被取消，未选中的被选中。

委派命令

这些命令可把操作委派给某个 RealityScan 实例。关于命令委派的更多内容见此处。

命令名称 必需参数 可选参数 说明
setInstanceName instanceName 为 RealityScan 实例指定名称。
delegateTo instanceName|* 把一条命令或一串命令委派给指定的 RealityScan 实例（instanceName），或委派给第一个可用实例（参数写 * 符号）。
waitCompleted instanceName|* 暂停执行后续命令，直到指定的 RealityScan 实例（instanceName）或第一个可用实例（参数写 *）中的当前进程结束。
getStatus instanceName|* 返回指定 RealityScan 实例（instanceName）或第一个可用实例（参数写 * 符号）中运行进程的进度状态。
pauseInstance instanceName|* 暂停指定 RealityScan 实例（instanceName）或第一个可用实例（参数写 * 符号）中正在运行的进程。
unpauseInstance instanceName|* 恢复指定 RealityScan 实例（instanceName）或第一个可用实例（参数写 * 符号）中已暂停的进程。
abortInstance instanceName|* 中止指定 RealityScan 实例（instanceName）或第一个可用实例（参数写 * 符号）中正在运行的进程。若处理是通过 CLI 命令完成的，该进程之后的所有进程也会被中止。
execRSCMDIndirect instanceName|* commands.rscmd 在指定实例中执行 .rscmd（或 .rccmd）文件中列出的命令。

针对所选图像的命令

以下命令可为后续图像处理设置一些偏好。

命令名称 必需参数 可选参数 说明
setFeatureSource 0|1|2 为所选图像定义特征来源模式：
0 —— Merge using overlaps，
1 —— Use component features，
2 —— Use all image features。
enableAlignment true|false 在配准过程中启用/禁用所选图像。
enableMeshing true|false 在模型计算/网格重建中启用/禁用所选图像。
enableTexturingAndColoring true|false 在着色与纹理计算中启用/禁用所选图像。
setWeightInTexturing <0,1> 设置所选图像在着色与纹理计算中的权重。
enableColorNormalizationReference true|false 把所选图像设为色彩归一化过程中的颜色参照，这些图像自身的颜色不会被改变。
enableColorNormalization true|false 在色彩归一化过程中启用或禁用所选图像。
setDownscaleForDepthMaps integer 设置所选图像计算深度图的降采样系数。
enableInComponent true|false 在网格重建中启用所选图像并继续。仅适用于已配准的图像。
setCalibrationGroupByExif 依据 Exif 设置所有输入的标定组。
setConstantCalibrationGroups 把所有所选输入归入同一个标定组。
lockPoseForContinue true|false 在下次配准时保持所选图像的相对相机位姿不变。仅适用于已配准的图像。
setPriorCalibrationGroup number 为所选图像设置先验标定组：
-1 —— 不分组，
其他数字 —— 归入同一标定组。
setPriorLensGroup number 为所选图像设置先验镜头组。-1 表示不分组，其他数字表示把所选图像归入同一畸变组。
editInputSelection "key=value" 依据 Selected inputs 面板中的值或其键名，编辑所选输入的设置。更多信息见此处。

代码示例

所有脚本都用 Windows 命令行语法编写。假设你把批处理脚本放在 C:\MyFolder，要加载工程 C:\MyFolder\PlainProject.rsproj、加入 C:\MyFolder\Images 文件夹中的图像、把进度保存为 MyProject.rsproj 然后退出。

set PATH=%PATH%;C:\Program Files\Epic Games\RealityScan\
RealityScan.exe -load C:\MyFolder\PlainProject.rsproj -addFolder C:\MyFolder\Images\ -save C:\MyFolder\MyProject.rsproj -quit

为提升可读性（路径较长时）与代码灵活性，建议把工作文件夹存进环境变量。

set PATH=%PATH%;C:\Program Files\Epic Games\RealityScan\
set MyPath=C:\MyFolder
RealityScan.exe -load %MyPath%\PlainProject.rsproj -addFolder %MyPath%\Images\ -save %MyPath%\MyProject.rsproj -quit

添加图像清单与添加单张图像的方式相同。

set PATH=%PATH%;C:\Program Files\Epic Games\RealityScan\
set MyPath=C:\MyFolder
RealityScan.exe -load %MyPath%\PlainProject.rsproj -add %MyPath%\images.imagelist -add %MyPath%\Images\image_123.jpg -save %MyPath%\MyProject.rsproj -quit

通常不必使用 -newScene 命令，因为应用启动时本身就是新场景；但若想不重启应用就开一个新工程，它很有用。

在批处理脚本中，若想让 RealityScan 命令序列延续到下一行并作为一条处理，必须用 ^ 断行。
以 #、//、REM 或 rem 开头的行会被跳过。可以用这些符号把一段文本标记为代码注释，例如：// I am a comment。
