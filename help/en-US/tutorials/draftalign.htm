快速草稿重建

RealityScan 支持做快速的草稿重建（预览），也就是先估算所有输入的位姿，例如用于现场分析——入口在 ALIGNMENT / Draft (CTRL+F6)。模型算完后，可以生成预览，再进入 MESH & COLOR / Colorize / Preview quality 继续。但请记住，草稿模式是用质量换速度。

  • 以下是草稿模式的默认设置——ALIGNMENT / Registration / Settings：


Image overlap 是对相邻照片共同区域的粗略估计，可设为 low、medium 或 high。重叠设得越大速度越快，但若图像数量不够，可能导致组件之间断开。
Image downscale factor 是特征检测前对图像降采样的系数。要最高精度就用全分辨率，即数值 1（不降采样）。
Final model optimization 启用/禁用全局场景优化。做模型预览时不必开启，但做高精度模型时强烈建议开启。

  • 想快速看模型效果，也可以用 MESH & COLOR / Preview (CTRL+F7)，它会迅速生成一个低细节模型。
  • 与预览相关的设置（可管理预览模型属性）位于 MESH & COLOR / Create Mesh / Settings（阅读更多）。
