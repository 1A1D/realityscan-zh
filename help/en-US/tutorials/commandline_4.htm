设置命令

用这些命令可以直接从命令行修改应用设置与行为。

命令名称 必需参数 可选参数 说明
set "key=value" 设置一个应用状态变量。
preset "key=value" 在初始化阶段修改应用设置，适合那些需要重启应用才能生效的改动。关于该命令的用法，见此处。
reset ui | cfg | cfgui | all 重置用户界面、设置，或两者都重置，也可以让 RealityScan 恢复到干净安装的状态。该命令只在批处理文件中使用才有效，且不支持委派命令。重置什么由所选参数决定：ui —— 重置用户界面，cfg —— 重置应用设置，cfgui —— 同时重置界面与设置，all —— 恢复为干净安装状态。
silent crashReportPath 设置崩溃报告的存放位置。应用会把报告存到这里，而不再弹出上传向导。
writeProgress fileName timeout 把任何新的进度变化写入指定文件（fileName 含路径）。可选的 timeout 参数还会在指定时长内持续输出（timeout 以秒计）。关于文件结构的更多内容见错误处理命令一节。
printProgress timeout 把任何新的进度变化打印到 Windows 命令提示符中。可选的 timeout 参数还会在指定时长内持续输出（timeout 以秒计）。
tag string 把字符串参数输出到 Windows 命令提示符。它遵循所用命令的顺序，会在前一个进程结束后才执行。
stdConsole 启用控制台重定向到应用的标准输出。启用后，应用控制台的内容会同时镜像到标准 Windows 控制台中，这也便于为 CLI 用途做进一步重定向。
disableOnlineCommunication 禁用一切在线通信。
importGlobalSettings settings.rsconfig 从 settings.rsconfig 文件导入应用全局设置。
exportGlobalSettings settings.rsconfig 把应用全局设置导出到 settings.rsconfig 文件。
setProjectCoordinateSystem authority:id 用权威机构及其 ID 定义项目坐标系（ID 可在特定数据库中查到，例如 epsg.xml 与 local.xml）。
setOutputCoordinateSystem authority:id 用权威机构及其 ID 定义输出坐标系（ID 可在特定数据库中查到，例如 epsg.xml 与 local.xml）。

设置示例

RealityScan.exe -set "sfmDistortionModel=Brown3" ^
-set "unwrapMaximalTexCount=1" ^
-set "unwrapStyle=1"

用下面的命令可以把局部欧氏坐标系设为项目坐标系，把 EPSG 代码 4326 的 GPS（WGS84）设为输出坐标系：

RealityScan.exe -setProjectCoordinateSystem Local:1 ^
-setOutputCoordinateSystem epsg:4326
