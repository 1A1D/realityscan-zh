LiDAR 扫描

RealityScan 可对 LiDAR 数据自动完成配准、滤波、着色、纹理和网格化。扫描数量与项目规模都没有限制，超大数据集也能处理。

你已经把 LiDAR 数据导入项目了，恭喜！现在可以跳过导入步骤，直接创建三维模型。也可以按 Ctrl+N 新建场景，重新导入 LiDAR 数据。

LiDAR 导入

可以导入有序的地面 LiDAR 数据（点按扫描仪原始采集模式排列），也可以导入易与摄影测量数据对齐的移动 LiDAR 数据。导入时 LiDAR 数据会被转换为 LSP 文件 —— 一种类似图像的应用内部格式。

LSP 文件存于本地，可与原始 LiDAR 数据放在一起，也可指定自定义位置。导入之后，新建项目时无需也不建议重新导入同一批 LiDAR 扫描 —— 那会覆盖已有的 LSP 文件。应直接使用之前生成的 LSP 文件，避免重复处理。

导入 LiDAR 扫描，直接把文件拖放到项目中即可。也可以点击 WORKFLOW 选项卡中的 LiDAR Scan 按钮，再选择导入选项并指定源文件夹。

地面 LiDAR

地面 LiDAR 数据的点按结构化的、反映扫描仪采集方式排列，可导入的格式为 PTX、E57、PLY 和 ZFS/ZFPRJ。

移动 LiDAR

支持的格式包括 LAS/LAZ、E57、PLY、CSV、XYZ 和 ASCII PTS。导入后，LSP 文件的相机位姿或取自已有位姿（先验或已配准），或按所选选项自动生成。

导入设置

地面与移动 LiDAR 数据的导入设置大体相同，但有些差异。以下是全部可用导入设置：

  • LiDAR type 类型会依据文件格式自动检测，但仍可手动修改，可选 Terrestrial LiDAR 与 Mobile LiDAR。不过不建议改动默认选择。
  • Registration 定义导入前扫描的配准精度：
    • Exact 导入的位姿会被保留。导入的模型决定场景的坐标系。
    • Draft 扫描站点已粗略配准，但需要微调。
    • Unregistered 站点尚未配准，配准引擎会为所有扫描计算位姿。
  • Georeferenced 若 LiDAR 扫描已地理参考、且希望这类数据进入项目，请设为「是」。
  • Coordinate system 当 Georeferenced 设为「是」时，需指定 coordinate system。
  • Features source 选择用颜色还是强度通道把照片与 LiDAR 扫描配准起来，默认是 Color。对 Z+F 扫描，若源文件旁有对应的 .jpg，请用 Color。
  • Noise profile 定义点云精度如何随「到扫描站的距离」和「强度值」变化。可选 Noise free profile、ScanStationP20，或依据扫描仪技术文档自定义。要新增配置，请编辑 noiseprofiles.xml（位于应用安装目录）。
  • Import classification 导入含分类数据的 LAS 或 LAZ 文件时可用。导入的类别会列在 1Ds 视图的 LiDAR Classification 下。
  • Output path LSP 文件可与原始数据放在同一目录，也可指定自定义位置。
  • Custom path 若 Output path 设为 Custom，请指定 LSP 文件的保存目录。

导入移动 LiDAR 扫描还有虚拟相机的设置，地面 LiDAR 不使用这些设置。列表如下：

  • Use camera poses 选择虚拟相机位姿的计算方式：可取自先验相机位姿、取自已有的已配准组件，或自动生成。
  • Extract from component 若选择从已有组件生成相机位姿，请指定使用哪个组件。
  • Height reference 选择自动生成移动位姿时，设置相对于扫描的高度基准。
  • Camera height 设置相对所选基准的高度。建议与扫描时传感器离地高度一致。
  • Camera overlap percentage 设置生成相机位姿之间的重叠度。值越大相机越密。
  • Camera cluster 选择如何从扫描生成相机组：单个相机、一个相机加四个指定非天底角的附加相机，或地面 LiDAR 扫描所用的六相机。
  • Off-nadir camera angle 设为非零值时，会在天底相机周围以该角度生成四个附加相机。

LiDAR 分类

LiDAR 分类依据 ASPRS（美国摄影测量与遥感学会）标准，把点云数据归入地面、植被、建筑物等类别。每个类别代表扫描捕获的一类特定表面或物体，便于识别和分离场景中的不同要素。用户可以显示或隐藏选定的点类别，只让相关的类别参与重建，从而得到更干净、更有针对性的模型，并去除最终结果中的噪声或多余特征。

导入 LAS 或 LAZ 文件时会自动检测是否含分类。要让分类生效，请在 Import LiDAR 对话框中启用 Import classification。导入后，所有 LiDAR 类别会列在 1Ds 视图的 LiDAR Classification 下。

分类可以叠加在 3Ds 视图的稀疏点云（连接点）上显示，总开关在 SCENE 3D/VIEW 选项卡 Alignment Points 区域的 LiDAR Classes 复选框。要显示或隐藏某个类别，用 1Ds 视图中各分类名旁的可见性开关。也可以在 Reconstruction Settings 中选择哪些类别参与或排除在网格创建之外。

导入 .ZFS 与 .ZFPRJ 格式

导入 Z+F 扫描格式时，可以选中全部 .zfs 文件，也可以选 .zfprj 工程。若扫描构成文件链，只需选中链中一个文件，其余会自动一并导入。请注意：不支持 Z+F Profiler 扫描仪或其他处于 profiler 模式的扫描仪生成的扫描。

RealityScan 可以导入 .zfprj 镶嵌图像，并在对齐过程中把它们作为特征来源。这有助于配准未配准的扫描，或在把扫描与图像合并时自动找到相同特征。该功能默认启用（设为 "Yes"），可在 Alignment settings 中以 Prefer images as feature source 找到。

导入带镶嵌图像的 .zfprj（Z+F 工程）：

  • 把 .zprj 文件拖放到 RealityScan，或点击 WORKFLOW 选项卡中的 LiDAR Scan 按钮并选择要导入的 .zfprj 文件
  • 把 Select Feature source 设为 Color（选 Intensity 不会从 .zfprj 文件导入镶嵌图像）
  • 按 OK 导入文件并转换为 .lsp。

注意：不支持导入 .zfs 数据（扫描站位）附近的全景图像。
