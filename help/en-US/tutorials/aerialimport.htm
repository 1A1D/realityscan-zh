用航空数据创建三维模型

航空摄影常用于制图，以及拍摄从地面不便到达的结构物。

在 RealityScan 中，用航空影像建模与用地面数据建模没有区别。你可以任意组合航空照片、街景照片，甚至地面与航空 LiDAR 扫描仪的数据。不过要产出带地理配准的三维模型，可以导入多种数据来自动化处理。

处理航空数据的最佳实践如下：

  • 把航空图像加入已打开的项目。可选地再加入其他输入，例如地面照片、LiDAR 扫描等。输入添加顺序不限。
  • 若有飞行日志（用 GPS 设备记录的某次飞行轨迹），可点击 WORKFLOW 选项卡 Import Metadata 区域的 Trajectory 按钮导入。
  • 若你有与图像关联的地面控制点文件，可点击 WORKFLOW 选项卡 Import Metadata 区域的 Ground Control 按钮添加。

后续创建三维模型的一般流程详见这份分步教程：点击此处。做到哪一步由你决定。

创建真正射影像与数字表面/地形模型

要创建真正射地图或数字表面模型，请按以下顺序操作：

  • 把图像加入项目并对齐。
  • 设置重建区域，标记感兴趣的范围。
  • 计算模型，然后上色或贴图。
  • 创建正射投影。
  • 若要导出 DTM，用 Classification 工具对模型进行分类。
  • 点击 ORTHO 2D/TOOLS 选项卡 Export 区域的 Orthophoto、Digital Surface Model 或 Digital Terrain Model 按钮，导出正射投影、DSM 或 DTM。

提示：对于用低成本相机采集的航测数据，建议使用 Brown3 with tangential distortion model.
