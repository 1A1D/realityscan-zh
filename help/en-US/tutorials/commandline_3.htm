模型工具

模型成功创建后，可以用这些工具给模型上色、创建纹理，并对模型做些后期处理。

命令名称 必需参数 可选参数 说明
selectModel modelName 选择指定名称（modelName）的模型。
deleteSelectedModel 删除当前所选模型。
duplicateSelectedModel 复制所选模型（含纹理）。
renameSelectedModel newModelName 重命名当前所选模型。
correctColors layerName 对所选组件中的所有图层或指定图层（layerName）运行色彩校正。
unwrap params.xml 用当前设置或 params.xml 中的设置（可选参数）计算模型展开。这些设置可用应用中的 Unwrap 工具导出。
calculateTexture 用当前设置计算纹理。
calculateQualityTexture 用网格质量值计算纹理，该值可由 Quality Analysis 工具算出。使用本命令前不必先计算质量值。
reprojectTexture sourceModel resultModel params.xml 用当前设置或 params.xml 中的设置（可选参数），把纹理从带纹理的模型（sourceModel）重投影到已展开的模型（resultModel）上。sourceModel 与 resultModel 均为应用中的模型名称。这些设置可从应用中的 Texture Reprojection 工具导出。
calculateVertexColors 用当前设置计算上色。
calculatePreviewVertexColors 用当前设置计算草稿上色。
calculateQualityColors 用网格质量值计算顶点颜色，该值可由 Quality Analysis 工具算出。使用本命令前不必先计算质量值。
simplify targetTriangleCount or params.xml 用当前设置（不带任何参数时）把所选模型简化到指定三角面数（targetTriangleCount），或使用 params.xml 中的设置。这些设置可用应用中的 Simplify Tool 导出。
smooth params.xml 用当前设置或 params.xml 中的设置平滑所选模型。这些设置可从应用中的 Smoothing Tool 导出。
closeHoles maxEdgesCount 用当前设置或指定的最大边数（maxEdgesCount）封闭模型孔洞。
cleanModel 清理所选模型：移除非流形边与顶点、封闭小孔洞等。
selectTrianglesInsideReconReg 选中重建区域内部的三角面。
selectTrianglesOutsideReconReg 选中重建区域外部的三角面。
selectMarginalTriangles 选中那些包围体积、但不属于当前重建结果的三角面。
selectLargeTrianglesAbs edgeSizeThreshold 选中边长大于阈值（edgeSizeThreshold）的三角面。
selectLargeTrianglesRel edgeSizeThreshold 选中边长大于阈值（edgeSizeThreshold）乘以平均边长后的三角面。
selectLargestModelComponent 选中属于模型最大连通分量的三角面。
invertTrianglesSelection 反选三角形选区。
deselectModelTriangles Deselect all model triangles.
removeSelectedTriangles 新建一个模型，把所选三角面剔除（行为与 Filter Selection 工具相同）。
cutByBox inner|outer fillHoles 滤掉重建区域内部或外部的三角面。必需参数决定滤掉哪些三角面，可选参数 fillHoles 决定是否填补切割产生的孔洞（可设为 true 或 false，对应 Yes 与 No）。若未指定该可选参数则使用默认值（Yes）。该工具会新建一个模型。
exportModel modelName fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把模型（工程中的 modelName）导出为文件（fileName 含路径与文件扩展名）。该文件可从 Export model 对话框导出。
exportSelectedModel fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把所选模型导出为文件（fileName 含路径与文件扩展名）。该文件可从 Export model 对话框导出。
exportModelToZip filePath modelFormat 把所选模型导出为压缩包。需指定压缩包的保存路径与导出文件名，压缩格式的扩展名可省略。此外还可用可选参数指定模型格式（例如 .obj 或 .fbx）。
importModel fileName 从文件导入模型（fileName 含路径与文件扩展名）。
calculateOrthoProjection rsorthoFile rsboxFile 用当前设置计算正射投影。可选地使用投影参数文件（.rsortho）来定义计算设置，该文件可随正射投影一起导出，其结构见此处。还有一个可选参数是导出的重建区域文件（.rsbox），用于指定纳入正射投影的范围。
selectOrthoProjection orthoName 选择指定名称（orthoName）的正射投影。
editOrthoProjectionSelection "key=value" 依据 Selected ortho photo(s) 面板中的值或其键名，编辑所选正射投影的设置/参数。更多信息见此处。
exportOrthoProjection orthoName fullPath params.xml 用 params.xml 文件中的设置导出正射投影（正射影像、DSM 或 DTM），该文件可从对应导出对话框导出。本命令有三种写法，取决于所用参数：params.xml 定义导出设置；orthoName 是投影在工程中的名称；fullPath 指定导出文件的完整路径；folderPath 指定保存目录；exportName 设置导出文件名。对 fullPath 与 exportName 而言格式扩展名可选——若省略则生成 TIFF 文件。
orthoName folderPath exportName params.xml
fullPath params.xml
calculateCrossSections step axis 用当前设置计算横断面，或通过指定轴向（重建区域的局部轴）与断面间距来计算。
exportCrossSections fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把所选横断面导出为文件（fileName 含路径与文件扩展名）。该文件可从 Export Cross Sections 对话框导出。
renameCrossSections crossSectionsName Rename selected cross sections.
selectCrossSections crossSectionsName 按名称选中横截面。
computeContours params.xml 用当前设置或 params.xml 中的设置（可选参数）为所选正射投影计算等高线。这些设置可用应用中的 Contours Tool 导出。
exportContours fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把所选等高线导出为文件（fileName 含路径与文件扩展名）。该文件可从 Export Contours 对话框导出。
renameContours contoursName Rename selected contours.
selectContours contoursName Select contours by name.
exportShapes fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把所选形状导出为文件（fileName 含路径与扩展名 .json）。该文件可从 Export Shapes 对话框导出。
importShapesToSelectedOrtho fileName mosaicing|measurements 把文件中的形状（fileName 含路径与文件扩展名）导入所选正射投影。其类型取决于当前启用的形状创建工具：Measure 或 Enhance Mosaic。
importShapesToOrtho fileName orthoProjectionName mosaicing|measurements 把文件中的形状（fileName 含路径与文件扩展名）导入正射投影（orthoProjectionName）。其类型取决于当前启用的形状创建工具：Measure 或 Enhance Mosaic。
selectShape shapeName Select shape by name
addShapeToSelection shapeName 按名称把某个形状加入当前选择。
exportReport outputFileName templateFileName true|false 用模板（templateFileName 含路径）把报告导出为文件（outputFileName 含路径与 .html 扩展名）。默认模板存放在安装目录\Reports 下。可用可选的布尔参数（true 或 false）导出包含指定模板中所找到报告的文件。
printReport reportString 把报告文本输出到命令提示符。该命令可用于以批处理文件运行 RealityScan 的场景，不支持委派。关于报告自定义的更多内容见此处。
generateMaskFromMesh 依据现有相机视图（图像）与所选模型生成遮罩图像：从相机看模型周围的一切都会被遮掉。
exportDepthAndMask folderName params.xml 为所选图像导出深度图和/或遮罩。若未指定 folderName 与 params.xml，则按当前设置把结果存放在原图旁边。设置文件可在应用的 Export Depth Maps and Masks 对话框中导出。
exportLod fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把所选模型导出为线性 LOD 模型文件（fileName 含路径与文件扩展名）。该文件可从 Export LoD 对话框导出。要导出为 Cesium 3D Tiles（.json）格式，请使用 export3dTiles 命令。
export3dTiles fileName params.xml 用当前设置或 params.xml 中的设置（可选参数），把所选模型导出为层级 LOD 的 .json 文件（fileName 含路径与文件扩展名）。在 Export LoD 对话框中选中 Cesium 3D Tiles（.json）格式后即可导出该文件。
exportCameraSnapshots folderName params.xml 从相机位置渲染模型图像：若未选或只选了一张图像则使用全部图像，否则只用所选图像。需指定图像存放的文件夹路径，并可用可选参数文件套用导出对话框中的设置。
renderMeshFromCustomPositionYPR fileName params.xml|width height focalLength x y z yaw pitch roll 用 yaw、pitch、roll 朝向从某个相机位置导出模型渲染图。
示例：从局部欧氏空间 (0,0,0) 处模型的俯视图：
RealityScan.exe -renderMeshFromCustomPositionYPR "C:/images/image.png" 1280 720 100 0 0 150 0 0 0
renderMeshFromCustomPositionLookAt fileName params.xml|width height focalLength x y z atX atY atZ upX upY upZ 从某个相机位置导出模型渲染图，视线看向另一个 XYZ 坐标，并可再指定一个 XYZ 坐标来确定竖直轴的上升方向。
示例：局部欧氏空间 (0,0,0) 处模型的侧视图（使用 up 参数）：
RealityScan.exe -renderMeshFromCustomPositionLookAt "C:/images/image.png" 1280 720 50 0 -100 0 0 0 10 0 0 1
renderMeshFromCustomGridPositionYPR fileName params.xml|fileName width height focalLength x y z yaw pitch roll 从自定义网格位置导出模型渲染图，视点由 yaw、pitch、roll 朝向定义。
renderMeshFromCustomGridPositionLookAt fileName params.xml|fileName width height focalLength x y z atX atY atZ upX upY upZ 从自定义网格位置导出模型渲染图，视线朝向指定目标，并可指定竖直轴。
uploadToSketchfab APIToken 把模型上传到 Sketchfab。必需参数是 Sketchfab API 令牌，可在你 Sketchfab 账号的账号设置中找到。

Classification Commands

用这些设置创建并调整分类。

命令名称 必需参数 可选参数 说明
dtmClassify params.xml 用当前设置或 params.xml 中的设置（可选参数）把所选模型的顶点分到预定义类别中。这些设置可用应用中的 AI Classify tool 导出。
selectClassification classificationName 按指定名称（classificationName 参数）选择分类。
renameSelectedClassification newClassificationName 把所选分类重命名为指定的新名称（newClassificationName）。
transferClassification params.xml 从标签层图像转移分类。可用从 AI Classify tool 面板导出的参数文件作为可选参数。
exportClassificationSettings XMLfilePath 从 AI Classify tool 面板导出设置。必需参数（XMLfilePath）请给出导出用的完整路径，含文件名与格式扩展名（.xml）。
importClassificationSettings XMLfilePath 把设置导入 AI Classify tool 面板。必需参数（XMLfilePath）请给出导入用的完整路径，含文件名与格式扩展名（.xml）。
overrideSelectedVertices className 覆盖所选顶点，把它们的类别改为当前所选类别，或改为按名称指定的类别（可选）。
selectClass className 用指定的类名从所选分类中选择一个类。
deselectClass Deselect all selected classes.
renameSelectedClass newClassName 把所选类的名称改为指定的新类名（newClassName）。
setSelectedClassAsGroundForDTM true OR false 在 Selected Class 面板中修改所选类的 Use as ground for DTM 设置：设为 true 则用作 DTM 的地面，设为 false 则排除。
setSelectedClassAsGroundForExport 在 Selected Class 面板中把 Export class LAS 设置改为 Ground (2)。
setSelectedClassLasFormat 0 - 12 把 Export class LAS 设置改为 0 到 12 之间的某个数值。
selectVerticesOfSelectedClass 依据所选类选择模型顶点。
selectClassificationFormat classificationFormatName 按指定的分类格式名称选择分类格式。
renameSelectedClassificationFormat newClassificationFormatName 把所选分类格式重命名为指定的新名称。
exportSelectedClassificationFormat filePath 通过指定完整路径（含文件名与 .cfd 扩展名）导出所选分类格式。
exportClassificationFormat classificationFormatName filePath 通过指定名称与输出文件路径（含文件名与 .cfd 扩展名）导出分类格式。
importClassificationFormat filePath 通过指定完整路径与名称（含 .cfd 扩展名）导入分类格式。
colorModelBySelectedClassification 按所选分类中的类别给模型上色。
deleteSelectedClassification 删除所选分类。

模型工具示例

以下是一些模型工具、导入与导出的用法示例。

简化、平滑、贴图并导出模型

这段代码会以正常细节计算模型，简化到 10 万三角面，再平滑、贴图，然后导出结果。

RealityScan.exe .... -calculateNormalModel -simplify 100000 -smooth -calculateTexture -exportModel "Model 3" %MyPath%\Object.obj %MyPath%\objParams.xml -save %Mypath%\NewProject.rsproj -quit

注意：参数文件可从 Export Model 对话框获取。

现在工程里有三个模型：第一个是正常模型，第二个是简化后的，第三个是简化并同时平滑、贴图的。默认会选中最后创建的模型用于下一步处理。
现在可以用 -selectModel 命令按名称选择模型，再用 -exportSelectedModel 导出该模型。下面这段代码会以正常细节计算模型，简化到 10 万三角面，再平滑、贴图，但导出的是第二个模型：

RealityScan.exe .... -calculateNormalModel -simplify 100000 -smooth -calculateTexture -selectModel “Model 2” -exportSelectedModel %MyPath%\Object.obj %MyPath%\objParams.xml -save %Mypath%\NewProject.rsproj -quit

把模型导入组件

假设你有一个名为 Models 的文件夹，想把其中所有模型导入一个已对齐的工程（并存为新工程）。

RealityScan.exe -load %MyPath%\AlignedProject.rsproj -save %MyPath%\NewProject.rsproj -quit
for %%s in (%MyPath%\Models\*.obj) do (
RealityScan.exe -load %MyPath%\NewProject.rsproj -selectMaximalComponent -importModel "%%s" -save %MyPath%\NewProject.rsproj -quit
)

For 循环会遍历所有 .obj 扩展名的文件并把它们加入工程。

计算正射投影

用命令创建并导出正射投影时，必须附上包含所有必需参数的文件。

RealityScan.exe .... -calculateNormalModel -calculateOrthoProjection %MyPath%\params.rsortho -exportOrthoProjection %MyPath%\ortho.tiff exportOrthoParams.xml -save %MyPath%\MyProject.rsproj -quit

在图形界面导出正射投影时，把 Export projection parameters file 设为 True，即可获得 params.rsortho 文件。想了解更多导出与导入参数文件的内容，请访问 this page。
