管理正射投影

管理正射投影在把模型导入新项目时特别有用。每个正射投影都会保存颜色图层，以及带深度和高程图层的数字表面模型。也可以渲染带深度和高程图层的数字地形模型。本教程说明如何显示、处理和以不同格式导出它们。

前提条件

必须已创建正射投影。点击 此处了解如何创建正射投影。


显示正射投影

正射投影可以在 2D 视图中显示。在左侧 1Ds 视图中找到要显示的正射投影 —— 它位于生成该正射投影所用模型的组件下。然后点击该正射投影，拖放到 2D 视图中。

正射投影显示在 2D 视图后，功能区会出现 ORTHO 2D 上下文选项卡。在 ORTHO 2D/VIEW 选项卡的 Source 区域可选择显示哪个图层，这样能预览导出后的效果；也可以更改正射投影上显示哪些对象。要使用正射投影相关工具、导出正射投影或其上创建的对象，请到 ORTHO 2D/TOOLS 选项卡。

若投影已地理参考，可以拖放到地图视图中查看其地理位置是否正确。map 视图的更多信息 点击此处。



也可以用 ORTHO 2D/TOOLS 选项卡 Tools 区域的 Sample Points 工具，把正射投影按规则栅格采样。Sample Points 工具的详情 见此处。

批处理

也可以批量处理多个正射投影，即同时执行多个正射投影的计算。

  • 在 1Ds 面板中选中要生成正射投影的模型。
  • 设置重建区域。关于重建区域的更多内容见 此处。
  • 点击 Ortho Projection 工具启用它（F11）。
  • 点击重建区域上要把模型重投影过去的那一面（用边角的灰色方块确定正射投影的左上角）。用 Estimate 按钮确定正射投影的最佳尺寸（分辨率），或手动修改这些值。然后点击 Add to batch 按钮（未处理的正射投影会出现在 1Ds 面板项目树中模型下方）。重复操作，直到定义好所需的所有正射视图。
  • 在 1Ds 面板中选中未处理的正射投影。
  • 最后点击 Selected ortho photo(s) 面板中的 Render 按钮，自动处理加入批次的全部未处理正射投影。
  • 处理完成的正射投影会加到项目树中，位于未处理的那些下方。
  • 要删除所有未处理的正射投影，先在 1Ds 面板中选中它们，再点击 Selected ortho photo(s) 面板中的 Delete 按钮。

测量

在正射投影中可以测量距离，并检查面积与体积。

所选正射投影的面积与体积信息可在 Selected ortho photo(s) 面板中查看：

  • Cut volume - 重建区域底面与渲染模型可见表面之间的体积。
  • Fill volume - 重建区域顶面与渲染模型可见表面之间的体积。
  • Area 2D - 渲染出的投影面积，或重建区域顶面/底面的面积。
  • Area 3D - 渲染模型可见表面的面积。

在 ORTHO 2D/TOOLS 上下文选项卡中可以找到 Measure Distance 工具，用于测量线段两端点所代表的两点之间的二维和三维距离。

  • 在 ORTHO 2D/TOOLS 上下文选项卡的 Tools 面板中点击 Measure Distance 按钮。
  • Measure Distance 工具会在所有正射 2D 视图中显示。
  • 用鼠标移动工具线段的端点。


把鼠标悬停在 2D 视图中显示的正射影像上时，还能看到所指每个点的 GPS 坐标和坐标系。

导出

可以把所选正射投影导出为正射影像、数字表面模型或数字地形模型。这三者提供的信息不同，请按用途选择。
若选中了多个正射投影，则全部导出。

要导出正射投影，进入 ORTHO 2D/TOOLS 上下文选项卡，选择正射投影的导出类型，会弹出保存文件的对话框。输入文件名并选择格式，然后点击 Save。点击 Save 按钮后会出现导出对话框。也可以使用 WORKFLOW 选项卡中通用的 Export 按钮。

导出正射影像

  • Export world file 勾选后同时导出 world 文件。
  • World file coordinate system 可选 Projected、Global 或 Image。选 Projected 时，模型会投影到由重建框定义的选定平面上，制作翻转立面时很有用；制作地图或顶视图请选 Global；制作立面图或剖面图请选 Image。

    注意：world 文件是一种纯文本数据文件，许多地理信息系统（GIS）用它为栅格地图图像做地理参考。小比例尺矩形栅格地图可附带一个 world 文件，供 GIS 软件描述地图的位置、比例和旋转。

  • Export projection parameters file 勾选后导出包含投影参数的文件，例如正射图像、全局坐标系与世界坐标系之间的变换矩阵，以及框定义、图像分辨率、坐标系定义等。
  • Compression 可选择压缩算法来压缩正射投影，得到更紧凑的数据表示。
  • Export as BigTIFF 若正射投影超过 4GB，可导出为 BigTIFF。选择 .tif 或 .tiff 格式时可用。
  • Tile image format 金字塔图像文件格式，与 .KML 和 .KMZ 格式配合使用。
  • Tile image resolution (pixel) 金字塔图像分辨率，与 .KML 和 .KMZ 格式配合使用。

导出数字表面模型与数字地形模型

数字表面模型与数字地形模型的导出沿用正射影像导出的设置，另外还有以下选项。

  • Color palette 选择渲染深度与高程数据所用的调色板。
  • Color depth 选择 8 位或 16 位色深。
  • Pixel type 决定导出内容显示哪种信息。Altitude 显示 RealityScan 坐标系中的高度；若模型已地理参考，则显示项目坐标系中的高度。Depth (local) 是从重建区域顶面量起的深度。Depth (global) 是从「包含项目坐标系零点、且平行于投影面」的平面量起的深度。这样在满足「所有投影面平行」的前提下，可以生成多个深度基准一致的投影。请注意：RGB 文件格式下深度会以 JET 色阶导出；若要以浮点导出深度，请选择 .tiff 格式。
  • Normalize image 启用后，导出的正射投影可直接在各种图像编辑软件中使用。设为 Yes 时，高度会被归一化到 <0,1> 区间。若要保留深度（全局），务必把此项设为 No。
  • Alpha channel 设为 Yes 时，导出的正射投影为 RGBA 色彩模型，背景透明；不使用此设置则导出为灰度图。请注意设为 Yes 时最终文件可能大四倍。

注意：导出为 KML 或 KMZ 格式时，建议使用 Map 类型的正射投影。
