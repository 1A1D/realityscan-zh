缩放场景

一般而言，用摄影测量方法无法直接确定场景的尺度，必须额外提供一些先验信息。事实上，要正确缩放场景，只需要一个数值就够了。在 RealityScan 中，你可以让三维模型在三个方向上同时等比缩放；不支持各轴单独设定系数的非等比缩放。缩放场景有几种做法。

距离约束

最简单的缩放方式是用距离约束工具。该工具位于 IMAGE 2D/TOOLS 选项卡，也可在 SCENE 3D/TOOLS 选项卡的 Registration & Sparse Point Cloud 区域以 Define Distance 按钮的形式找到；它还出现在 ORTHO 2D/TOOLS 选项卡的 Constraints 区域。为方便起见，也可以直接按键盘上的 F4 键。该工具以交互方式定义两个控制点之间的距离。请注意，这两个控制点各自必须已分配到两张或更多图像上。


  • 添加距离约束之前，请先放置至少两个控制点。
  • 启用该工具。
  • 在 2D 图像视图中选一张图像，其中要包含你想定义距离的那两个控制点。也可以切换到含两个或更多 2D 图像视图的布局，并多选几张图像，以便同时看到两个端点。
  • 在任意一个端点上点击并按住鼠标左键。
  • 把鼠标光标移到第二个控制点（任意视图均可）。你会看到一条从第一个点出发、跟随光标到鼠标指针位置的虚线。虚线末端会自动吸附到控制点附近，应用也会自动高亮这些点。
  • 松开鼠标按键确认创建。
注意：也可以在正射投影上交互式定义距离，位于 2D 视图；控制点也可以直接放到点云或模型上，在 3Ds view.

这一步会在两点之间创建一个距离约束，但两个端点之间的实际物理距离还没有定义。要定义距离，需在创建约束后自动打开的 Selected constraint(s) 面板中设置：只有给 Distance 属性填一个非零值，该约束才会参与空三对齐。多加几条距离约束可以提高精度。约束即便被禁用，仍可作为标尺使用。


可在 1Ds 视图中 Control points 节点下编辑约束属性。

直接定义距离约束

除交互方式外，也可在 1Ds 视图中 Control points 树下直接创建距离约束。

  • 添加距离约束之前，请先放置至少两个控制点。
  • 在 1Ds 视图中展开 Control points 节点。
  • 点击 Create distance 创建一个空约束。
  • 约束属性面板会自动打开。
  • 定义距离。
  • 在 A 和 B 字段中填入两个端点的名称。

导入距离约束

也可以在 WORKFLOW 选项卡的 Import Metadata 区域导入 Distance Constraints，随即弹出导入对话框：

  • File name 包含距离定义的文件名。
  • File format 定义距离定义文件中各值的顺序与类型。
  • Values separator 用于分隔距离定义文件中各值的分隔符。也支持限定符，即可以把每个字段放在双引号（""）里，表示它们是同一个字段。
  • Ignore first line 若文件带表头，可让 RealityScan 忽略第一行。以 # 符号开头的行会被自动跳过。
  • Coordinate system 导入的距离约束所处的坐标系。
  • Imported data accuracy 若距离定义文件不含精度信息，可在此以 Measurements accuracy 指定精度。还可指定 Units，即导入的距离约束及其精度值所用的单位。
  • 你可以在应用安装目录下的 distancedefinitions.xml 中自定义文件格式、其他值分隔符、注释符号或限定符。关于如何编辑 distancedefinitions.xml 的说明，以及导入支持的值列表，请见此处。

对新定义的距离满意后，点击 Update or the Align Images (F6) button in the Alignment tab. The Update 只改变当前所选组件的坐标系，同时更新其所有子模型的尺度；而 Align Images button creates a new component.

也可以通过 Workflow 选项卡导入 Distance Constraints。该文本文件所需的格式定义在应用安装目录下的 distancedefinitions.xml 中。


地面控制点

另一种缩放方式是给场景建立正确的坐标系，这可以通过添加地面控制点并定义其三维位置来实现。

通常需要 1 到 3 个点，且每个点至少在两幅不同图像中可见，也就是说实际需要 2 到 6 条约束。不过 RealityScan 内置了先进的解算器：只要建立任意 5 个独立观测（例如从 5 个互不重叠的位置观测到的 5 幅图像），就能解出场景的尺度与朝向。更多信息见地理配准章节（阅读更多）。

  • 定义一个地面控制点可确定场景原点：创建一个地面控制点并赋予 X/Y/Z 坐标。
  • 定义两个地面控制点（GCP）可确定尺度：把一个 GCP 放在原点，另一个放在 (distance,0,0) 即可。
  • 定义三个地面控制点可建立完整坐标系，前提是场景中能找到一处相互正交的角落。

用相机先验缩放

如果已知两台或多台相机之间的距离，这个信息同样可以用来缩放场景。另一种情况是相机中心可由 GPS 或飞行日志获得，此时场景会自动得到正确的尺度。更多信息见相机先验帮助章节（阅读更多）。若只知道两台相机之间的距离：

  • 添加位置先验，并把第一台相机设到原点。
  • 给第二台相机添加位置先验并设为 (distance,0,0)。

另一种做法是完全固定某台相机的位置与朝向，最简单的方式是使用 XMP 文件（阅读更多）。

缩放场景有几种方法，其中部分配有视频教程，可提供更多信息：

  • 创建两个能三角化出三维位置的控制点，并定义距离约束。
  • 用地面控制点直接定义坐标系。
  • 给相机中心添加相机先验。
  • 用 XMP 文件固定一台或多台相机的位置，或定义相机先验。
  • 添加地面 LiDAR 扫描。
  • 导入带元数据的标记点，本质上等同于定义地面控制点。
  • 导出时缩放场景。
