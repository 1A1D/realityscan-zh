对齐命令

以下命令可用于计算相机位姿与标定，以及处理组件与控制点。

命令名称 必需参数 可选参数 说明
align 按当前设置对齐图像。
draft 按当前设置以草稿模式对齐图像。
update 用刚性变换更新所有组件与模型，使其符合实际约束与控制点。
detectFeatures 按对齐设置执行特征检测。检出的特征会保存到应用缓存中。
mergeComponents 合并已创建的组件。使用该命令时不会向现有组件添加新图像。
exportXMP params.xml 用当前设置或 params.xml 中的设置（可选参数），以 XMP 格式导出上一次对齐所创建组件的相机元数据。该文件可从 XMP metadata export 对话框导出。组件必须满足 setMinComponentSize 命令定义的条件。
注意：XMP 文件与对应图像存放在同一文件夹中。
exportXMPForSelectedComponent 用当前设置以 XMP 格式导出所选组件的相机元数据。示例见下文“元数据（XMP）导出设置”一节。
注意：XMP 文件与对应图像存放在同一文件夹中。
importComponent component.rsalign 从 component.rsalign 文件导入组件。
loadBundler filePath params.xml 导入 Bundler 工程。该命令需要 Bundler 文件路径，以及可选的配置文件——该文件保存导入对话框中的场景变换设置，可用于在导入时调整坐标系或应用自定义变换。
loadColmap filePath params.xml 导入 COLMAP 工程。该命令需要 COLMAP 文件路径（三个文本文件中的任意一个），以及可选的配置文件——该文件保存导入对话框中的场景变换设置，可用于在导入时调整坐标系或应用自定义变换。
exportLatestComponents folderName 把上一次对齐创建的组件以 RealityScan 对齐组件（.rsalign）形式导出到指定文件夹。组件必须满足 setMinComponentSize 命令定义的条件。
setMinComponentSize size 指定 exportLatestComponents 与 exportXMP 命令导出时的最小组件尺寸，默认值为 5。
exportSelectedComponentDir folderName 把所选组件以 RealityScan 对齐组件（.rsalign）形式导出到文件夹（folderName 含路径）。
exportSelectedComponentFile fileName 把所选组件导出为 RealityScan 对齐组件文件。
exportRegistration fileName params.xml 用当前设置或 params.xml 中的设置（可选参数）把配准结果导出到指定文件。这些设置可在应用的 Export Registration 对话框中导出。
exportUndistoredImages folderName params.xml 用当前设置或 params.xml 中的设置（可选参数）把去畸变图像导出到指定文件夹。这些设置可在应用的 Export Registration 对话框中导出。
exportSTMap folderName params.xml 为所选图像导出 ST maps。若未指定 folderName 与 params.xml，则按当前设置把结果存放在原图旁边。设置文件可在应用的 Export Registration 对话框中导出。
exportSparsePointCloud fileName params.xml 用当前设置或 params.xml 中的设置（可选参数）把三维连接点（稀疏点云）导出到指定文件（fileName 含路径与格式扩展名）。这些设置可在应用的 Export Point Cloud 对话框中导出。
selectComponent componentName 选择指定名称（componentName）的组件供后续处理。
selectMaximalComponent 选择最大的组件供后续处理。
selectComponentWithLeastReprojectionError 依据计算出的 Mean error [pixels]，选择重投影误差最小的组件供后续处理。
renameSelectedComponent newComponentName 重命名当前所选组件。
deleteSelectedComponent 删除当前所选组件。
deleteComponent index 按所选索引删除组件。注意索引从 0 开始。
deleteAllComponents 删除所有组件。
importTrajectory flFileName params.xml 用当前设置或 params.xml 中的设置（可选参数）导入航迹文件。这些设置可在应用的 Import Trajectory 对话框中导出。
importGroundControlPoints gcpFileName params.xml 用 params.xml 中的设置导入地面控制点。这些设置可在应用的 Import Ground Control Points 对话框中导出。
importControlPointsMeasurements cpmFileName params.xml 用当前设置或 params.xml 中的设置（可选参数）导入控制点（CP）测量值。这些设置可在应用的 Import Control Points Measurements 对话框中导出。
editControlPointSelection "key=value" 依据 Selected control point(s) 面板中的值或其键名，编辑所选控制点的设置/参数。更多信息见此处。
listControlPoints fileName 把控制点清单导出到指定文件路径（fileName 参数，含文件名与扩展名）。每个控制点会连同其索引一起列出。
selectControlPoint controlPointName 按名称选中控制点。
invertControlPointSelection controlPointName 反转控制点的选中状态。若当前没有选中的控制点，则全选。
renameControlPoint controlPointName newName 重命名控制点。用当前名称（controlPointName）指定控制点，并给出新名称（newName）。
renameSelectedControlPoint newName 把所选控制点重命名为指定名称（newName）。
deleteControlPoint index 删除所选控制点。若使用可选的 index 参数，则删除对应索引的控制点。索引从 0 开始，顺序与 1Ds 视图中的控制点顺序一致。
selectMeasurementByError errorValue controlPointName 选中位置误差（像素）大于或等于指定 errorValue（浮点值）的所有测量值。若未指定控制点（controlPointName），则对全部测量值生效，不论属于哪个控制点。
selectMeasurementByIndex controlPointName index 按指定控制点内部的索引选中该控制点的测量值。
deleteControlPointMeasurement 移除所选控制点的测量值（即分配给某个控制点的图像）。需先在 1Ds 视图中对应控制点下选中这些图像。
exportGroundControlPoints gcpFileName params.xml 用当前设置或 params.xml 中的设置（可选参数）导出地面控制点。这些设置可在应用的 Export Ground Control 对话框中导出。
exportControlPointsMeasurements cpmFileName params.xml 用当前设置或 params.xml 中的设置（可选参数）导出控制点测量值。这些设置可在应用的 Export Control Points Measurements 对话框中导出。
defineDistance PointNameA PointNameB distance constraintName 在两个控制点之间定义距离约束。若未给定 constraintName，会自动生成距离名称。也可以从文件加载距离约束（见下文）。
defineDistance fileName params.xml 用当前设置或 params.xml 中的设置（可选参数）从文件（filename 含路径）导入距离约束。这些设置可在应用的 Import Distance Definitions 对话框中导出。支持的格式清单见安装目录下的 distancedefinitions.xml。
editConstraintSelection "key=value" 依据 Selected constraint(s) 面板中的值或其键名，编辑所选约束的设置/参数。更多信息见此处。
deleteConstraint index 移除所选距离约束。约束需在 1Ds 视图中选中。可用 index 作为可选参数指定要移除哪一条；索引从 0 开始，顺序与 1Ds 视图中的约束顺序一致。
detectMarkers params.xml 用当前设置或 params.xml 中的设置（可选参数）在图像中检测标记。这些设置可用应用中的 Detect Markers 工具导出。
setCamerasGravityDirection componentID 若图像的 XMP 文件含重力信息（xcr:Gravity），则组件会被旋转，使 -z 向量指向重力方向。该操作不影响稠密点云（网格/模型），只作用于稀疏点云（对齐结果）。作用于所选组件，或由可选参数（组件 ID）指定的组件。

对齐示例

跟着这些示例学习如何用命令行对齐图像。

对齐与草稿

假设你要添加图像、做快速草稿对齐、查看效果，然后继续正常对齐与其他计算。

RealityScan.exe -addFolder %MyPath%\Images\ -save %MyPath%\MyProject.rsproj -draft
RealityScan.exe -load %MyPath%\MyProject.rsproj -align .... -quit

第一行没有以 quit 结尾，因此该命令会等待应用关闭，然后紧接着继续执行。

导出 XMP 以复用对齐结果

现在来复用对齐结果。假设我们有一个已正确对齐的工程 Project1.rsproj，其图像来自 Images1 文件夹；我们想用 Images2 中的图像创建工程 Project2.rsproj，并复用同一套对齐。假定 Images1 与 Images2 中对应的图像名称相同，但扩展名可能不同。

RealityScan.exe -load %MyPath%\Project1.rsproj -exportXMP -quit
copy Images1/*.xmp Images2/
RealityScan.exe -addFolder %MyPath%\Images2\ -align -save %MyPath%\Project2.rsproj -quit

该脚本把 Project1 的 .xmp 文件导出到图像旁边（即 Images1 文件夹），再复制到 Images2。之后的 align 命令会依据这些 .xmp 文件与应用设置中保存的相机位置与标定进行对齐。

选择并导出最大的组件

下一个示例取最大组件，并把它加载到一个空场景中。

RealityScan.exe -load %MyPath%\AlignedProject.rsproj -selectMaximalComponent -exportComponent %MyPath%\max -quit
for %%s in ("maxComponent *.rsalign") do (
RealityScan.exe -importComponent "%MyPath%\%%s" -save %MyPath%\NewProject.rsproj -quit
)

组件名称事先未知，因此需要在应用之外查找。由于组件默认命名为 Component 0、Component 1 等，最大组件会被保存为 maxComponent 1.rsalign 之类。

导出超过最小尺寸的组件

最后一个示例导出所有相机数超过 5 的组件，再逐个导入到新工程。

RealityScan.exe -load %MyPath%\AlignedProject.rsproj -minComponentSize 5 -exportComponent %MyPath%\ -newScene -save %MyPath%\NewProject.rsproj -quit
for %%s in (*.rsalign) do (
RealityScan.exe -load %MyPath%\NewProject.rsproj -importComponent "%MyPath%\%%s" -save %MyPath%\NewProject.rsproj -quit
)

也可以把每个组件导入各自的工程，分别处理。
