正射投影

RealityScan 支持创建任意方向的正射投影。每个正射投影都连同颜色、深度和高程图层一起保存在项目中。你可以创建并导出带地理配准的正射影像图、图像镶嵌、DSM、DTM、侧视投影等。

前提条件

  • 必须已完成模型重建并选中该模型。

启用并使用工具

只有在指定了重建区域、且至少已创建一个模型之后，该工具才会激活——这对确定投影方向很有帮助。若跳过这一步，正射工具会自动识别一个合理的区域，你之后仍可调整。要创建重建区域，进入 MESH & COLOR 选项卡或 SCENE 3D/TOOLS 选项卡，点击 Set Reconstruction Region 按钮。关于如何设置重建区域的更多内容，请见此处。

要为选中的模型创建正射投影：

  • 在 3Ds 视图中显示出要用于创建正射投影的模型。Ortho Projection 工具位于 SCENE 3D/TOOLS 选项卡的 Tools 区域。
  • 也可以直接按键盘上的 按下 F11 代替上述步骤，或使用 WORKFLOW 选项卡中的 Ortho Projection 工具。
  • 正射投影的widget会出现于 3Ds 视图中。选择感兴趣的区域与投影面。
  • 在 1Ds 视图中还会出现一个新面板 Ortho Projection Panel，在其中填写正射投影的参数。
  • 点击 Render 按钮创建正射投影。

想了解如何一次创建多个正射投影，请见 Batch Processing。

投影控件

该widget可帮你快速确定要渲染场景的哪一部分、投影方向以及渲染图像的朝向。

  • 只有重建区域内的三角面会被投影到所选的橙色面上。
  • 橙色方块代表渲染图像的左上角。在重建区域任意一个角上点击灰色方块即可改变它。
  • 点击灰色方块也可以选择正射投影的方向。
  • 红色箭头表示正射投影方向。
  • 只有当正射投影类型选为 Top 或 Side 时，才能把它切换到某些指定面。
  • 可以用缩放、平移和旋转手柄来改变重建区域的属性。
  • 当正射投影类型选为 Top 或 Side 时，只能使用红色的旋转手柄。

正射投影工具面板

Ortho Projection 工具激活时，可在 1Ds 视图中看到此面板。它可用于确定正射投影尺寸、指定渲染选项，以及设定该投影任务何时执行。

  • Type 要创建的正射投影类型。

    Arbitrary No restrictions.
    Top 需要制作带地理配准的正射影像或 DSM 并导出到 GIS 应用时，用这个类型：可确保投影始终与所选坐标系对齐。
    Side 此时正射投影平面会始终垂直于所选坐标系的地平面。当正射影像要用作 CAD 工程文档的底图时很有用。
    Map 选此选项时坐标系会设为 WGS84，所有旋转选项锁定为 0。把正射影像导出为 KML 或 KMZ 格式时用这个类型。

    此选项仅对已做地理配准的场景可用；否则会自动选中任意（arbitrary）类型。

  • Info 定义重建区域的分组。
  • Info - Coordinate system 定义重建区域所用的坐标系，正射投影也会在该坐标系中进行。因此请务必注意这些设置并正确选择—— more about coordinate systems.

    请注意：若模型未做地理配准，坐标系面板不会出现，正射投影会建在局部坐标系下。

  • Rendering method 渲染方式：图像镶嵌（常规或航空）、从带纹理或带颜色的模型生成真正射。
  • Width, Height 渲染正射投影的分辨率。改变高度（宽度）时，正射像素尺寸与宽度（高度）会随之重新计算。
  • Ortho pixel size 所选坐标系下一个像素的尺寸（单位/像素）。改变此设置时，宽度与高度会随之重新计算。
  • Estimate optimal resolution 依据当前所选模型的属性（带颜色、带纹理、模型质量等）计算出最佳分辨率。
  • Color type 若模型已带纹理，可选择用着色还是贴图来计算正射投影。
  • Backface color type 若三角面的背面投影到所选投影矩形内，可以选择其颜色类型（Backface color）与颜色透明度（Backface color transparency）。仅在创建模型剖面时适用，见右图。
  • Generate DTM 想随正射投影一起生成数字地形模型就设为“ON”；不想生成则设为“OFF”。
  • DTM from classification 选择一个已有分类用于生成 DTM，或新建一个。若选 New Classification，会出现 DTM 生成设置。
  • Render ortho projection 点击 Render 开始渲染正射投影。
  • 创建未处理（待处理）的正射投影 当你点击 Add to batch 时会新建一个空的正射投影。若想快速建好多个正射投影、之后再一次性批量渲染，这很有用。

要继续，请创建一个或多个正射投影。
